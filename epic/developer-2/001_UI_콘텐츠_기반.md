## 목표

핵심 게임 루프를 지원하기 위한 초기 UI, 콘텐츠 데이터, 시나리오 표시 기준을 준비한다.

## 작업

1. 초기 화면 목록을 정의한다.
2. 핵심 루프에 필요한 콘텐츠 데이터 형태를 정리한다.
3. 시나리오 또는 안내 문구의 표시 위치를 정의한다.
4. 플레이스홀더 아트 요구사항을 정리한다.
5. 수동 검수 체크리스트를 작성한다.

## 완료 기준

- 초기 UI 화면 범위가 명확하다.
- 콘텐츠 데이터의 기본 구조가 문서화되어 있다.
- 개발자 1의 핵심 루프와 연결 가능한 입력/출력 조건이 정리되어 있다.
