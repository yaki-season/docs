S0+D1의 최초 공개 게이트를 검증하고, 공개 뒤 D2·D3 기능을 단일 정적 URL에 순차 배포할 수 있는

## 사용자 확정 실행 조건

- 최초 공개는 S0 정식 아트와 D1 전체 영업·정산·D2 전환이 모두 완성된 뒤 한다.
- 최초 공개 시 S0와 D1의 사용자 노출 placeholder는 0개다.
- 외부 플레이테스트는 필수 조건이 아니며 자동 테스트와 제작자 수동 검수로 공개한다.
- 공개 뒤 D2·D3는 기능 완성 즉시 순차 개방하며 아트 placeholder를 허용한다.
- 단일 공개 URL을 계속 갱신하고 첫 공개부터 저장 마이그레이션을 보장한다.

## 작업 절차

1. 모든 선행 작업의 완료 증거와 정확한 app commit을 수집한다.
2. S0+D1 자동 종단, 저장 복구, 새로고침, 중복 입력, 실패 경로를 실행한다.
3. S0·D1 manifest와 화면을 대조해 사용자 노출 placeholder 0개를 검증한다.
4. 제작자 수동 검수로 대사·입력·시각·무음 이해 가능성을 확인한다.
5. 최초 공개 뒤 저장 fixture를 고정하고 업데이트 마이그레이션을 회귀한다.
6. D2·D3는 기능 완료 단위로 공개 gate를 열고 placeholder를 명시적으로 보고한다.
