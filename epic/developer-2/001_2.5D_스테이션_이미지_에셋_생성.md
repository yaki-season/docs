## 목표

`ART-001 v1.1.0`에 정의된 16개 래스터 에셋을 지정 프롬프트와 콘셉트 참조로 생성하고, 정확한 경로·파일명·규격·알파로 `app/art/gameplay/`에 저장해 개발자 1이 추가 이름 결정 없이 바로 사용할 수 있는 인계 묶음을 완성한다.

## 범위

### 포함

- 배경 2개, 스테이션 4개, 음식 4개, 접시 1개, 츠키오카 상태 5개 생성
- 로컬 콘셉트 이미지 참조와 파일별 프롬프트 적용
- 평면 `#00ff66` 크로마키 제거, 최근접 리사이즈와 포맷 변환
- 규격·알파·앵커·정체성·문자 오염·파일 크기 검사
- `app/art/gameplay/ASSET-MANIFEST.md` 작성

### 제외

- HTML, CSS, JavaScript, Three.js와 게임 상태 수정
- 에셋을 실제 장면에 배치하거나 애니메이션하는 작업
- UI 문자, 주문표, 말풍선, 게이지, 경고 테두리와 히트 영역
- 연기·불씨·판정 링 등 개발자 1이 절차적으로 구현할 VFX
- 인트로, 생맥주, 직장인 A·B, 좌석 정리와 정산 에셋

## 작업 절차

1. `ART-001 v1.1.0`의 공통·투명·개별 프롬프트를 읽고 ID별 최종 프롬프트를 구성한다.
2. 각 프롬프트에 지정된 `docs/inbox/2.art-concept/` 로컬 참조 이미지를 이미지 생성 도구에 제공한다.
3. `BG-01`을 먼저 생성해 가게의 색, 소실점과 광원을 고정한다.
4. `ST-01`, `ST-02`, `ST-04`를 동일한 소실점과 광원으로 생성하고 `ST-03`을 그릴 개구부에 맞춘다.
5. `FD-01`, `FD-02`, `FD-03`과 `PR-01`을 생성한 뒤 앞의 재료를 참조해 `FD-04`를 생성한다.
6. `CH-01`을 캐릭터 기준 원본으로 생성하고 승인한 뒤, 이를 편집 참조해 `CH-02`~`CH-05`의 포즈·표정만 바꾼다.
7. 투명 파일의 균일한 `#00ff66` 배경을 제거하고 straight alpha PNG로 저장한다.
8. 최종 캔버스를 자동 trim하지 않고 manifest 규격으로 최근접 리사이즈한다. `BG-01`만 JPEG 품질 88 이상으로 저장한다.
9. 파일별 크기, 모서리 알파, 내부 불투명 픽셀, 크로마 잔류, 읽을 수 있는 문자와 워터마크를 검사한다.
10. 캐릭터 5종을 같은 크기로 합성 비교해 머리·어깨·하단 앵커 오차 4px 이하를 확인한다.
11. 세 작업대를 배경 위에 합성 비교해 수평선·중앙 소실점 오차 8px 이하와 안전 영역을 확인한다.
12. `ASSET-MANIFEST.md`에 ID, 경로, 실제 규격, 바이트, SHA-256, 최종 프롬프트, 참조 이미지, 후처리와 검사 결과를 기록한다.
13. 런타임 경로에 생성 원본·실패본·중간 크로마키 파일이 없는지 확인하고 개발자 1에게 경로 계약을 인계한다.

## 완료 기준

- [x] 16개 이미지가 지정된 경로·파일명·픽셀 규격으로 존재하고 실제 이미지로 열린다.
- [x] 투명 PNG의 네 모서리 알파가 0이며 내부에 비투명 픽셀이 있고 녹색·검은 halo가 없다.
- [x] 배경과 작업대에 사람, 음식, 접시, UI, 설명, 워터마크와 읽을 수 있는 문자가 없다.
- [x] 닭·대파·빈 꼬치·완성 네기마의 실루엣과 순서가 정확하다.
- [x] 츠키오카 5종의 얼굴·의상·체형·머리 위치와 하단 앵커가 허용 오차 안에서 일치한다.
- [x] `satisfied`, `neutral`, `retry`가 눈·입·자세 중 두 가지 이상으로 구분된다.
- [x] 세 작업대의 원근과 광원이 배경과 일치하고 안전 영역을 침범하지 않는다.
- [x] 전체 에셋은 5MB 이하, 첫 조립 장면 에셋은 2.5MB 이하이거나 초과 사유가 manifest에 기록된다.
- [x] `ASSET-MANIFEST.md`의 경로·규격·해시·프롬프트·참조·검사 결과가 실제 파일과 일치한다.
- [x] 런타임 디렉터리에 중간 생성물과 콘셉트 시트 복사본이 없다.

## 구현 및 검증 결과

- app 구현 위치: 최종 에셋 `app/art/gameplay/`, 생성·실패 원본 `app/art/review/generated-2026-07-22/`
- 구현 기준 spec 버전: `ART-001 v1.1.0`, `SCN-001 v1.0.0`, `SYS-002 v1.0.0`, `UI-001 v1.1.0`
- 구현 기준 태스크 버전: `v1.0.3`
- 검증 방법: 16개 직접 열람, 픽셀 규격·RGBA·모서리 알파·내부 픽셀·잔류 크로마·바이트·SHA-256 자동 검사, 캐릭터 공통 정렬과 구성 계약 수동 대조

- 남은 위험: 생성 원본은 콘셉트 기반 래스터이므로 개발자 1의 실제 2.5D 합성 단계에서 화면 크롭·광량의 미세 조정이 필요할 수 있다. 경로·파일명·원본 에셋은 재명명하거나 재가공하지 않는다.
