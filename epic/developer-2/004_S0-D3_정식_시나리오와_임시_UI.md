## 목표

D1 아트 제작과 병행해 S0~D3의 정식 한국어 대사·연출 순서·건너뛰기·3줄 요약과 화면 레이아웃을
임시 UI로 먼저 완성하고, 승인 아트가 도착하면 상태·입력 계약을 바꾸지 않고 교체한다.

## 사용자 확정 실행 조건

- 주인공은 `아사노 아키(浅野 秋)`, 29세, 중성적으로 표현되는 고정 인물이다.
- 외형은 짧은 흑갈색 머리·피곤한 눈매·마른 체형·걷어 올린 셔츠·짙은 남색 앞치마다.
- 첫 손님은 `츠키오카 세이지(月岡 誠司)`, 68세, 퇴직한 시내버스 기사다.
- S0~D3의 나머지 손님은 이름 없는 엑스트라 유형과 기억 플래그로 처리한다.
- S0는 `열쇠 선택 → 대문 열기 → 숯 점화`의 짧은 무실패 클릭 상호작용이다.
- 이야기·정산에는 아키 초상을 표시하지만 영업·조리에는 신체 부위를 표시하지 않는다.
- 오디오는 이번 범위에서 제작하지 않고 모든 의미를 시각적으로 전달한다.

## 범위

### 포함

- S0~D3 영업 전·정산 후 정식 대사와 장면 순서
- 모든 이야기 장면 건너뛰기와 최대 3줄 맥락·신규 행동·목표 요약
- S0 세 단계 무실패 상호작용과 D1 영업 준비 연결
- 날짜별 이야기·튜토리얼·정산 UI의 semantic DOM/CSS 임시 레이아웃
- 아사노 아키·츠키오카와 엑스트라 유형의 안정 ID·표시명·대사 규칙
- 승인 아트 교체를 위한 `sourceMasterId`·component·safe area 연결

### 제외

- 실제 영업일 gameplay·저장 — 개발자 1 작업 008~010
- S0·D2·D3 아트 생성 — Artist 작업 023·024
- BGM·SFX·보이스
- 하루·카나모리와 D4 이후 고정 인물 세부 설정

## 작업 절차

1. S0~D3 장면 ID·대사 ID·flag·skip summary를 콘텐츠 데이터와 연결한다.
2. S0 세 클릭 장면을 무실패 상태 흐름과 접근 가능한 버튼으로 구현한다.
3. D1~D3 영업 전·중 짧은 대사·정산 후 장면을 우선순위 규칙에 맞게 구현한다.
4. 임시 UI를 FHD/720 안전 영역에 배치하고 `개발 중` 표시를 분리한다.
5. 승인 아트 도착 시 DOM 의미·상태 ID를 유지한 채 manifest 에셋으로 교체한다.
6. 건너뛰기·재시작·저장 재개·키보드 입력을 E2E로 검증한다.
