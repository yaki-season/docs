`d1-game.html` 전체 영업으로 같은 저장을 유지하며 이동한다.

## 범위

- 현재 `D1-business-placeholder` 공개 노출 실패를 고정하는 실제 URL E2E
- D1 pre-open 완료 시 `campaignBridge.startDay()` 성공 뒤 같은 탭의 실제 D1 게임으로 전환
- 저장 실패 시 이동 차단과 기존 `campaign-error` 복구 화면 유지
- 공통 저장 prefix·campaignId·contentVersion·backup 정책 연속성 검증
- S0 새로고침, D1 day-start 복구, public shell 새 게임·이어하기 검증
- 기존 S0~D3 E2E의 가짜 D1 영업·정산 공개 경로 제거와 콘텐츠/도메인 검증 보존

### 제외

- D1 영업 도메인·정산·가격·시간·손님·주문·release artifact 변경
- D2~D5 영업 구현 또는 공개 우회 gameplay 경로
- UI 디자인, 아트, manifest, runtime asset resolver, placeholder inventory
