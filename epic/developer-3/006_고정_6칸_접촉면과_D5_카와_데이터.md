## 목표

그릴 접촉면 상태 불변식(칸 수는 명성 해금 가변, `content/progression/grill-slots.json`가 소유)을
스키마·검증기로 제공하고, D5 카와를 코드 분기 없이 조립·양념·면별 판정·공통 품질 데이터만으로
로드할 수 있게 한다.

## 범위

### 포함

- 명성 해금 가변 칸(시작 2·최대 8, `grill-slots.json`)과 D1 첫 주문 2칸 staged·동시 시작 데이터
- 제작물의 양면 누적 시간·아래 방향·`staged|active|offGrill` 배치·접촉면 저장 상태 스키마
- 그릴 위치·방향·접촉면 조합과 한 틱 양면 동시 증가를 거부하는 검증 fixture
- 카와의 접은 닭껍질 5개 레시피와 `salt|tare` 조리 방식
- 카와 면별 `perfect=10`, `over=14`, `burnt=18`과 네기마 공통 양면 품질 참조
- D5 첫 가이드의 적정 강조가 실제 판정 범위를 넓히지 않는 교차 검증
- D6 이후 부채가 카와의 현재 접촉면에만 적용되는 시뮬레이터 fixture

### 제외

- 그릴 상태 머신·화면·저장 로직 구현 — 개발자 1 작업 009
- 카와·그릴 아트와 시나리오 대사 제작
- 츠쿠네·난코츠·삼겹살말이의 미확정 레시피·시간 수치

## 작업 절차

1. 현재 조리·메뉴·저장 스키마에서 가변 칸과 단일 현재 면 시간 의존을 찾는다.
2. 가변 칸(명성 해금)·접촉면·양면 누적 상태와 카와 메뉴 레코드를 텍스트 콘텐츠로 추가한다.
3. 네기마·카와가 같은 양면 품질 집계 참조를 사용하도록 중복 분기를 제거한다.
4. 잘못된 접촉면·동시 양면 증가·판정 폭 보정·경계 역전을 실패 fixture로 추가한다.
5. 콘텐츠 검증기와 밸런스 시뮬레이터에서 경계값과 부채 위험을 결정적으로 검증한다.

- [ ] 콘텐츠 로더가 그릴 칸을 명성 해금 데이터(`grill-slots.json`, 시작 2·최대 8)로 제공하고 골드 grillSlots 업그레이드 레코드를 거부한다.
- [ ] 위치·방향·접촉면 불변식 위반과 한 틱 양면 동시 증가 fixture가 검증에 실패한다.
- [ ] 카와가 접은 닭껍질 5개·소금/타레·면별 `10/14/18초` 데이터로 로드된다.
- [ ] 네기마와 카와가 같은 양면 품질 집계 테이블을 참조한다.
- [ ] D5 가이드가 판정 폭을 넓히거나 D5 완료 전 부채를 노출하면 검증에 실패한다.
- [ ] 경계 직전·정확한 경계·부채 4초 적용 시뮬레이터 테스트가 통과한다.
