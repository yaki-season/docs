## 목표

D4 이후 즉시 제공·고난도 꼬치·하이볼·튀김·사시미·플레이팅·밥·시즌 메뉴와 대응 스테이션의 최종 콘텐츠 ID가 승인되는 순서대로 모듈식 에셋 pack을 제작한다. 후보 메뉴 이미지를 선제적으로 양산하지 않고 공정·조작 계약과 함께 완성한다.

## 보류 사유

- D4 즉시 제공 메뉴, D7 메뉴 7종과 후반 메뉴 구성 미확정
- 튀김·사시미·하이볼·플레이팅의 최종 조작·판정 계약 미확정
- D31 이후 시즌 콘텐츠의 배포 단위 미확정

메뉴·공정 레코드가 `DAT-001`의 `approved` 상태가 되고 `GPL-004`의 조작 단위가 확정된 pack부터 부분적으로 상태를 전환해 제작한다.

## 범위

### 포함

- `FD-INSTANT-*`, `FD-SKEWER-ADV-*`, `FD-HIGHBALL-*`, `FD-FRIED-*`, `FD-SASHIMI-*`, `FD-RICE-*`, `FD-SEASON-*`
- 메뉴별 재료·도구 GLB, 재질, 주문 icon, plated visual과 노트 illustration
- `ST-INSTANT-SERVE`, `ST-FRYER`, `ST-SASHIMI`, `ST-PLATING`, `ST-HIGHBALL`
- fryer basket·기름 surface, 칼·slice guide, garnish·plate anchor, 얼음·jigger·soda tap 등 공정 조작물
- 커플·관광객·취객 등 승인된 P2 손님 전용 소품·반응
- 계절 외관·노렌·날씨 overlay와 D31 이후 선택 연출
- 메뉴·공정·스테이션별 runtime pack과 manifest·카탈로그·provenance

### 제외

- 승인되지 않은 후보 메뉴의 최종 에셋 양산
- 실제 조리 로직·물리·액체·직원 자동화 구현
- 사진 모드·마케팅 이미지처럼 게임 완료와 무관한 결과물

## 작업 절차

1. 승인된 메뉴 ID, 공정 ID, 필요한 station과 조작 단계가 모두 연결됐는지 확인한다.
2. P0 닭·대파·꼬치·도구·UI atlas를 재사용할 수 있는 항목과 신규 모듈을 분리한다.
3. 메뉴마다 재료·도구 GLB, material, order icon, plated visual과 note illustration의 묶음을 정의한다.
4. station 몸체와 조작물·interaction anchor를 분리해 장비 성장이나 메뉴 추가에 재사용하고, 모든 station 몸체는 고정 카운터 앞 `playerWorkBounds`에 접속한다.
5. 튀김 상태, 사시미 slice, 하이볼 액체처럼 연속 수치는 셰이더·mask로 표현하고 상태 이미지를 과다 복제하지 않는다.
6. 각 pack의 triangle·texture·atlas·전송 예산과 LOW 대체를 검수한다.
7. P2 손님·계절 overlay는 캠페인 필수 pack과 분리하고 미사용 시 초기 다운로드에 포함하지 않는다.
8. 승인 산출물의 메뉴·공정·station ID, runtime/source/provenance 경로와 SHA-256을 manifest·카탈로그에 기록한다.

## 의존성과 인계 조건

- 선행 작업: Artist 작업 001, 작업 003 `v2.0.1`, 작업 005 `v2.0.1` 완료 및 메뉴·공정·시즌 콘텐츠의 `approved` 결정
- 후속 작업: Artist 작업 008, 개발자의 후속 station·메뉴 콘텐츠 연결
- 다른 역할에게 제공할 입력·출력: 개발자에게 메뉴·공정·station별 GLB node, texture, icon, VFX, `barCounter` 접속·`playerWorkBounds` anchor와 pack 경로를 인계한다.

## 완료 기준

- [ ] 전체 캠페인에서 `approved`된 모든 메뉴·공정에 누락 없는 에셋 묶음이 있다.
- [ ] 즉시 제공·튀김·사시미·플레이팅·하이볼 station이 공정별 anchor·도구를 가진다.
- [ ] 모든 후속 station이 셰프측 카메라와 고정 카운터를 유지하며 손님 없는 독립 테이블 장면을 요구하지 않는다.
- [ ] 공통 재료·도구·UI를 메뉴별로 복제하지 않는다.
- [ ] 연속 조리 상태가 불필요한 raster 상태 폭증 없이 표현된다.
- [ ] P2·시즌 에셋이 필수 캠페인 pack과 분리된다.
- [ ] 모든 pack이 triangle·texture·전송·LOW 모드 예산을 만족한다.
- [ ] runtime/source/provenance 경로, 콘텐츠 연결과 SHA-256이 manifest·카탈로그에 기록된다.
- [ ] 미승인 후보는 runtime 파일 없이 `blocked` 상태와 해제 조건만 카탈로그에 남는다.
