## 2026-08-23 ART-004 변경 확인 범위

- 사용자 승인·승격이 끝난 D2 모모 slice는 완료 증빙으로 보존하고 자동 재제작하지 않는다.
- 남은 D3 꼬치 음식은 `109×494` 원본, 중심축 `x=54`, 조립 완료와 `raw` 파일 공유, 다섯 익힘 PNG, `256×256` 공통 아이콘과 `1000×600` 제공 접시 계약을 적용한다.
- shader-only·중복 GLB 금지라는 과거 전제보다 실제 승인된 단계별 PNG 계약을 우선한다. 타레·토치 VFX는 음식 상태 PNG와 분리하고 도메인 판정을 소유하지 않는다.
- 새 꼬치 메뉴의 서로 다른 최종 PNG 수는 재료 수가 `N`일 때 `N+8장`이며 앞뒤 전용 PNG를 추가하지 않는다.
- Artist 1은 D3 제작 전에 위 변경 범위를 확인하고, 확인 뒤 상태를 다시 `진행 중`으로 갱신한다.

## 2026-08-10 D2 모모 R1 최종 승인

- 사용자 D2 완성 지시에 따라 `art-workspace/review/artist-026/d2-momo/r1/`에 조립 0~5,
  raw·cooking·proper·overcooked·burnt, 주문 아이콘, 손님 제공 접시를 제작했다.
- D1에서 사용자가 승인한 단계별 raster 교체 방식을 D2에도 유지한다. 문서의 구형 shader-only 요구보다
  실제 승인된 D1 소비 계약과 사용자 지시를 우선한다.
- 109×494 동일 앵커를 app의 실제 조립대·그릴 두 슬롯에 연결했고 Chromium 720/FHD에서 검증했다.
- 2026-08-10 사용자 최종 승인을 기록하고 `D2-MOMO-RUNTIME-SET@R1-B1`으로 manifest에 승격했다.
  D2 모모 slice는 완료됐으며 D3 타레 slice는 계속 남아 있다.

## D3 타레 변경 영향

- Developer 1 작업 014의 새 계약에 따라 `미적용→도포→재가열→반복 도포 적정→과열` 음식 표면 상태를 제작물별로 구분한다.
- 기존 필수 토치 결과만을 전제로 한 상태 묶음은 폐기하고, 토치 없는 적정 타레와 선택적 불향 보너스를 서로 다른 상태로 제공한다.
