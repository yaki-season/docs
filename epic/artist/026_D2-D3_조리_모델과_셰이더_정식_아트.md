## 목표

D1에서 승인한 꼬치·재료·양면 접촉 조리와 shader 파생 방식을 유지해 D2 모모와 D3 타레 음식
표면 상태를 제작하고, Artist 3 작업 024가 서비스·이야기·정산 화면에 읽기 전용으로 합성할
stable asset ID와 finalizer handoff를 제공한다.

## 범위

### 포함

- D2 모모 조립·생·첫 면/둘째 면 익는 중·적정·과다·탄 상태의 조합과 shader
- D3 타레 미적용·적정·과다의 음식 표면 mask와 양면 접촉 조리 조합
- 처음부터 고정 6칸인 그릴의 D2·D3 음식 접촉면·방향·면별 누적 시간 시각 검수
- 승인 그릴 master의 3/4 상부 station 카메라에서 raw·익는 중·proper·overcooked·burnt와
  타레 상태의 부피·외곽·숯불 반사광·색 관계 검수
- FHD/720 소비 화면 재조립, provenance, 최적화, 최종 승인과 runtime handoff

## 작업 절차

1. 작업 000을 완료한 뒤 개발자 1 작업 010과 개발자 3 작업 005의 날짜별 recipe/state ID를 인수한다.
2. 작업 000의 승인 모델·재질·camera를 읽기 전용 source로 고정하고 신규 stable ID의 owner를 기록한다.
3. 모모와 타레 상태를 독립 raster가 아닌 기존 조합·domain time·shader mask에서 파생한다.
4. checkerboard는 모델·node·재질 중간 증빙으로만 쓰고, 각 새 revision은 승인 master-derived base의
   실제 slot/tray 위치에 한 상태만 합성해 FHD/720 station 소비 승인을 먼저 받는다.
5. proper의 밝은 회갈색 속살·절제된 sear·익은 녹색, 음식 부피·잉크 외곽·숯불 반사광을
   `ART-003 v5.9.0` 기준으로 raw부터 burnt까지 같은 카메라에서 비교한다.
6. 상태별 station 소비 승인 뒤 최적화·최종 승인·finalizer handoff를 만든다.
7. 개발자 2가 동일 state ID placeholder를 교체하면 개발자 1 작업 010의 저장 복구·교차 관리 회귀를 확인한다.
