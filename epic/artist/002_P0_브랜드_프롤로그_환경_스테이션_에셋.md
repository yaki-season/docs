## 목표

S0 프롤로그부터 D1 정산까지 가게와 작업 공간이 완전하게 보이도록 브랜드, 외관, 이야기 소품과 함께 바 안쪽 플레이어가 고정 카운터 너머 손님을 바라보는 6석 내부 및 조립·그릴·드링크·서빙·정리 스테이션의 P0 래스터 에셋을 제작·승인한다.

## 범위

### 포함

- `BR-LOGO-HORIZONTAL`, `BR-LOGO-COMPACT`
- `BG-EXTERIOR-S0-CLOSED`, `BG-EXTERIOR-S1-OPEN`
- `PR-SHOP-KEY`, `PR-NOREN-S0`, `PR-RECIPE-NOTE-CORE`, `PR-CHARCOAL-IGNITION`, `PR-MATCHBOX-OLD`
- `BG-INTERIOR-BASE`, `BG-FOREGROUND-FRAME`, 손님측 `BG-SEATING-6`, 고정 상판 `BG-BAR-COUNTER-BASE`
- `ST-ASSEMBLY-TIER-1`, `ST-GRILL-TIER-1`, `ST-CHARCOAL-CORE`, `ST-DRINK-BEER-TIER-1`, `ST-SERVICE-COUNTER`, `ST-CLEANUP-OVERLAY`
- `PR-SERVING-PLATE` 재사용 검수 또는 교체
- PC·모바일 crop, HUD 안전 영역과 anchor metadata 제작
- 승인 결과의 manifest·카탈로그·provenance 동시 갱신

### 제외

- 캐릭터, 음식 GLB, UI icon과 VFX atlas
- 8·12석, 4·6칸 그릴과 S3 이후 환경 변화
- 생성 이미지에 문자를 그대로 맡기는 로고·간판 제작

## 작업 절차

1. Artist 작업 001의 ID·pack·카탈로그 계약과 `ART-002`의 팔레트·광원을 확인한다.
2. 사람이 문자 정확도를 검수할 수 있는 레이어로 두 로고와 `とり暦` 표식을 제작한다.
3. 같은 골목 구도로 S0 폐점과 S1 영업 외관을 제작하고 점등·노렌·반사 외 구조가 튀지 않게 맞춘다.
4. 열쇠, 노렌, 레시피 노트 5상태, 숯 점화와 성냥갑을 프롤로그 입력·이야기 상태에 맞춰 제작한다.
5. 기존 내부 배경·전경·조립대·그릴·숯·서빙대·접시를 셰프측 기준 화면에 합성해 재사용 또는 교체를 결정한다.
6. `BG-SEATING-6`에서 결합 카운터와 플레이어 앞 완전한 스툴을 제거하고, 손님측 좌석 layer와 `BG-BAR-COUNTER-BASE`를 별도 에셋으로 제작한다.
7. 신규 생맥주 스테이션과 모든 P0 작업대는 고정 상판 앞 플레이어측 하단에 접지하고, 손님·카운터가 사라지는 독립 테이블 합성을 만들지 않는다.
8. 각 배경·스테이션에 HUD 안전 영역, 좌석·작업·tray·잔·주문 mat anchor뿐 아니라 `barCounterBounds`, `customerOcclusionLine`, `playerWorkBounds`, `handoffPath`를 정규화 좌표로 작성한다.
9. 1280x720, 1920x1080과 기준 모바일 가로 합성에서 셰프측 시점·카운터 연속성·손님 가림·크롭·문자 오류·투명 경계를 검수한다.
10. 승인 파일을 P0 core·S0-D1 pack에 넣고 manifest, 카탈로그와 provenance에 실제 경로·해시·사용 화면을 기록한다.

## 의존성과 인계 조건
