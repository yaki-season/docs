## 목표

S0의 열쇠·대문·숯 점화와 이야기 화면을 `YS-HANDCRAFTED-NIGHT-v1` 정식 아트로 제작·승인·분리하고,
최초 공개 빌드에서 S0 placeholder를 0개로 만든다.

## 사용자 확정 실행 조건

- S0는 `열쇠 선택 → 대문 열기 → 숯 점화` 세 단계의 무실패 클릭 장면이다.
- 주인공 아사노 아키의 이야기 초상은 표시하지만 상호작용 화면에는 신체 부위를 표시하지 않는다.
- 아키는 29세, 짧은 흑갈색 머리·피곤한 눈매·마른 체형·걷어 올린 셔츠·짙은 남색 앞치마다.
- S0는 D1과 함께 최초 공개되며 사용자 노출 placeholder를 허용하지 않는다.

## 작업 절차

1. S0 화면별 topology·카메라·클릭 안전 영역을 문서와 개발자 2 인계에서 확인한다.
2. 통합 master를 한 장씩 사용자 승인받고 임의의 다음 장면을 병행 생성하지 않는다.
3. 승인 master에서 배경·대문·열쇠·숯 상태·초상을 분리한다.
4. checkerboard·FHD/720 재조립·alpha·해시·anchor를 검증한다.
5. finalizer와 runtime handoff를 만들고 개발자 2 작업 004·006에 인계한다.
