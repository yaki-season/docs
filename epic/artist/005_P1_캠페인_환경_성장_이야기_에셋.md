## 목표

S0의 꺼진 가게가 S7의 관리된 활기와 D31의 다음 영업으로 이어지는 캠페인 변화를 배경·좌석·그릴·직원 흔적·노트와 성장 UI로 표현하고, 전체 배경을 중복 제작하지 않는 단계별 pack을 완성한다.

## 범위

### 포함

- `BG-EXT-S3`, `BG-EXT-S4`, `BG-EXT-S5`, `BG-EXT-S6`, `BG-EXT-S7` 환경 overlay
- `BG-INT-SEATS-8`, `BG-INT-SEATS-12`와 desktop·mobile anchor
- `ST-GRILL-TIER-2`, `ST-GRILL-TIER-3`, `ST-STAFF-OVERLAY`
- `UI-UPGRADE-*`, `UI-NOTE-*`, `UI-STAFF-*` icon군
- `PR-NOTE-STAGE-*`, `PR-REGULAR-MEMENTO-*`, `BG-SETTLEMENT-*`, `BG-D31-*`
- S0~S7 pack 경계, 지연 로드와 texture dispose를 고려한 파일 구성
- manifest·카탈로그·provenance와 단계별 사용 날짜 기록

### 제외

- 하루·카나모리·일반 손님 캐릭터 본체
- 후속 메뉴·튀김·사시미·하이볼 스테이션
- 가격·레벨·대사·메뉴판 문구를 이미지에 굽는 작업

## 작업 절차

1. 작업 002가 `ART-003 v2.0.0`으로 재승인한 S0·S1 외관과 셰프측 내부 소실점·광원·고정 카운터·pixel density를 기준으로 고정한다.
2. S3 행인·자전거·우산, S4 화분·메뉴판·단골 흔적, S5 대기 손님·직원 흔적, S6 확장 좌석 빛·예약, S7 관리된 활기를 독립 overlay로 제작한다.
3. 기본 내부와 호환되는 손님측 8석·12석 layer와 각 좌석·주문·캐릭터 anchor를 desktop·mobile로 작성하며 고정 상판을 중복 포함하거나 플레이어 앞에 완전한 스툴을 그리지 않는다.
4. 기존 그릴과 같은 interaction 슬롯 계약을 유지하는 4칸·6칸 변형을 제작한다.
5. 직원 동선·접시·잔을 위한 투명 overlay와 anchor를 제작하되 직원 본체와 합치지 않는다.
6. 업그레이드·노트·직원 icon과 S0~S7 노트 page overlay를 수치·대사 없는 상태로 제작한다.
7. 성냥갑, 예약 메모, 사진 허락 표식 등 이야기 소품을 story flag ID와 연결한다.
8. 마감·정산과 D31은 새 대형 배경보다 gameplay 배경+작은 overlay 재조합을 우선한다.
9. 단계별 pack byte·텍스처 메모리·동시 활성 layer를 측정하고 runtime/source/provenance 경로를 manifest·카탈로그에 기록한다.

## 의존성과 인계 조건

- 선행 작업: Artist 작업 001 완료, Artist 작업 002 `v2.0.1`의 교정된 6석·`BG-BAR-COUNTER-BASE`·셰프측 crop metadata 승인 및 작업 완료
- 후속 작업: Artist 작업 006·008, 개발자의 성장·캠페인 장면 구현
- 다른 역할에게 제공할 입력·출력: 개발자에게 캠페인 단계·날짜별 배경/overlay ID, 고정 카운터와 호환되는 seat·grill tier anchor, crop metadata와 성장 UI icon 경로를 인계한다.

## 완료 기준

- [ ] S0, S1, S3, S4, S5, S6, S7이 같은 가게의 점진적 변화로 읽힌다.
- [ ] 6·8·12석과 2·4·6칸 그릴이 동일한 ID·anchor 규칙으로 교체된다.
- [ ] 6·8·12석 모두 고정 카운터 뒤 손님측에 있고 셰프측 카메라와 플레이어측 작업 bounds를 바꾸지 않는다.
- [ ] 12석 D30 합성에서 주요 인물·주문·경고가 가려지지 않는다.
- [ ] 성장·노트·직원 icon이 가격·레벨·대사에 종속되지 않는다.
- [ ] 노트와 이야기 소품이 `SCN-002`의 단계·flag와 연결된다.
- [ ] 단계별 pack이 필요 날짜 전에 로드되고 사용 뒤 해제 가능한 단위다.
- [ ] 모든 runtime/source/provenance 경로, pack, 사용 날짜와 SHA-256이 manifest·카탈로그에 기록된다.
- [ ] 전체 배경 중복으로 `SYS-003` 텍스처·초기 로드 예산을 넘지 않는다.
