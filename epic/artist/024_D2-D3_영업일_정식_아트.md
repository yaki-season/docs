## 목표

기능 우선으로 공개되는 D2·D3의 손님·서비스·상태 신호·이야기·정산 placeholder를 날짜별 승인
아트로 순차 교체한다. D2·D3 음식 모델과 shader 상태는 Artist 1 작업 026이 맡으며 이 작업은
그 stable ID를 읽기 전용으로 합성한다.

## 사용자 확정 실행 조건

- D2·D3는 기능이 완성되면 placeholder가 남아 있어도 먼저 공개할 수 있다.
- placeholder는 구형·유사 상태가 아니라 명시적 개발 도형·라벨이다.
- 승인 아트는 gameplay 상태 ID를 바꾸지 않고 교체 적용한다.
- 조립·그릴·드링크 화면에는 플레이어 신체 부위를 표시하지 않는다.

## 작업 절차

1. 개발자 2 작업 004·005의 현 placeholder inventory를 먼저 받고, 개발자 1 작업 010이 날짜별
   stable state/component ID를 고정할 때 같은 표를 증분 갱신한다.
2. 날짜별 사용자 노출 우선순위로 master·상태를 하나씩 승인받는다.
3. Artist 1·2 승인 에셋을 읽기 전용으로 재사용할 상태와 Artist 3 신규 제작 상태를 분리한다.
4. 타레·위험·완료 상태를 색 외 형태·질감·아이콘으로 구별한다.
5. 승인 에셋을 분리·재조립·검증하고 runtime handoff로 전달한다.
6. 교체 뒤 남은 placeholder 목록을 자동·수동으로 대조한다.

## 2026-08-23 ART-004 변경 확인 범위

- 2026-08-10까지 사용자 승인된 D2 서비스 slice는 완료 증빙으로 보존하고 자동 폐기·재제작하지 않는다.
- 앞으로 제작하거나 교체하는 D3 좌석 인물은 FHD 투명 캔버스, `seatHipAnchor`, 인물별 키·체형 다양성, 정면 착석과 기본 상태의 손·팔·팔꿈치 비접촉 계약을 적용한다.

- D3 음식·음료 합성은 `ART-004`에 규격이 있는 자산만 그대로 소비하고, 양배추 등 승인 화면이 없는 음식은 전체 화면 콘셉트 승인 전 제작하지 않는다.
- Artist 3는 남은 D3 제작 전에 위 변경 범위를 확인하고, 확인 뒤 상태를 다시 `진행 중`으로 갱신한다.
