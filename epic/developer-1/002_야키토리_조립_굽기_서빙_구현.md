## 목표

플레이스홀더 또는 기존 에셋을 사용해도 좋으나, PC 웹의 마우스 클릭으로 네기마 한 주문을 조립하고 양면을 구워 손님에게 서빙한 뒤 다시 시작할 수 있는 완전한 기능 흐름을 구현한다.

## 범위

### 포함

- 주문표, 재료통, 조립 꼬치와 단계별 자동 배치
- 잘못된 재료 피드백과 조립 완료 전달
- 그릴 배치, 면별 시간, 적정·과다·탄 상태, 뒤집기와 접시 회수
- 접시 선택, 손님 주문 매트 서빙, 품질 반응과 다시 하기
- 조립·그릴·카운터 화면과 자동·수동 공정 이동
- 마우스 클릭 입력, 최소 클릭 영역과 연속 클릭 방어
- 핵심 종단 흐름의 브라우저 자동 테스트

### 제외

- 최종 픽셀 아트 제작과 세부 시각 폴리시
- 생맥주, 추가 메뉴와 복수 주문
- 스테이지 목표, 점수, 경제, 저장과 이야기
- 모바일 브라우저, 터치 입력과 모바일 뷰포트 대응

## 작업 절차

1. 작업 001의 상태 모델을 조립·그릴·카운터 화면에 연결한다.
2. 주문 순서와 현재 재료를 표시하고 재료 클릭의 성공·오류 피드백을 구현한다.
3. 조립 완료 꼬치의 전달과 그릴 자동 배치를 구현한다.
4. 면별 시각 상태, 적정 신호, 너무 이른 클릭, 뒤집기, 과다와 탄 실패를 연결한다.
5. 접시 회수, 접시 선택, 손님 주문 매트 서빙과 결과 반응을 구현한다.
6. 다시 하기로 모든 화면과 상태가 초기화되는지 연결한다.
7. 두 데스크톱 검증 뷰포트에 레이아웃과 최소 클릭 영역을 적용한다.
8. 정상 흐름, 오류 흐름과 빠른 이중 클릭 종단 테스트를 작성한다.
