## 배경(확인된 개발 갭)

1. 배치 메커니즘(`src/render/cookStations.js` `createCookStations({slots, initialBatchSize})`의
   staged → 동시 시작)은 개수 무관하게 파라미터화돼 있으나, D1 첫 손님 슬라이스 `src/d1-game.js`는
   `createD1CookStations()` = `createCookStations({slots:6, initialBatchSize:3})`(고정 6칸·batch 3),
   `SLOT_KEYS=D1_GRILL_SLOT_KEYS`(6칸), 힌트 "첫 3개 동시 시작"(`d1-game.js:689-690`) 하드코딩으로
   확정 규격(네기마 2개·시작 2칸)에 미이관이다. 가변 슬롯 리팩터는 `game.js`만 이관했다.
2. 화면 가이드가 순차 단계 가이드가 아니다. `d1-game.js` `guideText()`→`#guide`는 현재 view 상태에
   따른 **한 줄 맥락 안내**이고, 전 과정 순서(주문 접수→조립→그릴 2개 동시→뒤집기→회수→제공)를
   플레이어가 화면에서 인지할 수 있는 **순차 단계 가이드가 없다**. 순차 step-list는 정산 단계에만 있다.

## 목표

D1 첫 손님 슬라이스를 명성 해금 가변 시작 2칸·네기마 2개 batch로 이관하고, 처음 플레이하는
사용자가 화면만 보고 첫 주문 전 과정을 순서대로 완주할 수 있는 **순차 사용자 가이드**를 함께
구현한다. 가이드는 매 순간 "현재 단계와 다음에 할 행동"을 색이 아니라 형태·텍스트로 인지시킨다.

## 범위

### 포함

#### A. 배치·튜토리얼 배선

- `src/d1-game.js`: `createD1CookStations()`(6/3) → 개발자 3 작업 012 계약 값 기반
  `createCookStations({slots: 시작 2, initialBatchSize: 2})` 배선(명성 해금 가변 칸 포함)
- 그릴 geometry: 고정 6칸(`D1_GRILL_SLOTS`/`D1_GRILL_SLOT_KEYS`) → 가변 시작 2칸
  (`screenLayout.computeGrillSlots`/`GRILL_SLOT_KEYS`)과 해금 시 재배치
- 하드코딩 3/6 잔재 제거(힌트 문구·주석 `game.js:33` 포함)

#### B. 순차 사용자 가이드

- 첫 주문 진행 도메인 모델을 view에 제공: `firstOrderGuide`(전체 단계 목록, 각 단계의
  완료/현재/대기, 현재 화면과의 대응, 다음 행동 문구)
- 상시 표시 순차 단계 가이드 UI: 주문 접수 뒤 생맥주 제조와 네기마 조립·완성 꼬치 트레이 이동 ×2 → 그릴 2칸 동시 시작 → 뒤집기 → 완성품 회수를 안내한다. 주문된 생맥주·네기마 중 먼저 준비된 항목부터 제공할 수 있고, 제공 가능 항목이 생기면 현재 공정 사이에 제공 방법 단계를 삽입한다. 현재 단계 highlight·완료 체크·다음 행동을 명시한다.
  기존 `guideText` 한 줄 맥락 안내를 이 순차 진행 표시로 확장한다.
- 화면 전환(손님/조립/그릴/드링크)에서도 같은 가이드가 일관되게 현재 단계를 가리킨다.
- 필수 단계 목록·현재 단계·다음 행동은 초보 보조 토글과 별개로 상시 표시한다. `tutorialPolicy`의
  `guidanceLevel`·`helpCanBeReenabled`·`no-failure`는 손 모양·대상 강조·시범 같은 추가 보조에만 적용한다.
- 두 꼬치가 동시에 뒤집기·회수 가능한 경우 준비 시각 우선·동률이면 낮은 슬롯 번호 하나만 현재 대상으로 삼는다.
- 제공 단계는 완성품 카드·대상 손님·`1개만 제공`/`다 주기` 버튼을 색 외 테두리·형태·문구로 시각화하며 주문 line 순서를 입력 허용 조건으로 사용하지 않는다.
- 3회 무효 입력의 현재 단계 자동 완료는 초보 보조 토글과 무관한 `no-failure` 복구로 적용한다.
- 접근성(UI-002 v7.2.0): 색 외 형태·아이콘·텍스트 구별, FHD/720 겹침·잘림 없음, 무음 인지.

## 작업 절차

1. 개발자 3 작업 012의 계약 값(placementCount 2, placementSlots [1,2], 시작 2칸)을 수신한다.
2. `d1-game.js` 조리 스테이션을 시작 2칸·`initialBatchSize=2`로 배선하고 그릴 geometry를 가변화한다.
3. 첫 주문 단계 진행 도메인 모델 `firstOrderGuide`를 view에 제공한다.
4. 상시 순차 가이드 UI를 구현하고 `guideText` 한 줄 안내를 단계 진행 표시로 확장한다.
5. 하드코딩 개수를 데이터/모델 값으로 교체하고 도움 토글·재활성·접근성을 연결한다.
6. 첫 손님 완주 경로를 생맥주 선제공·네기마 선제공 두 분기로 나눠, 가이드만 보고 주문→조립·트레이 이동×2→그릴 2개 동시→뒤집기→회수와 준비 순서 자유 제공을 FHD/720 E2E로 검증한다.

  다음에 뭘 해야 하는지 알 수 있으며**, 뒤집기·제공까지 막힘 없이 완주하는지 사용자가 직접 확인한다.
