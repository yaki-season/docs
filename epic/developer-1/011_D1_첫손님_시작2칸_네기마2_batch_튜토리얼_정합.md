## 2026-08-09 사용자 확정 변경

1. 기존 `두 꼬치를 모두 올려야 굽기 시작` 규칙을 폐기한다.
2. 첫 꼬치는 1번 칸에 놓이는 즉시, 둘째 꼬치는 2번 칸에 놓이는 즉시 자기 앞면 조리를 시작한다. 배치·면별 누적 시간·뒤집기·회수·품질 판정은 꼬치별로 완전히 독립한다.
3. 튜토리얼은 실제 영업과 분리된 화면별 비플레이 온보딩 UI로 다시 설계한다. 이 태스크에서는 새 온보딩을 개발하지 않는다.
4. 현행 인게임 가이드의 제거·대체는 후속 작업이다. 이번 변경에서는 동시 시작을 전제로 한 문구와 진행 조건만 독립 조리 규칙에 맞춘다.

## 배경

- 기존 D1은 `initialBatchSize=2`로 첫 꼬치를 `staged/contactFace=null`에 멈춘 뒤 둘째 꼬치가 놓일 때 두 타이머를 같은 시각에 시작했다.
- 공개 런타임 계약도 `timerStartPolicy=afterInitialBatchPlaced`, `startPolicy=simultaneous`와 같은 시작 시각을 요구했다.
- 구형 저장에는 첫 꼬치가 `staged`로 남아 있을 수 있으므로 새 규칙으로 복구하지 않으면 이어하기에서 계속 멈춘다.
- 기존 순차 가이드 구현과 검증 이력은 보존하되, 실제 영업 위에 겹치는 튜토리얼이라는 제품 방향은 이번 사용자 결정으로 폐기 예정이다.

## 범위

### 포함

- `createCookStations`의 첫 batch 대기·동시 시작 상태와 `initialBatchSize` 설정 제거
- D1 두 칸에서 각 꼬치가 자기 배치 시각에 `active/contactFace=front`로 시작
- 서로 다른 배치 시각이 각 슬롯의 면별 누적 시간에 독립적으로 반영되는 회귀 검증
- 구형 `staged` 저장을 이어하기 시 앞면 조리 상태로 승격하는 호환 처리
- 공개 D1 런타임 계약을 `placementState=active`, `timerStartPolicy=onEachPlacement`, `startPolicy=independent`로 변경
- 동시 시작을 전제로 한 현행 힌트·가이드 문구와 테스트 정정
- 관련 gameplay/data/UI/art spec 및 작업 현황 정합

### 제외

- `SCR-SYS-ONBOARDING` 화면, 목차, 시범, 이전·다음·나가기 동선 구현
- 현행 인게임 가이드 전체 제거와 온보딩으로의 교체
- 그릴 아트·레이아웃·익힘 단계 색상 변경
- 첫 주문 수량(네기마 2개·생맥주 1잔), 시작 2칸·최대 8칸 정책 변경

## 작업 절차

1. 기획·데이터·UI spec에서 동시 시작 규칙을 독립 시작으로 바꾸고 분리형 온보딩을 후속 설계로 기록한다.
2. 조리 도메인에서 batch staging을 제거하고 모든 배치가 즉시 앞면 접촉으로 시작하게 한다.
3. 구형 `staged` 저장 복구와 슬롯별 시차 배치 회귀 테스트를 추가한다.
4. 공개 런타임 계약·fixture·현행 문구를 새 정책에 맞춘다.
5. `src/d1-game.html`에서 첫 꼬치가 둘째 꼬치를 기다리지 않고 익으며, 둘째 꼬치가 나중에 독립 시작하는지 검증한다.

## 사람 화면 gate

- 첫 꼬치만 올려도 즉시 익힘 외형 변화가 시작되고, 둘째 꼬치를 나중에 올려도 첫 꼬치의 진행이 초기화되거나 맞춰지지 않는지 확인한다.
- 각 꼬치를 서로 다른 시점에 뒤집고 회수해도 다른 슬롯의 방향·시간·품질·재고가 바뀌지 않는지 확인한다.
- 화면별 비플레이 온보딩 자체는 이번 사람 화면 gate 대상이 아니다.
