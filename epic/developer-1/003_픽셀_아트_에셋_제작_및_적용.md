## 목표

기준 콘셉트아트를 바탕으로 프로토타입에 필요한 픽셀 아트 에셋을 제작하고, 조립·굽기·서빙의 모든 상태에 실제 적용해 에셋 누락 없이 일관된 플레이 화면을 완성한다.

## 범위

### 포함

- `ART-001` 최소 에셋 목록의 제작 또는 기존 에셋 보완
- 조립 0~5단계, 조리 5상태, 접시·주문 매트와 손님 반응 적용
- 조립·그릴·카운터 배경과 최소 VFX 적용
- 투명 경계, 최근접 보간, 정수 배율, 파일 크기와 로딩 경로 정리
- 실제 화면에서 콘셉트 스타일과 데스크톱 가독성 검수
- 에셋 목록과 경로 문서화

### 제외

- 콘셉트 시트 전체를 런타임 이미지로 사용하는 임시 처리
- 생맥주, 추가 메뉴, 복수 손님과 스테이지 배경
- 완전한 3D 모델, 리깅과 고해상도 시네마틱
- 기능 범위 변경과 새 게임 시스템 추가
- 모바일 전용 에셋과 모바일 화면 검수

## 작업 절차

1. 작업 002의 에셋 슬롯과 상태 이름을 기준으로 제작 목록과 파일명을 확정한다.
2. 기존 `app/art/skewer-negima.png`의 품질과 셰이더 호환성을 평가해 보완 또는 교체한다.
3. 콘셉트 03, 05, 06, 13, 17의 팔레트·광원·실루엣을 기준으로 배경과 독립 오브젝트를 제작한다.
4. 조립 단계와 조리 상태별 에셋 또는 셰이더 파라미터를 게임 상태에 연결한다.
5. 관통, 연기, 윤기와 불씨의 짧은 VFX를 연결하되 작업 대상을 가리지 않게 조정한다.
6. 두 데스크톱 기준 뷰포트에서 픽셀 보간, 크롭, 명도 우선순위와 재료 구분을 검수한다.
7. 사용하지 않는 중간 파일을 런타임 경로에서 분리하고 에셋 목록·출처·경로를 문서화한다.

  - `app/tests/e2e/assets.spec.js` — 404·콘솔 오류·보간·로딩 게이트 자동 검사
  - `app/README.md` — 에셋 목록, 경로, 제작 방법
- 구현 기준 spec 버전: `ART-001 v1.0.0`, `UI-001 v1.0.0`, `GPL-001 v1.0.0`
- 구현 기준 태스크 버전: `v1.0.0`
- 제작 방식: 이미지 생성 도구가 아니라 Python/Pillow 스크립트로 생성했다. 팔레트는 콘셉트
  `05`, `06`, `13`에서 추출한 값을 기준으로 삼았고, 콘셉트 시트를 축소·크롭해 쓰지 않았다.
- 검증 방법
  - `npm run verify` — 단위 31개, 종단 36개(두 뷰포트)
  - 에셋 404와 처리되지 않은 콘솔 오류를 정상 흐름 전체에서 자동 수집해 0건 확인
  - 필수 에셋 응답을 인위적으로 지연·실패시켜 로딩 게이트와 오류·재시도 화면 검증
  - 두 뷰포트 공정별 캡처 20장을 `app/captures/`에 생성해 육안 검수
- 검증 결과: `2026-07-21` 기준 전체 통과. 에셋 404 0건, 콘솔 오류 0건.
  전송 크기 약 `16KB`(목표 `5MB` 이하), 최대 한 변 `640px`(제한 `1024px` 이하).
- 구현 중 발견·수정한 결함
  - 조각 경계가 붙어 꼬치가 하나의 기둥으로 보였다. 조각마다 1px 외곽선을 넣어 분리했다.
  - 손님 3종의 표정이 구분되지 않았다. 얼굴을 키우고 눈썹·눈·입 형태를 모두 다르게 바꿨으며
    낮은 품질 반응에는 땀방울을 더해 형태만으로 구분되게 했다.
  - 배경의 1px 판자 선이 `cover` 확대에서 뭉개졌다. 배경을 `640×360`으로 키우고 넓은 면과
    부드러운 밝기 변화만 쓰도록 다시 만들었다.
  - 재료 비행 연출(480ms)이 클릭 간격보다 느려 주문표는 `조립 완료`인데 칸이 비어 보였다.
    380ms로 줄여 상태와 화면이 어긋나지 않게 했다.
  - 결과 오버레이가 화면 전체를 덮어 손님 반응이 보이지 않았다. `GPL-001 §14`에 맞춰
    하단 패널로 바꾸고, 손님 반응이 함께 보이는지 종단 테스트로 고정했다.
  - `1920×1080`에서 조작 대상이 화면 양끝으로 흩어졌다. 중앙 정렬로 묶었다.
- 남은 위험
  - 에셋은 코드로 생성한 픽셀 아트라 콘셉트 시트의 회화적 밀도에는 미치지 못한다.
    파일명 계약을 유지하므로 이후 손으로 그린 에셋으로 교체하면 코드 수정 없이 반영된다.
  - 배경은 `cover`로 늘어나 조작 대상 스프라이트와 픽셀 밀도가 완전히 같지는 않다.
    가는 디테일을 배제해 이질감을 줄였으나 정수 배율 고정은 아니다.
  - VFX는 연기·윤기·불씨·관통 스파크의 최소 구성이며 프레임 수를 늘리지 않았다.
