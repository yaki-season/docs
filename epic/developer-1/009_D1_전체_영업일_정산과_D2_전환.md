## 목표

현재 첫 손님 수직 슬라이스를 D1 전체 영업일로 확장해 추가 손님·좌석 정리·마감·정산·자동
저장과 D2 전환까지 끊김 없이 플레이할 수 있게 한다.

## 사용자 확정 실행 조건

- D1은 첫 손님 반응에서 끝나지 않고 전체 영업일을 완료한다.
- 아사노 아키와 츠키오카 세이지만 고정 인물이며 나머지 D1 손님은 이름 없는 엑스트라다.
- 조립·그릴·드링크는 클릭 기반이고 플레이어 신체 부위를 표시하지 않는다.
- 최초 공개 시 D1 사용자 노출 placeholder는 0개여야 한다.

## 범위

### 포함

- 츠키오카 완전 가이드 뒤 시간대별 엑스트라 손님 입장·주문·부분/최종 제공
- 6석·그룹·대기·자동/부분 제공과 공용 준비 목록의 프로덕션 연결
- 퇴장 좌석 3초 정리, 정리 전 재배정 금지
- 마감 시 신규 입장 중단, 남은 주문·좌석 정리와 숯불 낮추기
- 정산 5단계, 매출·팁·명성·품질·대기·이탈 집계와 성장 결과
- `day-complete` 저장 후 D2 개방과 전환

### 제외

- S0 프롤로그 화면과 이야기 UI — 개발자 2 작업 004
- D2·D3 영업 규칙과 D4 예고 — 개발자 1 작업 010
- 새 아트 제작과 승인 — Artist 작업 000·023
- 배포·전체 공개 검증 — 개발자 2 작업 006

## 작업 절차

1. 작업 005·006의 프로덕션 화면·손님 모델과 작업 000의 D1 주문·조리 상태를 연결한다.
2. D1 시간대별 손님 생성과 활성 주문·위험 공정 상한을 콘텐츠에서 읽는다.
3. 첫 손님 뒤 엑스트라 입장부터 퇴장·정리까지 전체 상태 흐름을 구현한다.
4. 마감·정산·성장 결과를 기존 영업일 집계와 연결한다.
5. 작업 008의 체크포인트에 정산 결과를 한 번만 반영하고 D2를 개방한다.
6. 모의 시간 종단과 두 기준 해상도 E2E를 추가한다.
