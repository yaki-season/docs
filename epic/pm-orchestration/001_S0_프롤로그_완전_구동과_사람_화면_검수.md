## 목표

새 게임이 정적 웹 URL에서 열쇠·대문 2클릭(KEY→GATE)과 점화 대사, 정식
이야기·건너뛰기·3줄 요약을 거쳐 D1 전체 영업으로 자연스럽게 전환되게 한다. 자동 검증뿐 아니라
사람이 실제 화면을 직접 조작한 `PASS` 증거까지 확보해 S0를 온전히 구동되는 스테이지로 닫는다.

## 범위

### 포함

- 개발자 2 작업 005와 완료 작업 009·011, 개발자 3 완료 작업 010의 실제 연결 증거 관리
- Artist 2 작업 023의 외관·KEY·GATE·`CH-AKI-STORY` 승인·승격 순서 관리
- 후보별 사용자 승인, finalizer, Developer 2 dry-run·receipt·write, exact binding, QA 재검증의 자동 인계
- Chrome·Edge, `1920×1080`·`1280×720`, 마우스·키보드의 S0 실제 화면 검수
- S0 시작·건너뛰기·요약·저장·D1 전환과 새로고침 복구의 사람 피드백 기록

### 제외

- PM의 앱 코드·아트 픽셀·manifest 직접 수정
- PM·QA의 사용자 시각 승인 대행
- 오디오 제작, 원격 플레이 기록 수집, D1 이후 영업 구현

## 병렬·순차 계획

- `ST-S0-BRAZIER`·`PR-CHARCOAL-IGNITION` lane은 2026-08-02 점화 대사 대체로 deprecated이며
  더 이상 후보·승인 cycle을 진행하지 않는다. Artist 2 S0 작업은 `CH-AKI-STORY`만 남는다.
- `CH-AKI-STORY` 소비 화면 승인 → finalizer → promotion은 순차다.
- 아키 초상이 exact binding된 뒤 S0 전체 QA와 사람 화면 테스트를 시작한다.
- S0와 D1 제작은 병렬로 진행하지만 최초 공개 gate는 PM 작업 002까지 함께 완료돼야 닫힌다.

## 현재 승인·blocker 큐

1. `ST-S0-BRAZIER cold R1`은 사용자 반려·재제출/재사용 금지다. PM이 이를 재승인
   후보로 올린 것은 오류며 해당 lane을 동결했다.
2. (2026-08-02 상위 spec-alignment로 무효화) 기존에는 올바른 화로 비주얼 방향 복구 전까지
   새 화로·점화 후보 제작을 금지했으나, 점화 대사 대체로 화로·점화 art lane 자체가 deprecated다.
   `ST-S0-BRAZIER cold R1` 반려 기록(항목 1)은 역사 기록으로 보존한다.
3. `CH-AKI-STORY`는 별도 순차 lane으로 유지한다.

## 작업 절차

1. PM 부팅 때 실제 epic·파일·SHA·테스트를 다시 확인하고 승인 큐와 실행 가능한 역할 lane을 복구한다.
2. 사용자 승인 불필요한 독립 계약은 역할 서브에이전트에게 즉시 배정한다.
3. 사용자 승인 후보는 후보 ID·revision·FHD/720 증거·고정/변경/제외 범위와 PM 권고를 한 건씩 보고한다.
4. 승인되면 Artist finalizer에서 Developer 2 promotion, exact binding, QA 재검증 순으로 자동 인계한다.
5. S0 placeholder와 오류가 0개가 되면 실제 정적 URL과 build 정보를 고정한다.
6. `template/사람_화면_플레이테스트_피드백_템플릿.md`로 사용자에게 S0 조작 테스트를 요청한다.
7. 사람 `PASS`와 자동 검증을 함께 기록하고 D1 시작 저장 전환까지 확인한 뒤 완료 처리한다.

## 사용자 승인 gate

- 아트 단품·실제 소비 화면·이야기 초상·최초 공개 시각 결과의 최종 승인자는 사용자다.
- `조건부 승인`은 수정 확인 전 최종 승인으로 바꾸지 않는다.
- 승인 전에는 해당 후보의 optimizer·finalizer·runtime promotion과 종속 후보를 진행하지 않는다.
- 승인 대기 lane만 멈추고, 충돌 없는 D1과 S0 독립 계약 lane은 계속 진행한다.

## 사람 화면 테스트

- 필수 경로: 새 게임 → 열쇠 선택 → 대문 열기 → 이야기(점화 대사 포함) → 건너뛰기/3줄 요약 →
  D1 전환 → 새로고침 복구.
- 필수 환경: 최신 Chrome·Edge, `1920×1080`·`1280×720`, 마우스·키보드.
- 필수 판정: 조작 막힘, 화면 가독성, 이야기 흐름, 무음 상태의 시각 피드백, 저장·전환을 확인한
  사용자 명시 `PASS`.
