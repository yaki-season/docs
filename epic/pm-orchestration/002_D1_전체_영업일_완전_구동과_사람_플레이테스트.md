## 목표

D1 첫 손님부터 추가 손님, 주문, 조립, 고정 6칸 양면 조리, 드링크, 선택 손님 중심 부분 제공,
좌석 정리, 마감, 정산, 저장과 D2 전환까지 실제 정적 웹 화면에서 끝까지 플레이되게 한다.
모든 사용자 노출 아트를 승인 runtime asset으로 교체하고 사람이 첫 손님과 전체 영업을 직접
플레이한 `PASS` 증거로 D1을 온전히 구동되는 스테이지로 닫는다.

## 정본 충돌 관리

- 현재 `GPL-002 v1.10.0`의 일부 예시는 생맥주 선제 제공과 구형 `2+1` 그릴 흐름을 유지한다.
  실행·검수 정본은 최신 사용자 확정과 `GPL-003 v4.12.0`, `GPL-004 v1.39.0`,
  `DAT-001 v5.23.0`의 비FIFO 선택 제공·고정 6칸·첫 네기마 3개 동시 시작이다.
- `SCN-002`·`ART-002`의 직장인 A/B 등 고정 인물 기록은 `ART-003 v5.9.0`의 아키·츠키오카 외
  이름 없는 엑스트라 정책과 충돌한다.
- PM은 위 drift를 임의로 spec 수정하지 않고 사용자에게 별도 `spec 정합 반영` 승인을 요청한다.
  충돌하는 구형 예시를 D1 완료 기준으로 사용하지 않는다.

## 병렬·순차 계획

- Artist 1 조립·그릴 음식 lane과 Artist 3 드링크·서빙·정리·엑스트라·정산 lane은 stable ID와
  쓰기 namespace가 달라 병렬이다.
- 개발자 1 gameplay/actor 계약, 개발자 2 binding/promotion, 개발자 3 회귀 감사, QA delta도
  담당 파일이 겹치지 않는 범위에서 병렬로 실행한다.
- 후보 하나의 순서는 사용자 승인 → completion/provenance/optimization/finalizer →
  개발자 2 dry-run/receipt/write/binding → 개발자 1 회귀 → QA다.
- 같은 stable ID·source master·finalizer·manifest promotion에는 동시에 한 writer만 둔다.
- placeholder 0 뒤 첫 손님 검수, 전체 영업 검수, S0와 결합한 최초 공개 검수를 순차로 수행한다.

## 작업 절차

1. 역할별 실제 증거와 사용자 승인 큐를 복구하고 독립 lane을 최대 세 개까지 병렬 배정한다.
2. 사용자 후보는 실제 FHD/720 소비 화면과 상태 구별성을 한 건씩 승인 요청한다.
3. 승인된 asset은 finalizer에서 promotion·binding·소유 회귀·QA로 자동 인계한다.
4. 조기 반복 뒤집기, 접촉면별 누적, 앞·뒤 시각 구별, 선택 손님 비FIFO 제공을 고정 회귀로 검증한다.
5. required asset과 시각 variant를 전수 감사해 placeholder·404·console 오류를 0으로 만든다.
6. 실제 정적 URL에서 첫 손님 플레이테스트를 받고 문제를 원래 owner에게 돌린다.
7. 전체 영업·정산·저장·D2 전환을 끝까지 사람에게 플레이시키고 명시적 `PASS`를 받는다.
8. PM 작업 001과 함께 최초 공개 gate를 닫고 PM 작업 003을 활성화한다.

## 사용자 승인 gate

- 아트 후보와 실제 소비 화면은 사용자가 최종 승인한다. PM·QA는 승인 권고만 한다.
- 승인 요청에는 candidate ID/revision, FHD/720 경로·SHA, 변경/고정/제외, 자동 검증, 승인 후
  자동 인계와 반려 시 수정 범위를 포함한다.
- 승인 대기 lane만 멈추며 다른 독립 lane은 계속한다.

## 사람 화면 테스트

- 중간 gate 1: 첫 손님이 주문하고 네기마 또는 생맥주 중 준비된 항목을 먼저 받을 때까지.
- 중간 gate 2: 꼬치를 임의 시점에 반복 뒤집어 면별 누적을 보충하고 앞·뒤 면을 화면에서 구별.
- 최종 gate: 추가 손님, 좌석 정리, 마감 drain, 정산, 저장, D2 전환과 새로고침 복구.
- 필수 판정: FIFO 강제 없음, 선택한 완성품→선택한 손님, 조작성·가독성·상태 구별, 전체 완주.
- PM 중간 검수는 `QA-002`의 최종 비개발자 사용성 표본을 대체하지 않는다.
