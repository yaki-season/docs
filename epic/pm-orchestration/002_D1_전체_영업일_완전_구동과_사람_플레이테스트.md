## 범위

### 포함

- 공개 `d1-game.html`의 첫 주문 실제 입력 경로
- 4명·4주문·8항목, 좌석 정리, 조기 마감, 정산·저장·D2 전환
- 13초 입장 상한과 영업창의 release data 연결
- 숨김·포커스 상실·이야기 중첩 정지
- 사용자가 실제로 보는 필수 상태의 누락·오표시는 차단하되, 내부 inventory 수치만으로 차단하지 않는 판정

### 제외

- 폐기된 순차 안내를 임시 튜토리얼로 유지
- 구형 진입점·DOM 구조·파일명을 유지하기 위한 gate
- 필수로 명시되지 않은 사람 대기를 단독 blocker로 사용

## 작업 절차

1. 영업 정책·정지·안내 제거를 공개 D1 경로에 연결한다.
2. gate 실패를 `제품 회귀|테스트 계약 낙후|환경 실패`로 분리한다.
3. 공개 진입점 첫 주문·통합 정지·release drift를 차단 gate로 실행한다.
4. 사람 플레이는 조작감·가독성 문제를 찾는 진단으로 기록하고 명시적 릴리스 판정이 아니면 다른 개발을 멈추지 않는다.
