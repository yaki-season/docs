## 목표

D3 타레와 교차 관리가 포함된 전체 영업, 정산, 저장을 끝까지 구동하고 D4의 공개 개발 중 경고와
읽기 전용 예고 화면으로 안전하게 전환한다. D4에서는 주문·보상·저장 gameplay가 변하지 않으며,
사람이 D3 전체 영업과 D4 불변식을 직접 확인한다.

## 범위

### 포함

- 개발자 1 작업 010의 D3 전체 영업과 D4-preview 연결
- 개발자 2 작업 005·006의 공개 경고·읽기 전용 shell과 통합 회귀
- 개발자 3 작업 005의 D3/D4 데이터 계약
- Artist 1 작업 026과 Artist 3 작업 024의 D3 stable pack 제작·승격
- D3 전체 영업과 D4 예고의 사람 화면 테스트

### 제외

- D4 실제 주문·조리·보상 gameplay
- 경고 확인 전 D4 노출
- D5 이후 콘텐츠, 오디오

## 병렬·순차 계획

- PM 작업 003 완료 뒤 D3 구현을 시작한다.
- D3 stable ID pack마다 Artist 1 타레 shader와 Artist 3 서비스·이야기·정산 lane을 병렬로 연다.
- D3 아트 승인·promotion 뒤 전체 영업 QA를 수행한다.
- D3 정산 저장 뒤에만 D4 경고→읽기 전용 화면 전환을 순차 검증한다.

## 작업 절차

1. D2→D3 저장 전환과 PM 작업 003 사람 `PASS`를 확인한다.
2. 개발자 1 D3 slice와 날짜별 stable ID pack을 배정한다.
3. Artist 1·3과 개발자 2 통합을 충돌 없는 lane으로 병렬 실행한다.
4. D3 전체 영업·정산·저장 회귀 뒤 사람 플레이테스트를 받는다.
5. D4 경고 확인과 읽기 전용 진입에서 주문·보상·저장이 변하지 않는지 자동·사람 검증한다.
6. D4를 공개 범위 밖 gameplay이자 공개 가능한 예고 화면으로 명시해 완료 처리한다.

## 사용자 승인 gate

- D3 아트·시나리오 소비 화면과 D4 공개 경고 화면은 사용자가 최종 승인한다.
- D4 경고 승인과 실제 D4 gameplay 개발 승인은 서로 다른 결정이다.

## 사람 화면 테스트

- D3: 타레·화면 전환 상태 보존, 전체 영업, 정산, 저장, D4 전환.
- D4: 개발 중 경고 확인, 읽기 전용 예정 콘텐츠, 주문·보상·저장 무변경, 뒤로 가기·재개.
- 필수 판정: D3 전체 완주 `PASS`와 D4 불변식 `PASS`.
