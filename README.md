# yaki-season 문서 저장소

이 저장소는 yaki-season 게임 개발을 위한 아이디어 수집, 요구사항 정의, AI 개발 지침, 개발자별 작업 분해 문서를 관리한다.

게임 개발과 운영에 필요한 소스코드, 테스트, 빌드·배포 설정은 별도 `app` 저장소에서만 관리한다.

## 디렉토리 구조

- `inbox/`: 아직 정제되지 않은 아이디어, 디자인, 아트 콘셉트, 참고자료를 보관한다.
- `spec/`: 게임 개발 요구사항을 카테고리별 디렉토리로 분류해 정의한다.
- `template/`: AI 개발 지침서와 반복 사용 가능한 문서 템플릿을 보관한다.
- `epic/`: `spec/`을 기반으로 개발자 2명이 독립적으로 수행할 작업을 순차적인 태스크 문서로 관리한다.

## 변경사항 반영 흐름

`inbox → spec → epic → app`

개발 중이나 개발 후 발견된 개선·수정사항, 버그와 모순은 `inbox/99.change-request/`에 기록한다. AI는 `template/AI_변경사항_반영_파이프라인.md`에 따라 요구사항을 갱신하고, 아직 완료되지 않은 작업에 반영하거나 새 작업을 생성한 뒤 `epic/작업_현황.md`를 동기화한다.

## 작성 원칙

- 모든 문서, 예제, 가이드, 커밋 메시지는 한국어로 작성한다.
- `inbox/`의 자료는 검토 후 `spec/`으로 승격한다.
- `epic/`의 작업은 반드시 관련 `spec/` 문서를 참조해야 한다.
- 구현과 운영은 `app` 저장소에서만 수행한다.
- 저장소 전역 AI 작업 규칙은 `AGENTS.md`를 따른다.
