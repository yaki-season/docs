# YAKI SEASON D1~D7 통합 영업일 기획 검토 초안

- 작성일: 2026-08-25
- 상태: 사용자 검토용 초안
- 목적: 초기 아이디어 문서가 아닌 현행 spec·구현을 기준으로 D1~D7의 플레이 흐름과 미확정 항목을 한곳에서 검토한다.
- 주의: 이 문서는 아직 정본 spec이 아니다. 사용자 확정 뒤 gameplay·scenario·data spec과 Epic에 반영한다.

## 1. 현재 구현 경계

- D1~D3은 실제 영업·정산·저장과 D4 예고 전환까지 구현되어 있다.
- D4는 현재 실제 영업일이 아니라 읽기 전용 개발 예고 화면이다.
- D5 토리카와는 격리된 후보 데이터와 검증 테스트만 있고, 실제 영업·UI·아트 연결은 없다.
- D6은 부채 규칙의 격리 테스트만 있고 실제 영업과 UI는 없다.
- D7은 첫 만석·그릴 4칸·츠키오카 단골화라는 시나리오 목표만 있고 실제 날짜 데이터는 없다.
- 이 초안의 우선 목표는 `D4 실제 영업 완성 → D5 토리카와 수직 슬라이스`다.

## 3. D1 — 다시 피우는 숯

### 핵심 주문

- 첫 손님: `REGULAR_TSUKIOKA`
- 고정 주문: 네기마 2개 + 생맥주 1잔
- 유효한 흐름: 주문 접수 → 생맥주 또는 네기마 준비 → 부분 서빙 → 나머지 음식 서빙 → 식사 → 퇴장 → 좌석 3초 정리
- 네기마 두 꼬치는 시작 2칸에 개별 배치하며 각자의 배치 시점부터 양면 시간이 독립적으로 흐른다.

### 이야기 결과

- 츠키오카가 첫 단골 후보가 된다.
- 모모 레시피가 복원되고 주인공은 다음 날도 영업하기로 한다.

## 4. D2 — 손의 리듬

### 핵심 변화

- 모모가 실제 조립·그릴 메뉴로 추가된다.
- D1의 강한 안내 없이 네기마·모모·생맥주를 함께 처리한다.
- A와 츠키오카가 다시 방문한다.

### 운영 의도

- 새 조작을 많이 추가하기보다, 이미 배운 조립·굽기·드링크·서빙을 혼자 연결하는 날이다.

## 5. D3 — 타레와 화면 밖 공정

### 핵심 변화

- `타레 모모`가 별도 주문명으로 등장한다.
- 플레이어가 붓을 직접 움직여 타레를 두 번 바른다.
- 타레 뒤 토치는 별도 선택 공정이며, 놓았다가 다시 잡을 수 있다.
- 그릴과 생맥주가 겹쳐 화면 밖에서도 시간이 흐르는 첫 위험을 경험한다.

### 이야기 결과

- A가 다른 사람에게 가게를 소개해도 되는지 묻는다.
- 선택은 대사와 운영 경향을 바꾸지만 진행을 막지 않는다.

## 6. D4 — 양배추 간장 사라다와 주문 우선순위

### 현재 확정 사항

- 신규 메뉴는 `양배추 간장 사라다`다.
- 조리 스테이션을 거치지 않고 공용 준비 목록에서 즉시 제공하는 메뉴다.
- 기본 레몬 하이볼 1종을 추가하며 위스키 1 : 탄산수 3 비율로 제조한다.
- S3 `퇴근길의 불빛`의 시작일이다.
- D1 이후 공통 규칙인 17:30~02:30 영업, 빈 가게 다음 손님 13초 상한, 마감·정산·저장을 유지한다.

### 제안하는 하루의 역할

- 플레이어에게 “모든 주문을 조리할 필요는 없다”는 새 판단을 가르친다.
- 즉시 제공 사라다를 먼저 내어 기다림을 줄일지, 진행 중인 꼬치를 먼저 관리할지 선택하게 한다.
- 사라다는 준비품 선택만 사용하고, 그날의 실질적인 신규 조작은 하이볼 비율 제조 하나로 제한한다.

### 구현 전에 확정할 항목

- [ ] 손님 수와 시간대별 입장 파동
- [ ] 전체 주문표와 사라다 주문 수량
- [ ] 사라다 기본 판매가와 품질 규칙
- [ ] 사라다를 무제한 즉시 제공할지, 영업 전 준비 수량을 둘지
- [ ] D4 영업 전·마감 이야기와 등장 손님
- [ ] D4 완료 보상과 D5 진입 조건

## 7. D5 — 토리카와와 좁은 굽기 구간

### 메뉴 명칭

- 사용자 표시명: `토리카와`
- 뜻: 닭껍질 꼬치
- 기존 데이터 ID `kawa`를 유지할지 `torikawa`로 이관할지는 구현 전 결정한다.
- 소금과 타레는 별도 음식명이 아니라 토리카와 주문의 양념 선택지다.

### 현재 확정 레시피·판정

- 접은 닭껍질 조각 5개를 순서대로 꿴다.
- 양념 선택: `salt | tare`
- 각 면의 누적 굽기 경계:
  - `0~9.999초`: 덜 익음 또는 익는 중
  - `10~13.999초`: 적정
  - `14~17.999초`: 과다
  - `18초 이상`: 완전 탄 상태
- 양면 판정은 네기마와 같은 공통 품질 표를 사용한다.
- 첫 토리카와 안내는 실제 적정 구간만 시각적으로 강조하고 판정 폭을 넓히지 않는다.

### 조립·굽기 제안 흐름

1. 주문에서 토리카와와 양념을 확인한다.
2. 조립 화면에서 접은 닭껍질 5개를 꼬치에 끼운다.
3. 그릴 빈 칸에 놓으면 현재 접촉면 시간만 흐른다.
4. 좁은 적정 구간을 보고 뒤집어 반대 면을 굽는다.
5. 주문이 타레라면 기존 타레 붓 공정을 재사용할지 별도 마감 방식을 둘지 확정한다.
6. 양면 결과를 합산해 완성·저품질·폐기를 결정한다.

### 이야기·보상

- D5 마감 뒤 주인공이 그릴 아래 수납에서 전대 점주의 낡은 부채를 발견한다.
- 부채는 D5 영업 중에는 사용할 수 없다.
- D5 완료 보상으로 `fan-boost`를 해금하며 D6부터 사용한다.
- 예정 효과: 모든 활성 그릴 꼬치의 현재 면을 4초 앞당김, 쿨타임 9초.

### 구현 전에 확정할 항목

- [ ] 메뉴 표시명 `토리카와`, 내부 ID `kawa|torikawa`
- [ ] 기본 판매가
- [ ] D5 손님 수·입장 파동·전체 주문표
- [ ] 소금/타레 주문 비율
- [ ] 타레 주문의 직접 붓질 적용 여부와 도포 횟수
- [ ] 토리카와 조립 입력 방식
- [ ] D5 영업 전·영업 중·마감 대사
- [ ] 토리카와 raw/cooking/proper/overcooked/burnt 및 주문·서빙 아트

## 8. D6 — 부채와 러시 예행연습

### 현재 확정 사항

- D5 완료 보상으로 해금된 `fan-boost`를 처음 사용할 수 있다.
- 부채를 사용하면 그릴 위 모든 제작물의 현재 접촉면 누적 시간이 즉시 4초 증가한다.
- 부채의 쿨타임은 9초이며 영업 일시정지 규칙을 그대로 따른다.
- 첫 사용은 효과와 과열 위험을 안전하게 안내하지만 적정 판정 구간을 넓히지 않는다.
- D6은 여러 주문이 겹치는 러시의 예행연습이다.
- A가 주인공을 처음으로 `사장님`이라고 부른다.

### 제안하는 하루의 흐름

1. 영업 전 노트에서 전날 발견한 낡은 부채의 사용법을 확인한다.
2. 한산 구간에서 네기마 또는 모모 한 꼬치로 부채를 시험한다.
3. 보통 구간에서 토리카와와 기존 꼬치가 동시에 올라가, 서로 다른 적정 구간을 비교한다.
4. 러시 구간에서 꼬치·생맥주·즉시 제공 사라다가 겹친다.
5. 부채를 무조건 누르는 것이 아니라 여러 꼬치가 함께 적정 직전에 있을 때 사용하는 판단을 학습한다.
6. 마감 뒤 A가 자연스럽게 주인공을 `사장님`이라고 부른다.

### 신규 메뉴 배치 제안

- D6의 새 행동은 부채 하나로 제한한다.
- 츠쿠네 성형이나 삼겹살말이처럼 별도 입력이 필요한 메뉴는 D6에 추가하지 않는다.
- 난코츠를 D6에 넣으려면 기존 조립·양면 굽기만 사용하는 변형 메뉴로 한정할 수 있으나, 부위·조각 수·양념·판정이 아직 미확정이므로 이번 초안에서는 보류한다.

### 구현 전에 확정할 항목

- [ ] 손님 수·입장 파동·전체 주문표
- [ ] 부채 첫 사용 온보딩의 정확한 제시 방식
- [ ] 러시 구간의 활성 주문·위험 공정 상한
- [ ] 부채 사용 시 애니메이션·바람 VFX·소리
- [ ] A의 영업 전후 대사와 `사장님` 호칭 장면
- [ ] D6 완료 보상과 D7 진입 조건

## 9. D7 — 첫 만석과 4칸 운영

### 현재 확정 사항

- 처음으로 모든 좌석이 차는 만석 장면을 보여준다.
- 그릴 4칸을 활용하는 병행 운영을 경험한다.
- 츠키오카를 단골로 등록한다.
- 츠키오카가 주문과 계절을 기록한 노트의 의미를 설명하고 가게 이름의 `暦` 의미를 공개한다.
- S3 `퇴근길의 불빛`을 마무리한다.

### 제안하는 하루의 흐름

1. 영업 전 화면에서 4칸 사용 가능 상태와 높은 예상 손님 밀도를 명확히 보여 준다.
2. 한산 구간은 기존 메뉴 복습으로 시작해 플레이어가 4칸 배치를 확인하게 한다.
3. 보통 구간에서 토리카와와 타레 모모를 섞어 굽기·붓질·드링크를 교차한다.
4. 러시 구간에서 첫 만석을 만들되 활성 주문과 위험 공정 상한을 4칸 운영 범위 안에 둔다.
5. 부채는 실수를 지우는 버튼이 아니라 여러 현재 면을 함께 앞당기는 운영 선택으로 사용한다.
6. 마지막 츠키오카 주문과 식사 뒤 단골 등록 장면으로 전환한다.
7. 마감·정산 뒤 `暦`의 의미를 공개하고 다음 스테이지를 예고한다.

### 메뉴 범위 제안

- 내일까지 구현하는 D7 초안은 D1~D5의 메뉴를 종합하는 날로 구성한다.
- 츠쿠네는 닭 완자 개수·성형 조작·노른자 제공 여부가 확정된 뒤 별도 도입일에 배치한다.
- 난코츠는 사용 부위·조각 수·양념·굽기 판정이 확정된 뒤 배치한다.
- 삼겹살말이는 아스파라거스·방울토마토·깻잎을 한 메뉴로 묶을지 세 메뉴로 나눌지와 말기 조작을 먼저 확정한다.

### 구현 전에 확정할 항목

- [ ] 4칸 해금 조건과 D7 시작 시 보장 방식
- [ ] 만석의 정확한 좌석 수와 동시 그룹 구성
- [ ] 손님 수·입장 파동·전체 주문표
- [ ] 츠키오카의 마지막 주문과 단골 등록 조건
- [ ] `暦` 의미 공개 대사와 컷씬
- [ ] S3 완료 보상과 D8 예고 범위

## 10. D4~D7 범위 충돌과 권장 정리

현행 캠페인 표는 D4~D7 사이에 양배추 간장 사라다·츠쿠네·카와·난코츠·삼겹살말이·하이볼·부채·러시·확장 슬롯을 모두 적고 있다. 그러나 같은 정본은 신규 행동을 하루에 원칙적으로 하나만 소개하도록 요구한다.

### 권장 D4~D7 확정안

| 날짜 | 새 행동 하나 | 실제 신규 메뉴 | 복습·운영 변화 |
|---|---|---|---|
| D4 | 하이볼 1:3 비율 제조 | 양배추 간장 사라다·기본 하이볼 | 즉시 제공과 기존 꼬치의 우선순위 판단 |
| D5 | 좁은 양면 굽기 | 토리카와 | 소금/타레 주문 선택 |
| D6 | 부채 | 없음 | 첫 러시 예행연습 |
| D7 | 4칸 병행 운영 | 없음 | 첫 만석·단골 등록·S3 종결 |

이 안을 사용하면 츠쿠네·난코츠·삼겹살말이는 D8 이후에 순차 도입하도록 캠페인 표를 수정해야 한다. 반대로 세 메뉴를 반드시 D7까지 넣으려면 하루 하나 원칙을 포기하거나 각 메뉴의 고유 조작을 없애야 한다. 이 초안은 손맛과 학습 가능성을 유지하기 위해 순차 도입을 권장한다.

## 11. D1~D7 공통 영업 규칙

- 영업 시간은 `17:30~다음 날 02:30`이다.
- 한산 → 보통 → 러시 → 마감의 밀도 곡선을 사용한다.
- 매장에 손님이 0명이고 다음 계획 손님이 남았으면 조건이 허용되는 한 13초 이내에 다음 손님이 도착한다.
- 스테이션을 바꿔도 그릴과 손님 시간은 흐르며, 브라우저 숨김·포커스 상실·대사·명시적 일시정지에서는 모든 시간축을 함께 멈춘다.
- 마감은 신규 입장 중단 → 남은 주문 처리 → 좌석 정리 → 숯불 낮추기 순서다.
- 정산 완료 보상은 한 번만 적용하고 다음 날짜 개방 상태를 저장한다.
- 새 행동 설명은 영업 상태를 바꾸지 않는 비플레이 온보딩에서 제공한다.
