## 2. 한 문장 조작 목표

### 야키토리

> 주문표를 보고 재료를 차례로 클릭해 꼬치를 만들고, 석쇠 위 꼬치를 적절한 순간에 클릭해 뒤집은 뒤, 접시와 손님을 차례로 선택해 낸다.

### 생맥주

> 빈 잔을 클릭해 기계에 놓고 레버의 아래 영역을 눌러 맥주를 채운 다음, 위 영역을 눌러 부드러운 거품을 올려 손님에게 건넨다.

두 조작 모두 별도 명령 버튼보다 화면 속 재료, 꼬치, 레버, 잔과 접시를 직접 클릭하는 방식을 우선한다.

## 3. 설계 원칙

### 3.1 한 번에 한 가지 의도

- 손가락을 댄 순간 플레이어가 해야 할 일은 하나여야 한다.
- 재료를 선택했으면 끼우기만 하고, 접시를 선택했으면 서빙 대상만 고른다.
- 생맥주를 따를 때 잔 각도와 레버를 동시에 조작하게 하지 않는다.
- 한 동작이 끝나기 전 별도 확인 버튼을 요구하지 않는다.
- 성공한 동작은 손을 뗀 순간 바로 다음 상태로 이어진다.

### 3.2 화면에 보이는 물건이 곧 조작 대상

- `끼우기`, `굽기`, `따르기`, `서빙` 같은 텍스트 버튼을 두지 않는다.
- 재료, 꼬치, 레버, 잔과 접시 자체를 클릭한다.
- 상호작용 가능한 물건은 포인터를 누르거나 손가락이 닿는 순간 `1.05배 들림+짧은 그림자+재질음`으로 반응한다.
- 사용할 수 없는 물건은 어둡게 비활성화하기보다 작업대 뒤로 물리거나 뚜껑을 닫아 자연스럽게 구분한다.

### 3.3 손맛은 정밀함보다 저항과 반응에서 만든다

- 작은 목표점에 정확히 포인터를 맞추도록 강요하지 않는다.
- 클릭 시 넓은 히트 영역과 자동 이동을 사용하되, 이동 애니메이션에 대상의 무게와 방향성을 보존한다.
- 재료가 꼬치에 들어갈 때 `눌림→살짝 멈춤→툭 관통`하는 0.12~0.18초의 저항을 표현한다.
- 꼬치를 뒤집을 때 직전 회전 방향 또는 일관된 기본 방향으로 180도 회전한다. 선택 입력인 스와이프에서는 손가락 방향을 반영한다.
- 생맥주 레버는 일정 거리까지 버티다가 금속 걸쇠가 풀리며 움직이는 느낌을 준다.
- 판정 팝업보다 음식의 색, 소리, 연기, 거품과 손님의 짧은 반응을 우선한다.

### 3.4 실수는 이해 가능하고 복구 가능해야 한다

- 실수 원인을 `순서가 다름`, `앞면이 덜 익음`, `너무 오래 구움`, `맥주가 너무 많음`처럼 구체적으로 보여준다.
- 첫 실수는 즉시 폐기보다 한 단계 복구를 허용한다.
- 잘못 끼운 마지막 재료는 클릭해 뽑을 수 있다.
- 덜 익은 꼬치는 다시 석쇠에 올릴 수 있다.
- 거품이 적은 생맥주는 레버 위 영역을 다시 눌러 보충할 수 있다.
- 완전히 탄 꼬치나 넘친 잔만 새로 만들도록 한다.

### 3.5 작업 중 UI가 손을 가리지 않게 한다

- 핵심 조작 영역은 화면 중앙 아래 70%에 둔다.
- 주문표는 상단, 스테이션 탭은 하단 가장자리, 화면 밖 경고는 좌우 가장자리에 둔다.
- 손가락 아래에 숫자나 설명을 표시하지 않는다.
- 모바일에서 선택한 대상의 예상 도착점은 손가락보다 12~20px 위에 표시해 가림을 줄인다.

### 3.6 웹 우선, 모바일 동일 의미

- 1차 입력은 `클릭`이며 hover, 우클릭, 휠과 키보드 단축키를 필수로 사용하지 않는다.
- PC에서 한 번 클릭하는 행동은 모바일에서 한 번 탭하는 행동과 같은 결과를 낸다.
- PC의 마우스 누르기·떼기는 모바일의 한 손가락 홀드·릴리스와 같은 결과를 낸다.
- 드래그와 스와이프는 숙련자가 빠르게 조작할 수 있는 선택 입력으로만 남긴다.
- 클릭만으로 주문 수락부터 조리·서빙까지 모든 핵심 흐름을 끝낼 수 있어야 한다.
- 선택된 물건은 외곽선, 살짝 들림과 커서 아이콘으로 표시해 hover가 없어도 상태를 알 수 있게 한다.
- 브라우저 기본 텍스트 선택, 이미지 끌기와 컨텍스트 메뉴가 조리 영역에서 발생하지 않도록 고려한다.
- 모바일 한 손 모드는 모든 필수 조작 대상을 선택한 손 쪽 하단 `70%` 안전 영역에 모으고 왼손·오른손 배치를 반전할 수 있게 한다.

## 4. 공통 입력 문법

| 입력 | 의미 | 사용처 | 사용하지 않는 곳 |
|---|---|---|---|
| 클릭·탭 | 선택 또는 현재 상태의 대표 행동 | 재료 끼우기, 꼬치 이동·뒤집기·회수, 잔 배치 | 별도 완료 확인에 중복 사용하지 않음 |
| 대상 선택→목적지 클릭 | 대상이 여러 개인 이동 | 접시·잔을 특정 손님에게 서빙 | 목적지가 하나뿐인 공정 |
| 클릭·탭 홀드 | 흐름을 유지하고 떼면 중단 | 맥주·거품 따르기 | 꼬치 뒤집기 |
| 드래그, 선택 | 빠른 직접 이동 | 재료·접시·잔 이동 단축 | 필수 조작으로 요구하지 않음 |
| 짧은 수평 스와이프, 선택 | 빠른 뒤집기 | 그릴 위 꼬치 | 필수 조작으로 요구하지 않음 |
| 스테이션 탭 클릭·탭 | 스테이션 전환 | 꼬치·그릴·드링크·카운터 | 빈 배경 스와이프를 요구하지 않음 |

### 4.1 입력 우선순위

1. 재료·도구·잔·접시처럼 클릭할 수 있는 물건
2. 선택한 물건의 목적지 또는 현재 공정의 대표 행동
3. 스테이션 전환
4. 카메라·배경 연출

클릭이 가능한 물건 위에서 스테이션 전환 제스처가 시작되어서는 안 된다.

### 4.2 잠정 터치 기준

| 항목 | 모바일 잠정값 | 이유 |
|---|---:|---|
| 최소 터치 영역 | `56×56px` 상당 | 작은 재료도 안정적으로 선택 |
| 클릭·탭 확정 | 누르고 뗀 위치 차이 `12px` 이하 | 미세 손떨림 허용 |
| 선택 유지 | 다른 대상 선택 또는 빈 영역 클릭 전까지 | 두 번 클릭 서빙 지원 |
| 레버 홀드 시작 | `150ms` 이내 즉시 흐름 시작 | 누르는 감각과 빠른 취소 |
| 선택 드래그 시작 | 이동 `8px` 이상 | 선택형 빠른 조작과 클릭 구분 |
| 길게 누르기 안내 | `600ms` 무입력 | 조작 힌트 표시 시점 |

PC는 화면 배율에 맞춰 같은 시각적 거리를 사용한다. 수치는 실제 기기 테스트 후 조정한다.

### 4.3 웹에서 모바일로 확장하는 한 손 조작 규칙

#### 입력 의미 대응

| PC 웹 | 모바일 | 결과 |
|---|---|---|
| 물건 클릭 | 물건 탭 | 선택 또는 현재 공정의 대표 행동 실행 |
| 선택 후 목적지 클릭 | 선택 후 목적지 탭 | 접시·잔을 해당 손님에게 전달 |
| 레버 영역에서 마우스 버튼 누르기 | 레버 영역 터치 시작 | 맥주 또는 거품 흐름 시작 |
| 마우스 버튼 떼기 | 손가락 떼기·터치 취소 | 흐름 즉시 중단, 현재 양 보존 |
| 선택한 물건 밖 클릭 | 빈 영역 탭 | 선택 취소 |

- `hover해야 발견`, `우클릭해야 취소`, `휠로 양 조절`, `Shift+클릭` 같은 PC 전용 규칙을 핵심 흐름에 넣지 않는다.
- 하나의 활성 포인터만으로 모든 공정을 완료한다. 잔을 누른 채 다른 손가락으로 레버를 누르는 동시 입력은 요구하지 않는다.
- 클릭 후 선택 상태는 목적지를 누르거나 취소할 때까지 유지해, 화면이 넓은 모바일에서도 한 번에 멀리 뻗지 않아도 된다.
- `pointerup`, `pointercancel`, 브라우저가 백그라운드로 이동하는 경우 모두 생맥주 흐름을 즉시 중단한다.
- 조리 화면에서는 브라우저 스크롤과 핀치 확대가 조작을 가로채지 않도록 하되, 접근성 확대 정책은 별도 검증한다.

#### 한 손 엄지 도달 영역

- 모바일은 가로 화면을 유지하되, `한 손 조작`은 한 번에 한 손가락만 쓴다는 의미와 필수 입력이 한쪽 엄지 범위에 모인다는 의미를 함께 가진다.
- 스테이션 탭, 대기 재료, 꼬치 트레이, 빈 잔과 완성 트레이를 화면 하단 및 선택한 손 쪽 가장자리에 배치한다.
- 손님 얼굴처럼 화면 상단의 먼 대상 대신 하단 카운터에 연결된 큰 `주문 매트·주문 칩`을 서빙 목적지로 제공한다.
- 오른손 모드는 주요 대기 물건과 다음 행동 대상을 오른쪽 아래에, 왼손 모드는 이를 수평 반전해 왼쪽 아래에 둔다.
- 중요한 두 대상이 화면 양 끝에 떨어질 때는 `대상 클릭→선택 유지→스테이션 이동 또는 목적지 클릭`으로 나눠 긴 이동을 요구하지 않는다.
- 누르고 유지해야 하는 생맥주 레버는 선택한 손 쪽 하단 절반에 두고, 맥주·거품 영역을 각각 최소 `72×72px`로 확보한다.
- 상단 주문표와 화면 밖 경고는 정보만 제공하며, 진행을 위해 반드시 탭해야 하는 대상으로 사용하지 않는다.

#### 선택 상태와 오입력 방지

- 선택한 물건은 `1.05배 들림`, 굵은 외곽선, 목적지의 짧은 맥동으로 표시한다.
- 선택 후 다른 조작 가능 물건을 누르면 기존 선택을 해제하고 새 대상을 선택한다. 단, 완성 접시·잔을 선택한 상태에서 손님 주문 칩을 누르면 서빙으로 해석한다.
- 스테이션 탭과 레버처럼 즉시 반응해야 하는 컨트롤은 선택 물건보다 높은 입력 우선순위를 갖되, 레버 홀드 중 스테이션 전환은 먼저 흐름을 중단한다.
- 같은 위치의 빠른 연속 클릭은 애니메이션 잠금 시간 동안 한 번만 처리해 꼬치 이중 뒤집기와 잔 이중 배치를 막는다.
- 드래그 중 손가락이 화면 밖으로 나가거나 브라우저 스크롤로 취소되어도 물건과 액체 상태를 마지막 유효 상태로 복구한다.

## 5. 전체 야키토리 사용자 여정

```text
주문 도착
  ↓
주문표가 조립 작업대에 고정
  ↓
재료를 순서대로 클릭해 다음 칸에 끼움
  ↓
완성 꼬치를 클릭해 전달 트레이로 보냄
  ↓
그릴 탭 클릭
  ↓
대기 꼬치 클릭으로 빈 석쇠 칸에 올림
  ↓
앞면 익힘 확인 → 꼬치 클릭으로 뒤집기
  ↓
뒷면 익힘 확인 → 꼬치 클릭으로 접시 회수
  ↓
카운터 탭 클릭
  ↓
접시 클릭 → 주문 표식이 같은 손님 매트 클릭
  ↓
손님 반응과 비차단 품질 피드백
```

기본 네기마 한 꼬치는 재료 5회, 전달 1회, 석쇠 배치 1회, 뒤집기 1회, 회수 1회, 서빙 대상 선택 2회의 클릭으로 완성된다. 스테이션 전환을 제외하면 약 11회다.

## 6. 화면 구조: 꼬치 조립 스테이션

```text
┌──────────────────────────────────────────────────────┐
│ [주문 1: 네기마] [다음 주문]       [그릴 위험 표시] │
├─────────────┬───────────────────────────┬────────────┤
│ 재료통      │                           │ 전달       │
│ 닭          │     꼬치 조립 매트        │ 트레이      │
│ 대파        │     ───────────           │            │
│ 기타        │                           │            │
├─────────────┴───────────────────────────┴────────────┤
│        [꼬치]          [그릴]          [드링크]      │
└──────────────────────────────────────────────────────┘
```

### 6.1 주문표

- 현재 조립 중인 주문표는 화면 상단 중앙에 고정한다.
- 네기마는 `닭-대파-닭-대파-닭`을 글자와 재료 아이콘으로 함께 보여준다.
- 현재 넣어야 할 재료만 한 단계 밝아지고, 이미 넣은 재료에는 작은 체크 자국을 남긴다.
- 주문표를 눌러 별도 화면을 열 필요가 없다.
- 손님 좌석 표식은 색상+도형+숫자를 함께 사용한다. 예: `호박색 원·2번`.

### 6.2 조립 매트

- 빈 대나무 꼬치는 처음부터 작업대 중앙에 놓여 있다.
- 플레이어가 빈 꼬치를 재료통까지 가져가는 동작은 생략한다.
- 꼬치에는 5개의 넓은 재료 구간이 있지만 평소에는 선을 강하게 보이지 않는다.
- 재료를 클릭하면 주문상 다음 빈 구간이 얕게 빛나고 재료가 짧은 호를 그리며 이동한다.
- 클릭 우선 방식에서는 정밀 간격 판정을 제거하고 순서 선택과 굽기 타이밍에 숙련을 집중한다.

### 6.3 재료통

- 현재 메뉴에 필요한 재료만 앞줄에 둔다.
- 닭과 대파는 색상뿐 아니라 모양이 확실히 다르다.
- 한 재료를 클릭하면 같은 통의 다음 재료가 앞쪽으로 살짝 밀려 나온다.
- 재료 재고가 없는 프로토타입에서는 개수가 줄어드는 표현을 하지 않는다.
- 재료통 자체는 움직이지 않고 재료 조각만 집힌다.

### 6.4 전달 트레이

- 조립이 끝나기 전에는 어두운 나무 트레이로 유지한다.
- 마지막 재료가 끼워지면 트레이 가장자리가 한 번 따뜻하게 빛난다.
- `완료` 버튼 대신 완성 꼬치 자체를 클릭하는 행위가 전달 입력이다.
- 전달 트레이에 놓인 꼬치에는 주문 표식이 손잡이 끝에 붙는다.

## 7. 야키토리 조립 상세 UX 시나리오

### 7.1 상태 A: 주문 도착

**화면**

- 문종과 함께 상단에 네기마 주문표가 내려온다.
- 빈 꼬치가 작업대 중앙으로 0.2초 미끄러져 온다.
- 첫 주문에서는 재료통→꼬치 방향을 보여주는 손 모양이 한 번만 움직인다.

**플레이어가 이해해야 할 것**

- 주문표 순서대로 재료를 끼운다.
- 첫 재료는 닭이다.

**사용 문구 후보**

> 주문표 순서대로 재료를 끼우세요.

문구는 첫 주문에서만 표시하고 두 번째부터는 아이콘 강조만 사용한다.

### 7.2 상태 B: 재료를 집음

**입력**

- 닭 조각을 한 번 클릭한다. 모바일에서는 같은 위치를 한 번 탭한다.

**즉시 피드백**

- 입력 후 50ms 안에 재료가 작업대에서 6px 정도 들린다.
- 다음 빈 구간까지 짧은 호를 따라 이동하되 도착 직전에 속도를 줄인다.
- 마우스 포인터나 손가락을 따라다니게 하지 않아 클릭 한 번으로 동작을 끝낸다.
- 선택음은 부드러운 `툭` 한 번이다.

**목표 접근 피드백**

- 이동 중 다음 구간이 밝아지고 꼬치가 아주 약하게 휜다.
- 모바일 진동을 지원할 경우 관통 순간 약한 한 번의 진동을 제공하되 기본 필수로 두지 않는다.

### 7.3 상태 C: 재료를 끼움

**입력**

- 재료 클릭 뒤 자동으로 이어진다. 별도 두 번째 클릭이나 확인은 없다.

**손맛 연출**

1. 재료가 꼬치 끝에서 0.08초 멈춘다.
2. 꼬치 방향으로 4~6px 눌린다.
3. 짧은 `톡` 소리와 함께 목표 위치까지 들어간다.
4. 꼬치가 작게 반동하고 원위치로 돌아온다.

**다음 행동 유도**

- 주문표의 첫 닭 아이콘에 체크가 찍힌다.
- 다음 대파 아이콘이 한 번 숨 쉬듯 밝아진다.
- 대파 통의 가장 앞 조각만 아주 살짝 들린다.

### 7.4 잘못된 재료를 들었을 때

#### D1 튜토리얼 권장안

- 잘못된 재료를 클릭하면 꼬치가 받지 않고 해당 재료가 짧게 들렸다 통으로 돌아간다.
- 주문표의 올바른 재료만 한 번 흔들린다.
- 품질·시간 패널티는 없다.

#### 일반 영업 권장안

- 잘못된 재료를 클릭해도 꼬치에 끼워져 주문 확인 능력을 게임에 남긴다.
- 주문표가 짧게 두 번 떨리고 올바른 재료 아이콘과 현재 재료가 번갈아 강조된다.
- 플레이어가 즉시 수정할 수 있게 마지막 재료 손잡이가 밝아진다.

### 7.5 마지막 재료 빼기

**입력**

- 꼬치의 마지막 재료를 한 번 클릭한다.

**피드백**

- 처음에는 조금 버티다가 `뽁` 소리와 함께 빠진다.
- 빠진 재료는 해당 재료통으로 돌아간다.
- 꼬치의 그 구간이 다시 빈 상태가 된다.
- 중간 재료를 개별로 빼는 기능은 기본안에서 제공하지 않는다. 입력 복잡도와 시각 겹침을 줄이기 위함이다.

### 7.6 조립 판정

- 클릭 우선 기본안은 작은 위치 정밀도를 요구하지 않는다.
- 재료 순서와 개수 일치 여부만 조립 품질에 반영한다.
- 손맛은 위치 오차 점수 대신 재료별 관통 소리, 저항 시간과 꼬치 반동으로 표현한다.
- 드래그 빠른 조작을 사용해도 추가 품질 보너스를 주지 않아 입력 방식에 따른 불이익을 만들지 않는다.
- D1에서는 잘못된 재료가 자동 복귀해 조립 Fail을 만들지 않는다.

### 7.7 조립 완료

**발생 조건**

- 주문표의 모든 재료 수와 순서가 채워짐.

**연출**

- 꼬치 전체가 아주 작게 위로 들렸다 내려온다.
- 다섯 재료가 차례로 `톡톡톡톡톡` 짧은 음을 내거나 마지막 한 음으로 합친다.
- 전달 트레이가 활성화된다.
- 큰 `완료!` 팝업은 사용하지 않는다.

**다음 입력**

- 완성 꼬치를 한 번 클릭한다.

### 7.8 전달 트레이에 놓기

- 클릭하면 재료가 약간 처지고 꼬치가 미세하게 휘며 전달 트레이로 이동한다.
- 트레이 도착 경로는 짧고 직접적이며 플레이어 입력을 추가로 요구하지 않는다.
- 도착하면 주문 표식이 손잡이에 붙고 그릴 탭에 `1` 배지가 생긴다.
- 첫 튜토리얼은 0.4초 뒤 그릴 스테이션으로 자동 전환한다.
- 일반 영업은 자동 전환하지 않는다. 여러 꼬치를 연속 조립하는 플레이 흐름을 방해하지 않기 위함이다.

## 8. 화면 구조: 그릴 스테이션

```text
┌──────────────────────────────────────────────────────┐
│ [주문 상태]   [화력]       [다른 스테이션 위험]      │
├────────────┬───────────────────────────┬─────────────┤
│ 대기 트레이│        숯불 석쇠          │ 완성 접시   │
│ 꼬치 1     │   [1번][2번][3번][4번]   │             │
│ 꼬치 2     │                           │             │
├────────────┴───────────────────────────┴─────────────┤
│        [꼬치]          [그릴]          [드링크]      │
└──────────────────────────────────────────────────────┘
```

### 8.1 석쇠 칸

- 프로토타입은 2칸으로 시작하고 확장 시 최대 6칸까지 늘어난다.
- 대기 트레이의 꼬치를 클릭하면 첫 번째 빈 칸이 얕게 빛나며 자동 배치된다.
- 위치별 화력이 추가되는 후속 버전에서는 `꼬치 선택→원하는 빈 칸 클릭`의 두 번 클릭으로 확장한다.
- 각 칸의 익힘 상태는 꼬치 손잡이 주변 반원 게이지와 음식 자체 변화로 보여준다.
- 중앙·가장자리 화력 차이는 후속 확장으로 두고 첫 버전은 모든 칸의 화력을 동일하게 한다.

### 8.2 익힘 피드백

색상에만 의존하지 않고 다음 네 요소를 함께 사용한다.

| 상태 | 외형 | 소리 | 연기 | 손잡이 표시 |
|---|---|---|---|---|
| 덜 익음 | 윤기 적고 밝은 생고기 | 약한 지글거림 | 거의 없음 | 짧은 회색 구간 |
| 익는 중 | 표면 수축과 갈색 변화 | 일정한 지글거림 | 가는 연기 | 진행 링 증가 |
| 적정 | 가장자리 갈변, 육즙 반짝임 | 높은 한 번의 `치익` | 짧은 향 연기 | 링의 홈이 맞물림 |
| 과다 | 검은 점 확대 | 거친 타닥거림 | 진한 연기 | 링 끝이 깨진 형태 |

### 8.3 앞·뒷면 구분

- 손잡이 옆에 작은 반원 두 개를 위·아래로 배치한다.
- 현재 굽는 면만 밝게 표시한다.
- 뒤집은 뒤 위 반원에 체크가 남고 아래 반원이 진행된다.
- `앞면`, `뒷면` 텍스트를 계속 표시하지 않는다.

## 9. 야키토리 굽기 상세 UX 시나리오

### 9.1 꼬치를 석쇠에 올리기

**입력**

- 왼쪽 대기 트레이의 꼬치를 한 번 클릭한다.

**피드백**

- 꼬치가 첫 번째 빈 칸으로 이동하는 동안 아래쪽에 주황빛이 번진다.
- 빈 칸의 석쇠 두 줄이 밝아지고 꼬치가 수평으로 정렬된다.
- 철망에 닿는 `착` 소리, 이어서 기름의 `치익` 소리가 난다.
- 작은 불씨 3~6개가 튀지만 화면을 가리지 않는다.

**실수 방지**

- 빈 칸이 없으면 클릭해도 꼬치가 움직이지 않고 그릴 칸 전체가 `가득 참` 형태로 한 번 흔들린다.

### 9.2 앞면 굽기

- 꼬치를 올린 직후 별도 시작 버튼 없이 타이머가 흐른다.
- 플레이어는 게이지만 기다리는 것이 아니라 음식 표면, 소리와 연기를 함께 본다.
- 적정 구간 3초 전 손잡이 반원 링에 작은 홈이 접근한다.
- 적정 진입 순간 짧은 높은 `치익`, 윤기 반짝임과 연기 한 줄로 알려준다.
- 튜토리얼에서만 `지금 뒤집으세요` 문구를 1회 표시한다.

### 9.3 뒤집기

**입력**

- 그릴 위 꼬치를 한 번 클릭한다.
- 모바일에서는 같은 꼬치를 한 번 탭한다.
- 수평 스와이프는 손가락 방향대로 회전하는 숙련자용 선택 입력으로 남긴다.

**연출**

1. 클릭 즉시 집게가 순간적으로 손잡이를 받친다.
2. 마지막 사용 방향 또는 고정된 시계 방향으로 180도 회전한다.
3. 모바일 선택 입력으로 스와이프한 경우에만 손가락 방향을 회전에 반영한다.
4. 반대 면이 석쇠에 닿으며 기름 불꽃이 짧게 튄다.
5. 앞면 반원에 체크가 찍히고 뒷면 반원이 활성화된다.

**손맛 핵심**

- 클릭 한 번에도 집게의 받침, 꼬치의 관성, 석쇠 재접촉을 충분히 보여 손맛을 만든다.
- 선택 입력인 빠른 스와이프는 회전 속도와 방향이 반영되지만 품질 보너스는 주지 않는다.
- 한 번 뒤집은 직후 0.3초 동안 재입력을 막아 이중 뒤집기를 방지한다.

### 9.4 너무 일찍 뒤집기

- 회전은 허용한다. 조작 자체를 막지 않는다.
- 앞면 반원이 덜 찬 상태로 고정되고 `덜 익은 면`을 형태로 남긴다.
- 뒷면을 다 구운 뒤 다시 한 번 뒤집어 앞면을 보충할 수 있다.
- 품질은 조금 낮아지지만 즉시 Fail로 처리하지 않는다.

### 9.5 너무 늦게 뒤집기

- 검은 점, 거친 타닥거림과 진한 연기로 원인을 분명히 보여준다.
- 뒤집기는 계속 가능하다.
- 조금 탄 상태는 OK까지 복구 가능하고, 완전히 탄 상태만 폐기 후보가 된다.
- 첫날에는 완전히 타기 직전 0.8초 짧은 슬로 모션 보조를 제공하는 안이 있다.

### 9.6 타레 바르기, 선택 공정

복잡도를 낮추기 위해 네기마 첫 주문에서는 자동 또는 생략하고 D2 이후 소개하는 안을 권장한다.

**입력**

- 붓을 한 번 클릭하고 도포할 꼬치를 한 번 클릭한다.

**단순화 규칙**

- 붓이 꼬치 길이를 한 번 자동으로 왕복하고 도구통으로 돌아간다.
- 별도 커버리지 조작을 요구하지 않는다.
- 드래그로 직접 바르는 입력은 시각적 손맛을 원하는 사용자의 선택 조작으로 남긴다.
- 소금 주문은 별도 소금 뿌리기 동작 없이 기본 처리하거나 후속 공정으로 둔다.

**피드백**

- 붓이 지나간 부분에 짙은 광택이 생기고 숯불에 닿을 때 단 향의 연기 표현이 나온다.
- 도포가 부족하면 빈 부분이 질감으로 보인다.

### 9.7 뒷면 완료와 회수

**완료 신호**

- 두 반원 링이 모두 맞물린다.
- 두 음으로 된 짧은 완성음이 난다.
- 꼬치 손잡이 끝이 한 번 따뜻하게 빛난다.

**입력**

- 뒷면까지 구운 꼬치를 한 번 클릭한다.

**연출**

- 클릭하면 꼬치가 석쇠를 떠나 오른쪽 접시로 이동한다. 지글거림이 줄고 나무·도자기 접촉음이 난다.
- 접시 가장자리에 주문 표식이 자동으로 붙는다.
- 품질 결과는 화면 중앙을 가리지 않고 접시 위에 `Perfect/Good/OK` 작은 도장으로 0.8초 나타났다 사라진다.

### 9.8 덜 익은 꼬치를 꺼냈을 때

- 클릭하면 손잡이 링이 차가운 형태로 흔들리고 `아직 덜 익음` 상태를 알린다.
- 같은 꼬치를 다시 클릭하면 조기 회수를 확인하고 접시로 옮긴다.
- 서빙 전 접시의 꼬치를 클릭하면 석쇠로 돌아가 부족한 면부터 이어서 굽는다.
- 손님에게 서빙한 뒤에는 되돌릴 수 없다.

### 9.9 완전히 탄 꼬치

- 손잡이 링이 깨지고 꼬치 표면이 검게 굳는다.
- 완성 접시 대신 화면 아래 폐기 트레이가 나타난다.
- 폐기 트레이 전체를 넓은 드롭 존으로 사용한다.
- 폐기 후 같은 주문의 빈 꼬치가 조립 스테이션에 자동 준비된다.
- 폐기 확인 팝업은 두지 않는다.

## 10. 화면 구조: 카운터 서빙

```text
┌──────────────────────────────────────────────────────┐
│ [주문표·대기 게이지]                   [스테이션 경고]│
├──────────────────────────────────────────────────────┤
│  손님 1       손님 2       손님 3       손님 4       │
│ [원·1]       [삼각·2]      [사각·3]      [별·4]       │
│ ─────── 카운터 개인 매트 ─────────────────────────── │
├──────────────────────────────────────────────────────┤
│ 완성 접시 트레이                                     │
├──────────────────────────────────────────────────────┤
│        [꼬치]          [그릴]          [드링크]      │
└──────────────────────────────────────────────────────┘
```

### 10.1 주문 연결 방식

- 접시와 손님 매트에 같은 `색상+도형+숫자` 표식을 사용한다.
- 색상만으로 구분하지 않는다.
- 손님 얼굴이나 작은 말풍선을 정확히 클릭하게 하지 않는다.
- 손님 앞 카운터 매트와 하단 주문 칩을 모두 넓은 클릭 대상으로 사용한다.

### 10.2 서빙 상세 UX

**입력**

- 완성 접시를 한 번 클릭하고 주문 표식이 같은 손님 매트 또는 주문 칩을 한 번 클릭한다.

**선택 중 피드백**

- 선택한 접시가 4px 정도 들리고 같은 표식의 손님 매트·주문 칩이 함께 강조된다.
- 마우스 포인터에는 작은 접시 아이콘을 붙여 현재 선택을 보여준다.
- 빈 영역을 클릭하거나 `Esc`를 누르면 선택만 취소되고 접시는 유지된다. 모바일은 선택한 접시를 다시 탭해 취소한다.

**드롭 성공**

- 목적지를 클릭하면 접시가 카운터 위를 미끄러져 손님 앞 정위치로 0.12초 스냅된다.
- 손님이 바로 손을 뻗거나 고개를 끄덕인다.
- 주문표와 대기 게이지는 작아지며 사라진다.
- 화면 중앙 점수 팝업 없이 팁·콤보가 상단에서 조용히 갱신된다.

### 10.3 잘못된 손님에게 놓기

- 잘못된 손님을 클릭하면 접시가 움직이지 않는다.
- 손님이 고개를 살짝 젓고 주문 표식이 한 번 나타난다.
- 접시는 완성 트레이로 돌아간다.
- 첫 실수에는 대기·품질 패널티를 주지 않고 시간만 소모한다.

### 10.4 품질 반응

| 결과 | 손님 행동 | UI |
|---|---|---|
| Perfect | 첫 입 뒤 짧게 눈이 커지고 추가 주문 후보 | 작은 금색 불씨 3개 |
| Good | 고개 끄덕임, 안정된 식사 | 따뜻한 체크 표시 |
| OK | 한 번 살펴본 뒤 먹음 | 회색 체크와 구체적 원인 1개 |
| Fail | 재조리 요청 또는 낮은 반응 | 붉은 화면 대신 깨진 꼬치 아이콘 |

## 11. 첫 네기마 전체 튜토리얼 시나리오

### 11.1 목표 시간 초안

- 주문 확인: 3초
- 조립: 15~25초
- 그릴 배치와 앞면: 8~12초
- 뒤집기와 뒷면: 8~12초
- 회수·서빙: 5~8초
- 전체: 설명 포함 60~90초

### 11.2 단계별 안내

| 순서 | 플레이어 행동 | 안내 | 보호 규칙 |
|---:|---|---|---|
| 1 | 닭 조각 클릭 | 클릭 파동 1회 | 대기 감소 없음 |
| 2 | 자동 관통 확인 | 다음 칸 표시 | 잘못된 재료 자동 복귀 |
| 3 | 남은 4개 클릭 | 주문표 다음 아이콘 강조 | 위치 Fail 없음 |
| 4 | 완성 꼬치 클릭 | 트레이 이동 연출 | 별도 완료 없음 |
| 5 | 대기 꼬치 클릭 | 빈 칸 자동 배치 | 자동 전환 |
| 6 | 적정까지 기다리기 | 색·소리 설명 1회 | 적정 구간 확대 |
| 7 | 꼬치 클릭 | 클릭 파동 1회 | 이중 뒤집기 방지 |
| 8 | 뒷면 완료 후 꼬치 클릭 | 접시 이동 연출 | 너무 일찍 클릭하면 경고 |
| 9 | 접시 클릭→손님 클릭 | 동일 표식 강조 | 오서빙 이동 없음 |

### 11.3 안내 감소

- 같은 행동을 한 번 성공하면 손 모양을 제거한다.
- 두 번 성공하면 텍스트를 제거하고 사물 강조만 남긴다.
- 세 번 성공하면 강조도 끄고 음식 자체 피드백만 사용한다.
- 설정에서 전체 도움말을 다시 켤 수 있다.

## 12. 숙련 야키토리 흐름

숙련자는 화면 전환과 기다림 사이에 다음 행동을 계획할 수 있어야 한다.

1. 첫 꼬치를 석쇠에 올린다.
2. 앞면이 익는 동안 조립 스테이션에서 두 번째 꼬치를 만든다.
3. 화면 가장자리 뒤집기 경고를 보고 그릴로 돌아온다.
4. 첫 꼬치를 뒤집고 빈 칸에 두 번째 꼬치를 올린다.
5. 첫 꼬치를 회수하면서 두 번째 꼬치의 앞면 상태를 확인한다.
6. 첫 접시를 서빙하고 두 번째 꼬치 경고에 맞춰 돌아온다.

이 흐름에서 화면 밖 그릴 실패가 억울하지 않도록 다음 규칙이 필요하다.

- 실패 3초 전 방향+아이콘+경고음.
- 마지막 1초 화면 가장자리 점멸.
- 동시에 두 꼬치가 위험하면 더 먼저 실패하는 꼬치만 크게 표시.
- 스테이션으로 돌아오면 위험 꼬치가 0.4초 동안 자동 강조.

## 13. 생맥주 조작의 기본 선택

기존 기획의 `잔 기울기를 직접 유지하며 따르기`는 사실적이지만 모바일 한 손가락으로 잔과 레버를 동시에 조작하면 복잡해질 가능성이 높다.

### 권장 기본안

> 빈 잔은 클릭하면 기계에 놓이고 자동으로 기울고 세워진다. 플레이어는 레버의 아래쪽을 누르고 있는 동안 맥주를 따르고, 위쪽을 누르고 있는 동안 거품을 올리는 타이밍에 집중한다.

이 안은 다음 장점을 가진다.

- 마우스 한 버튼 또는 한 손가락만 사용한다.
- 레버의 반대 방향 두 동작으로 맥주와 거품을 직관적으로 구분한다.
- 실제 기계 조작의 금속 걸림과 스프링 반동을 표현할 수 있다.
- 7:3 비율이라는 핵심 결과는 유지한다.
- 러시 중 언제든 손을 떼고 그릴로 돌아갈 수 있다.

잔 각도 직접 조작은 숙련 모드 또는 후속 난도 확장 후보로 남긴다.

## 14. 화면 구조: 생맥주 스테이션

```text
┌──────────────────────────────────────────────────────┐
│ [생맥주 주문·대기]            [그릴 위험 표시]       │
├────────────┬───────────────────────────┬─────────────┤
│ 빈 잔 선반 │       생맥주 기계          │ 완성 트레이 │
│            │        ┌레버┐             │             │
│            │        │    │             │             │
│            │      [기울어진 잔]         │             │
│            │       드립 트레이           │             │
├────────────┴───────────────────────────┴─────────────┤
│        [꼬치]          [그릴]          [드링크]      │
└──────────────────────────────────────────────────────┘
```

### 14.1 잔

- 손잡이가 오른쪽을 향한 빈 잔을 선반에 둔다.
- 잔 전체와 손잡이를 하나의 넓은 클릭·터치 영역으로 사용한다.
- 빈 잔을 클릭하면 기계 아래로 자동 이동하고 40~45도로 기울어진다.
- 잔 표면에 `맥주 70%`와 `완성 100%` 두 기준선을 유리 각인처럼 표시한다.
- 별도 세로 게이지보다 잔 자체를 보게 한다.

### 14.2 레버

- 하나의 중앙 레버를 사용한다.
- 레버의 아래 클릭 영역에는 맥주색 물방울 형태, 위 클릭 영역에는 흰 거품 형태를 작은 양각으로 표현한다.
- 튜토리얼 뒤에는 `맥주`, `거품` 텍스트를 계속 표시하지 않는다.
- 위·아래 클릭 영역은 실제 손잡이보다 넓은 `72×72px` 상당으로 둔다.
- 손가락을 놓으면 레버가 항상 중앙으로 돌아온다.

### 14.3 완성 트레이

- 잔이 완성되기 전에는 비활성 상태다.
- 맥주+거품 합계가 최소 제공선에 도달하면 활성화된다.
- 완성 잔을 트레이에 놓으면 손잡이에 주문 표식이 붙는다.

## 15. 생맥주 기계 상세 UX 시나리오

### 15.1 상태 A: 생맥주 주문 도착

**화면**

- 상단 주문표에 생맥주 잔 아이콘과 손님 표식이 나타난다.
- 빈 잔 선반의 앞 잔에 작은 물방울이 맺히며 강조된다.
- 첫 주문에서만 잔→드립 트레이 방향 손 모양을 한 번 보여준다.

**사용 문구 후보**

> 빈 잔을 기계 아래에 놓으세요.

### 15.2 상태 B: 잔 배치

**입력**

- 빈 잔을 한 번 클릭한다.

**피드백**

- 클릭하면 유리의 맑은 접촉음과 함께 잔이 노즐 아래로 이동한다.
- 이동 중 드립 트레이 홈이 밝아진다.
- 잔 바닥이 홈에 `딱` 맞고 자동으로 40~45도 기울어진다.
- 노즐과 잔 벽 사이의 흐름 경로가 0.5초 동안 얕게 보인다.

### 15.3 상태 C: 맥주 따르기

**입력**

- 레버의 아래쪽 맥주 영역에서 마우스 버튼 또는 손가락을 누르고 유지한다.

**레버 손맛**

1. 누르는 순간 레버가 0.12초 저항한 뒤 아래로 꺾인다.
2. 금속 `찰칵` 소리와 함께 맥주가 흐른다.
3. 버튼·손가락을 유지하는 동안 레버가 약하게 떨린다.
4. 떼면 스프링 반동으로 중앙에 돌아오며 `턱` 소리가 난다.

**잔 연출**

- 맥주가 잔 벽을 따라 흐르며 처음에는 거품이 거의 생기지 않는다.
- 채움이 35%를 넘으면 잔이 천천히 세워지기 시작한다.
- 65~70%에서 잔이 거의 수직이 된다.
- 플레이어는 잔 각도를 조작하지 않고 레버 해제 타이밍에 집중한다.

**소리**

- 시작은 낮은 액체음.
- 잔이 차오를수록 음 높이와 탄산 소리가 조금 올라간다.
- 70% 기준선을 넘으면 아주 작은 유리 공명음이 한 번 난다.

### 15.4 맥주 70%에서 멈추기

**입력**

- 맥주가 70% 선 근처에 도달할 때 마우스 버튼 또는 손가락을 뗀다.

**피드백**

- 레버가 중앙으로 돌아가고 흐름이 즉시 끊긴다.
- 마지막 한 방울이 노즐 끝에 맺힌다.
- 70% 선 근처면 잔의 맥주층 테두리가 짧게 반짝인다.
- 정확한 백분율 숫자는 기본 화면에 표시하지 않는다.

**판정 후보**

| 맥주 비율 | 상태 | 다음 단계 |
|---:|---|---|
| 65~75% | 이상적 | 거품 25~35% 공간 확보 |
| 55~64% | 적음 | 거품을 더 올릴 수 있으나 맥주 맛 판정 감소 |
| 76~85% | 많음 | 거품 공간이 좁아짐 |
| 86% 이상 | 과다 | 최소 거품만 가능, 넘침 위험 |

수치는 밸런스 테스트 전 잠정값이다.

### 15.5 상태 D: 거품 올리기

**입력**

- 레버의 위쪽 거품 영역에서 마우스 버튼 또는 손가락을 누르고 유지한다.

**레버 차이**

- 아래로 당길 때보다 가볍고 짧게 움직인다.
- 작동음은 높은 `딸깍`으로 맥주 모드와 구분한다.
- 거품은 액체보다 느린 속도로 올라와 미세 조절할 시간을 준다.

**거품 연출**

- 노즐에서 하얗고 부드러운 거품이 굵게 나온다.
- 큰 비눗방울보다 조밀한 크림 질감으로 쌓인다.
- 맥주층과 거품층 경계가 수평으로 유지된다.
- 거품이 잔 위쪽 30%에 들어오면 표면이 둥글게 솟기 시작한다.

**소리**

- 맥주 흐름보다 낮은 볼륨의 부드러운 `슈우` 소리.
- 거품이 완성선에 가까워지면 소리가 조금 둔해진다.

### 15.6 거품 30%에서 멈추기

**입력**

- 거품이 잔의 완성선에 닿을 때 마우스 버튼 또는 손가락을 뗀다.

**완성 피드백**

- 레버가 중앙으로 돌아온다.
- 거품 표면이 한 번 부드럽게 흔들리고 안정된다.
- 잔 외벽에 물방울이 맺히고 손잡이에 주문 표식이 나타난다.
- 이상적인 7:3이면 맥주층과 거품층 사이에 짧은 금빛 링이 지나간다.
- 큰 `PERFECT` 팝업 대신 기계의 금속 종소리 한 번을 사용한다.

### 15.7 상태 E: 완성 잔 옮기기

**입력**

- 완성 잔을 한 번 클릭한다. 잔이 오른쪽 완성 트레이로 이동한다.

**손맛**

- 이동 시작을 빈 잔보다 0.08초 느리게 해 무게를 표현한다.
- 이동 중 거품이 흔들리지만 실제로 쏟아져 실패하지는 않는다.
- 트레이에 놓으면 유리와 나무의 낮은 접촉음이 난다.

**다음 흐름**

- 카운터 탭에 완성 음료 배지가 생긴다.
- 카운터에서 완성 잔을 클릭하고 해당 손님 매트 또는 주문 칩을 클릭한다.

## 16. 생맥주 실패·복구 흐름

### 16.1 맥주가 적음

- 거품을 올리기 전에 레버 아래 영역을 다시 눌러 보충할 수 있다.
- 여러 번 끊어 따랐다는 이유로 큰 패널티를 주지 않는다.
- 흐름 재개 시 잔 각도는 현재 채움에 맞춰 자동 조정된다.

### 16.2 맥주가 많음

- 이미 따른 맥주를 빼는 조작은 제공하지 않는다.
- 남은 공간에 거품을 조금 올려 제공할 수 있다.
- 품질은 내려가지만 바로 폐기할 필요는 없다.

### 16.3 거품이 적음

- 레버 위 영역을 다시 눌러 보충한다.
- 거품 추가는 언제든 가능하지만 이미 넘치기 직전이면 흐름이 느려진다.

### 16.4 거품이 너무 많음

- 거품이 잔 위로 솟고 가장자리로 흐른다.
- 기계는 110%에서 자동으로 흐름을 차단해 끝없는 넘침을 막는다.
- 수건으로 닦는 추가 미니게임은 기본안에서 넣지 않는다.
- 자동으로 잔 외부를 닦는 짧은 연출 뒤 낮은 품질로 제공하거나, 잔을 클릭한 뒤 싱크 트레이를 클릭해 새로 만들 수 있다.

### 16.5 빈 잔 없이 레버 조작

- 레버가 임계점 전에 걸리고 흐름이 나오지 않는다.
- 드립 트레이의 빈 잔 위치가 한 번 밝아진다.
- 맥주가 바닥에 쏟아지는 실패 연출은 만들지 않는다.

### 16.6 조작 중 다른 스테이션 경고

- 레버에서 손을 떼면 즉시 흐름이 멈춘다.
- 스테이션을 떠날 때 레버는 자동으로 중앙에 돌아온다.
- 현재 잔의 맥주와 거품 상태는 그대로 보존한다.
- 그릴을 처리하고 돌아와 이어서 맥주 또는 거품을 추가할 수 있다.
- 플레이어가 다른 스테이션을 확인하려고 생맥주 한 잔을 버리게 해서는 안 된다.

## 17. 첫 생맥주 튜토리얼 시나리오

### 17.1 목표 시간 초안

- 잔 배치: 3~5초
- 맥주 따르기: 4~6초
- 거품 올리기: 2~4초
- 트레이 이동·서빙: 4~6초
- 설명 포함 전체: 20~35초

### 17.2 단계별 안내

| 순서 | 행동 | 안내 | 보호 규칙 |
|---:|---|---|---|
| 1 | 빈 잔 클릭 | 클릭 파동 1회 | 자동 배치 |
| 2 | 레버 아래 영역 누르고 유지 | 아래 영역 강조 | 70%에서 흐름 느려짐 |
| 3 | 손을 떼어 맥주 중단 | 기준선 반짝임 | 78% 전 자동 보조 |
| 4 | 레버 위 영역 누르고 유지 | 위 영역 강조 | 거품 속도 느림 |
| 5 | 손을 떼어 거품 중단 | 완성선 반짝임 | 첫 넘침 자동 차단 |
| 6 | 완성 잔 클릭 | 트레이 이동 연출 | 흔들림 실패 없음 |
| 7 | 잔 클릭→손님 클릭 | 동일 주문 표식 | 오서빙 이동 없음 |

### 17.3 첫 잔 보조

- 맥주가 65%에 도달하면 흐름을 20% 늦춰 손을 뗄 시간을 준다.
- 거품이 25%에 도달하면 흐름을 30% 늦춘다.
- 7:3 범위에서 손을 떼면 약한 자석처럼 정확한 선에 시각적으로 정렬한다.
- 두 번째 잔부터 보조를 절반으로 줄이고 세 번째부터 일반 속도를 사용한다.

## 18. 숙련 생맥주 흐름

숙련자가 느낄 손맛은 복잡한 조합보다 레버의 두 방향과 소리 타이밍에서 나온다.

1. 빈 잔을 클릭해 홈에 빠르게 안착시킨다.
2. 레버 아래 영역을 눌러 금속 걸림을 느낀다.
3. 액체음이 높아지는 순간 손을 놓는다.
4. 반동하는 레버의 위 영역을 바로 눌러 거품 모드로 전환한다.
5. 거품 소리가 둔해지는 순간 손을 놓는다.
6. 완성 잔을 클릭해 트레이로 보낸다.

숙련자는 숫자를 보지 않고 `찰칵→액체음 상승→턱→딸깍→거품음 둔화→턱` 리듬으로 완성할 수 있어야 한다.

## 19. 야키토리와 생맥주가 겹치는 러시 UX

### 19.1 권장 상황

- 네기마 앞면이 굽는 중.
- 직장인 2인이 생맥주 2잔 주문.
- 플레이어가 첫 잔 맥주를 50%까지 따른 시점에 그릴 3초 경고 발생.

### 19.2 플레이어 선택

#### 그릴 우선

1. 레버에서 손을 뗀다.
2. 맥주 흐름이 즉시 멈춘다.
3. 왼쪽 그릴 경고 또는 그릴 탭을 누른다.
4. 꼬치를 뒤집는다.
5. 드링크로 돌아와 아래 레버로 맥주를 이어 따른다.

#### 생맥주 우선

1. 70%까지 1~2초 더 따른다.
2. 손을 떼고 그릴로 전환한다.
3. 꼬치를 뒤집는다.
4. 돌아와 거품을 올린다.

두 선택 모두 복구 가능해야 한다. 화면 밖 상태를 몰라서 실패하는 것이 아니라 어떤 작업을 먼저 끝낼지 선택하는 긴장감이어야 한다.

### 19.3 경고 표시

- 생맥주 레버를 누르고 있어도 가장자리 경고가 레버나 잔을 가리지 않는다.
- 경고음은 맥주 따르는 소리보다 높은 대역을 사용한다.
- 마지막 1초에는 화면 전체가 아니라 그릴 방향 가장자리만 점멸한다.
- 동시에 손님 대기 경고가 있으면 `조리 실패 임박→손님 이탈 임박→일반 주문` 순으로 우선한다는 아이디어가 있다.

## 20. 게임필 상세

### 20.1 재료

- 생닭: 부드럽고 약간 무거운 추적, 낮은 `툭` 소리.
- 대파: 가볍고 빠른 추적, 마른 `톡` 소리.
- 꼬치 관통: 재료별 소리 높이를 다르게 한다.
- 완성 꼬치: 재료 무게에 따라 미세하게 휜다.

### 20.2 석쇠

- 꼬치 배치 때 금속 접촉음과 기름 소리를 연속으로 낸다.
- 뒤집기 속도에 따라 회전음 길이가 달라진다.
- 적정 구간은 UI음보다 실제 `치익` 소리를 강조한다.
- 회수할 때 숯불 소리가 한 단계 줄어 완료감을 준다.

### 20.3 접시와 서빙

- 접시를 클릭하면 살짝 들려 선택되며 내용물에 따라 들리는 속도를 달리해 무게를 준다.
- 손님 주문 칩을 클릭하면 접시가 카운터를 가로질러 자동으로 이동하며 작은 마찰음이 난다.
- 손님 매트에 맞으면 2~3px 짧게 미끄러진 뒤 멈춘다.
- 접시가 순간이동하거나 UI 슬롯으로 흡수되는 연출은 피한다.

### 20.4 생맥주 기계

- 맥주 레버는 무겁고 거품 레버는 가볍다.
- 레버 중앙 복귀 반동을 화면과 소리로 분명히 표현한다.
- 맥주·거품의 소리와 흐름 굵기를 다르게 한다.
- 잔이 차오를수록 유리의 무게감과 응결 물방울이 늘어난다.

### 20.5 진동, 선택 사항

- 재료 스냅: 매우 약한 1회.
- 꼬치 뒤집기 임계 통과: 중간 세기 1회.
- 레버 걸쇠 통과: 약한 1회.
- Perfect: 짧은 2회가 아니라 작은 1회로 절제.
- 진동은 설정에서 완전히 끌 수 있어야 한다.
- 현재 프로토타입 범위에서 진동을 제외해도 시각·소리만으로 모든 상태를 이해할 수 있어야 한다.

## 22. 접근성·대체 조작 아이디어

### 22.1 색상 외 정보

- 익힘 정도: 색+표면 질감+연기+소리+링 형태.
- 주문 연결: 색+도형+좌석 숫자.
- 맥주 비율: 색+잔 내부 층+각인 선.
- 위험 경고: 색+방향 아이콘+음향.

### 22.2 왼손잡이

- 재료통과 전달 트레이 위치를 좌우 반전할 수 있다.
- 생맥주 잔 선반과 완성 트레이를 반전할 수 있다.
- 레버의 아래=맥주, 위=거품 방향은 반전하지 않는다.

### 22.3 뒤집기 대체 입력

- 기본 뒤집기는 꼬치를 한 번 클릭·탭하는 방식이므로 스와이프 능력을 요구하지 않는다.
- 수평 스와이프는 회전 방향을 직접 정하고 싶은 사용자의 선택 입력으로만 제공한다.
- 운동 조절이 어려운 사용자는 `큰 터치 영역` 옵션으로 꼬치 손잡이 주변의 유효 영역을 넓힐 수 있다.

### 22.4 정밀 타이밍 완화

- 초보 모드: 굽기 적정 구간 30~40% 확대.
- 초보 모드: 맥주·거품 목표 근처에서 흐름 감속.
- 초보 모드: 위험 1초 전에 0.5초 슬로 모션 1회.
- 숙련 모드: 도움 강조를 줄이고 원래 판정 범위를 사용.

### 22.5 소리 없이 플레이

- `치익` 타이밍은 손잡이 링 홈과 짧은 표면 반짝임으로 대체한다.
- 레버 걸림은 손잡이의 눌림과 진동으로 대체한다.
- 거품 완성은 잔 테두리의 파동으로 표시한다.

## 23. 중단·복귀

### 포인터가 취소된 경우

- 재료·꼬치·접시·잔은 마지막 유효 위치로 돌아간다.
- 생맥주 레버는 중앙으로 돌아가고 흐름이 멈춘다.
- 꼬치 뒤집기 도중 취소되면 임계점 이전은 원위치, 이후는 뒤집기 완료로 처리한다.

### 스테이션 전환

- 조립 중 들고 있던 재료가 있으면 원래 통으로 돌아간 뒤 전환한다.
- 그릴 타이머는 계속 흐른다.
- 생맥주 흐름은 멈추고 잔 상태는 유지된다.

### 브라우저 백그라운드

- 모든 조리·손님·액체 흐름 타이머를 즉시 멈춘다.
- 복귀하면 현재 주문과 위험 상태를 2초 요약한 뒤 입력으로 재개한다.
- 복귀 요약 중에는 꼬치가 타거나 맥주가 흐르지 않는다.

## 25. 화면 문구 초안

문구는 한 번에 한 줄, 행동 동사 하나만 사용한다.

### 꼬치

- `순서대로 재료를 클릭하세요.`
- `마지막 재료를 클릭하면 뺄 수 있어요.`
- `완성 꼬치를 클릭하세요.`
- `대기 꼬치를 클릭해 석쇠에 올리세요.`
- `지금 꼬치를 클릭해 뒤집으세요.`
- `완성 꼬치를 클릭해 접시에 옮기세요.`

## 29. 권장 결론 요약

### 야키토리

```text
재료를 순서대로 5번 클릭
→ 완성 꼬치 클릭
→ 대기 꼬치 클릭으로 석쇠 배치
→ 적정 순간 꼬치 클릭으로 뒤집기
→ 뒷면 적정 순간 꼬치 클릭으로 접시 회수
→ 접시 클릭 후 같은 표식의 손님 주문 칩 클릭
```

- 별도 확인 버튼 없음.
- 정밀한 작은 드롭 없음.
- 드래그·스와이프 없이 전체 흐름 완료 가능.
- 선택형 드래그·스와이프에는 속도 이점만 있고 품질 보너스는 없음.
- 실패 시 마지막 재료 제거·재가열 가능.
- 손맛은 관통 저항, 석쇠 소리, 회전 반동과 접시 무게로 표현.

### 생맥주

```text
빈 잔 클릭으로 기계에 배치
→ 레버 아래 영역을 누르고 유지, 70%에서 놓기
→ 레버 위 영역을 누르고 유지, 거품 30%에서 놓기
→ 완성 잔 클릭으로 트레이 이동
→ 잔 클릭 후 같은 표식의 손님 주문 칩 클릭
```

- 잔 각도는 자동.
- 맥주와 거품은 레버의 반대 방향으로 구분.
- 한 번에 포인터 하나만 사용하며 PC와 모바일의 입력 의미가 같음.
- 러시 중 손을 놓으면 즉시 중단하고 나중에 이어서 조작 가능.
- 손맛은 레버 걸쇠, 스프링 복귀, 액체·거품 소리와 가득 찬 잔의 무게로 표현.
