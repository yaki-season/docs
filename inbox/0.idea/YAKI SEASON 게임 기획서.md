**한 줄 컨셉**

> 골목 끝 허름한 야키토리 노포를 물려받아, 숯불 하나로 동네 최고의 이자카야로 키워내는 손맛 경영 게임.
>

**핵심 재미 3요소**

1. **손맛(Craft)** — 꼬치 끼우기, 굽기, 술 따르기를 직접 드래그로 수행. 정확도가 곧 돈.
2. **압박(Rush)** — 여러 손님의 주문·대기 게이지를 동시에 관리하는 멀티태스킹 긴장감.
3. **성장(Grow)** — 메뉴 해금, 재료 등급업, 직원 고용·자동화, 가게 꾸미기로 이어지는 장기 성장.

# 2. 세계관 & 배경 스토리

주인공은 도시 생활에 지친 청년. 어느 날 할아버지가 40년간 운영하던 골목 야키토리집 「토리야(鳥屋)」의 열쇠와 낡은 레시피 노트를 물려받는다. 노트의 페이지는 대부분 기름에 절어 읽을 수 없는 상태 — **영업을 거듭하며 레시피(메뉴)를 한 장씩 복원(해금)해 나가는 것**이 스토리이자 콘텐츠 해금 장치다.

- 톤앤매너: 따뜻한 저녁 골목, 숯불의 주황빛, 로파이 BGM.
- 배경은 조명과 분위기가 반영된 2D 이미지로 구성한다. 꼬치·석쇠·맥주잔·도구처럼 플레이어가 직접 조작하는 대상만 Three.js 3D 오브젝트로 구현한다.
- 스토리는 단골 손님들과의 에피소드로 진행 (7장 참고).

# 3. 핵심 게임플레이 루프

```
[영업 준비] → [영업 (주문→조리→서빙→정리)] → [정산] → [업그레이드/해금] → 다음 영업일
```

1. **영업 준비**: 오늘 팔 메뉴 슬롯 확인, 숯불 점화(부채질 미니게임).
2. **영업 (3~4분)**: 손님 입장 → 주문 → 플레이어가 스테이션에서 조리 → 드래그로 서빙 → 손님 퇴장 시 자리 정리(탭).
3. **정산**: 매출/팁/품질 통계, 별점 리뷰, 명성 획득.
4. **성장**: 골드로 메뉴 해금·재료 등급업·장비·직원·인테리어 투자.
5. 명성이 오르면 손님 수·손님 타입·이벤트가 확장 → 난이도와 보상이 함께 상승.

- 일반 영업일은 준비부터 정산과 다음 목표 확인까지 4~6분을 목표로 한다.
- 첫 영업일은 튜토리얼과 기본 스토리를 포함해 최대 8분까지 허용하며, 모든 스토리 장면은 건너뛸 수 있다.
- 프로토타입은 이 전체 1영업일 루프와 가게 상속부터 다음 목표 제시까지의 기본 스토리·시나리오를 보여준다.
- 프로토타입에서는 재료와 소모품의 수량을 관리하지 않는다. 재료 소진, 보충과 품절도 발생하지 않는다.

# 4. 조리 시스템 (스테이션 상세)

화면 하단 탭 또는 좌우 스와이프로 스테이션을 전환한다. 프로토타입은 **꼬치 조립·그릴·드링크** 3개 스테이션으로 구성한다. 모든 스테이션은 동시에 진행 상태가 유지되며, 다른 스테이션으로 이동하거나 전환 애니메이션이 재생되는 동안에도 활성 조리 타이머는 계속 흐른다.

- 상단 고정 상태 바에 각 스테이션의 진행 상태를 항상 표시한다.
- 실패 예상 시점 3초 전부터 해당 스테이션 방향 아이콘, 경고 색상과 경고음을 함께 표시한다.
- 실패 예상 시점 마지막 1초에는 해당 방향의 화면 가장자리를 점멸한다.
- 경고는 색상에만 의존하지 않는다. 모바일 진동 경고는 현재 범위에 포함하지 않는다.

## 4.1 꼬치 스테이션 (조립)

- 주문서에 표시된 **재료 순서대로** 재료를 꼬치에 드래그하여 끼운다. (예: 네기마 = 닭다리살 → 대파 → 닭다리살 → 대파 → 닭다리살)
- 판정: 순서 정확도 + 재료 간격(드롭 위치 정확도).
- 잘못 끼우면 마지막 재료를 위로 드래그해 빼기 가능(시간 손실).

## 4.2 그릴 스테이션 (숯불)

- 꼬치를 석쇠 위로 드래그 → 굽기 게이지 진행 (덜 익음 → **Perfect 존** → 탄다).
- **뒤집기**: 꼬치를 좌→우 스와이프. 양면 각각 Perfect 존에서 뒤집기/회수해야 최고 판정.
- **타레(소금/양념)**: 붓을 꼬치 위에서 왕복 드래그 — 도포 커버리지 %가 판정에 반영.
- **숯불 화력 관리**: 화력이 서서히 감소, 부채를 연속 탭/스와이프해 화력 유지. 화력이 낮으면 굽기가 느려지고, 과하면 Perfect 존이 좁아진다.

## 4.3 튀김 스테이션 (가라아게 등·프로토타입 제외)

- 닭고기를 반죽 볼에 드래그 → 휘젓기(원형 드래그) → 기름에 투하.
- 기름 온도 게이지 + 튀김 색 변화. **황금색 타이밍에 건지기**(위로 드래그)가 판정 포인트.
- 기름 튀는 이펙트 등 타격감 있는 연출.

## 4.4 드링크 스테이션 (주류/음료)

- **생맥주**: 잔을 탭 아래로 드래그해 대고, **잔 기울기를 드래그로 유지**하며 따르기 → 맥주:거품 = 7:3 비율 판정. 거품 넘치면 감점.
- **하이볼**: 얼음 드래그 투입 → 위스키 계량(누르는 시간) → 탄산수 붓기 → 레몬 슬라이스 올리기. 비율 정확도 판정.
- **사와/우롱차 등**: 간단 버전(저난이도, 저마진).

## 4.5 플레이팅 & 사시미 스테이션 (프로토타입 제외)

- **사시미**: 칼을 생선 위에서 직선 드래그 — 선의 곧기·두께 균일성 판정. 접시에 부채꼴로 배치.
- **플레이팅**: 완성 요리를 접시에 드래그, 가니시(시치미, 레몬, 파슬리) 올리기.

## 4.6 품질 판정 공통 규칙

| 판정 | 조건 | 판매가 영향 |
| --- | --- | --- |
| Perfect | 모든 공정 상위 판정 | 최고 품질 배율 |
| Good | 경미한 공정 실수 | 기본가보다 높은 품질 배율 |
| OK | 복수의 경미한 공정 실수 | 기본 판매가 |
| Fail | 태움/순서 오류/비율 붕괴 | 감액 또는 판매 실패 |

- 품질 판정은 판매가에만 반영한다.
- 대기 시간과 손님 유형은 팁에만 반영한다.
- 만족도는 추가 주문과 명성에만 반영한다.
- 콤보는 팁 배율만 올리며 최대 `×1.5`로 제한한다.
- 판매가와 팁을 합친 한 주문의 최종 수익은 기본 판매가 대비 `×2.0`을 넘지 않는다.
- Perfect·Good·OK·Fail의 정확한 판매가 배율과 기본 팁 수치는 별도 밸런스 설계에서 확정한다.

# 5. 메뉴 라인업 & 해금 트리

실제 야키토리집 인기 메뉴 기반. **레시피 노트 복원** 컨셉으로 명성 레벨에 따라 해금.

프로토타입에서 제공하는 메뉴는 **네기마·모모·생맥주** 3종으로 제한한다. 아래의 나머지 메뉴는 프로토타입 이후 확장 후보이다.

| 단계 | 메뉴 | 공정 | 특징 |
| --- | --- | --- | --- |
| 시작 | 네기마 (대파 닭꼬치) | 조립+구이 | 튜토리얼 메뉴 |
| 시작 | 모모 (닭다리살) | 조립+구이 | 기본 |
| 시작 | 생맥주 | 드링크 | 첫 미니게임 확장 |
| 확장 | 에다마메 | 즉시 제공 | 노력 0, 회전율용 |
| Lv2 | 츠쿠네 (닭경단, 달걀노른자 디핑) | 성형+구이 | 반죽 빚기(원형 드래그) |
| Lv2 | 카와 (닭껍질) / 난코츠 (연골) | 조립+구이 | 굽기 존이 좁음(고난도) |
| Lv3 | 삼겹살말이 (아스파라거스/방울토마토/깻잎) | 말기+조립+구이 | 재료를 삼겹살로 '말기' 드래그 추가 |
| Lv3 | 하이볼 | 드링크 | 비율 판정 |
| Lv4 | 가라아게 | 반죽+튀김 | 튀김 스테이션 해금 |
| Lv5 | 사시미 모듬 | 슬라이스+플레이팅 | 칼질 판정, 고마진 |
| Lv6 | 오니기리(구운 주먹밥), 츠키미 츠쿠네 등 | 복합 | 후반 확장 |
| Lv7+ | 시즌/이벤트 한정 메뉴 | 복합 | 라이브옵스용 |

# 6. 손님 시스템

## 6.1 좌석과 흐름

- 카운터 6석에서 시작 → 인테리어 업그레이드로 테이블석 추가(최대 12석).
- 프로토타입에서 퇴근 직장인은 항상 2인 그룹, 혼술족은 항상 1인으로 입장한다. 3~4인 그룹은 프로토타입에서 제외한다.
- 퇴근 직장인 2인 그룹은 서로 붙어 있는 좌석 2개가 모두 비어 있을 때 함께 입장한다.
- 주문, 대기 게이지와 만족도는 손님별로 관리한다.
- 퇴근 직장인 2명이 모두 식사를 마치면 함께 퇴장한다.
- **대기 게이지**: 주문 직후 생성. 0이 되면 화내며 퇴장(명성 −, 매출 0). 게이지 잔량에 따라 팁 보너스 차등.
- 퇴장 후 **자리에 빈 접시/잔이 남음 → 좌석별로 각각 탭하여 치우기** 전까지 해당 좌석에 새 손님이 앉지 못한다.

## 6.2 손님 타입 (성격 파라미터: 인내심 / 주문량 / 팁 / 추가주문률)

| 타입 | 특징 |
| --- | --- |
| 퇴근 직장인 무리 | 주문량 많음, 인내심 보통, "일단 생맥" 선주문 후 안주 추가 |
| 혼술족 | 1~2개 소량, 인내심 높음, 단골화 확률 높음 |
| 커플 | 플레이팅 판정 가중치↑ (보기 좋은 요리에 만족도 보너스) |
| 외국인 관광객 | 랜덤/오마카세 주문, 팁 큼 |
| 미식 블로거 | Perfect 요구. 성공 시 리뷰로 다음 날 손님 수 +%, 실패 시 −% |
| 취객 | 인내심 매우 낮음, 이벤트 유발 (7장) |
| 단골 | 스토리 보유, "늘 먹던 걸로" 주문 (7장) |

프로토타입에서는 퇴근 직장인과 혼술족 2종만 사용한다. 다른 손님 유형과 장기 단골 호감도·다회차 에피소드는 확장 범위로 둔다.

## 6.3 만족도 & 추가 주문

- 만족도는 손님별로 계산하며 추가 주문 확률과 명성 획득에만 영향을 준다.
- **추가 주문 확률 = f(만족도)**: 예) 만족도 80 이상 시 60%, 50~79 시 30%, 그 이하 0%.
- 팁은 만족도나 품질이 아니라 대기 게이지 잔량과 손님 유형을 기준으로 계산한다.

# 7. 추가 재미 요소 (제안)

프로토타입 이후 기존 기획에 얹을 수 있는 확장 제안이다. **(P1)은 우선 검토, (P2)는 장기·라이브 업데이트 후보**를 뜻한다. 직원·자동화, 장기 단골 이야기, 시즌·라이브 이벤트와 본격적인 가게 꾸미기는 프로토타입에서 제외한다.

1. **(P1) 숯불 화력 관리** — 굽기 스테이션에 '부채질'이라는 유지 관리 행동을 추가해, 단순 타이밍 게임이 아니라 자원(화력) 관리 게임으로 확장. 후반에는 숯 등급(비장탄) 업그레이드로 완화 가능.
2. **(P1) 단골 & 스토리 시스템** — 특정 조건(만족도 높은 서빙 n회)을 채우면 손님이 단골로 승급. 단골마다 짧은 에피소드(할아버지와의 인연 등)가 해금되고, 호감도 레벨에 따라 팁 배율·특수 주문이 열린다. 단골은 메뉴 이름 없이 **"늘 먹던 걸로"** 라고만 주문 → 플레이어의 기억력 테스트(힌트 보기는 광고/재화 소모).
3. **(P1) 러시아워 곡선** — 한 영업일 안에 오픈 직후(한산) → 퇴근 러시(피크) → 마감 전 취객 타임으로 손님 밀도가 변화. 긴장-이완 리듬을 만든다.
4. **(P1) 콤보 & 명성** — 연속 Perfect 서빙 시 콤보 게이지 상승 → 팁 배율만 증가하며 최대 `×1.5`. Fail 시 리셋. 영업 종료 시 별점 리뷰(1~5성)가 다음 날 손님 수와 고급 손님 등장률에 반영.
5. **(P2) 오마카세 주문** — 손님이 메뉴명이 아니라 힌트("바삭하고 짭짤한 거", "불맛 나는 거")로 주문. 추론해서 맞는 메뉴를 서빙하면 큰 보너스. 관광객/미식가 타입 전용.
6. **(P2) 진상/취객 이벤트** — 취객이 테이블을 두드리며 다른 손님들의 대기 게이지 감소 디버프를 건다 → **물 한 잔을 빠르게 서빙**하면 진정. 마감 타임의 스파이스 이벤트.
7. **(P2) 날씨/요일 시스템** — 비 오는 날: 손님 수↓ 인내심↑ (연습하기 좋은 날), 금요일/축제날: 대량 러시 + 매출 배율. 영업 전 '오늘의 예보'로 전략적 준비(메뉴 슬롯, 직원 배치) 유도.
8. **(P2) 가게 고양이 '스미(炭)'** — 가게 앞을 지키는 마스코트 고양이. 영업 전 쓰다듬으면(드래그) 랜덤 버프 1개(화력 유지력↑, 팁↑ 등). 꾸미기 아이템 판매 포인트 & SNS 감성 요소.
9. **(P2) 가게 꾸미기** — 노렌(포렴), 제등, 간판, 좌석, 벽 장식. 외형 변화 + 소폭 버프(수용 인원, 특정 손님 타입 유입률). 스크린샷 공유 유도.
10. **(P2) 단체 회식 예약** — 하루 전 예약이 잡히고, 다음 영업일에 8인 단체가 대량 주문. 고위험 고수익 미션형 콘텐츠.

# 8. 경제 & 성장 시스템

## 8.1 재화

| 재화 | 획득 | 사용처 |
| --- | --- | --- |
| 골드 (소프트) | 영업 매출, 팁, 미션 | 메뉴 해금, 장비/인테리어 |
| 명성 별 (진행도) | 별점 리뷰, 단골 이벤트 | 명성 레벨업 → 메뉴/콘텐츠 해금 게이트 |
| 다이아 (하드) | 업적, 출석, IAP | 시간 단축, 한정 스킨, 힌트, 직원 슬롯 |

## 8.2 업그레이드 축 (4개)

1. **재료 등급업**: 같은 메뉴라도 원물 등급에 따라 기본 판매가가 상승한다. 재료는 등급만 가지며 보유 수량·소진·보충은 관리하지 않는다.
2. **장비**: 그릴 슬롯 확장(동시에 굽는 꼬치 수 2→6), 자동 회전 석쇠(뒤집기 1회 자동), 온도계(튀김 Perfect 존 시각화).
3. **메뉴 해금**: 레시피 노트 복원(골드 + 명성 레벨 조건).
4. **인테리어**: 좌석 수, 손님 인내심 보정, 특정 손님 유입.

## 8.3 직원 & 자동화

- 명성 Lv4부터 고용 가능. 슬롯: **드링크 담당 / 튀김 담당 / 홀 서빙(자동 서빙·자리 치우기)** 등 스테이션 전담 배치.
- 직원 파라미터: 속도 / 품질 상한(초기엔 Good까지만 생산) / 급여(영업일당 차감).
- 직원은 경험치로 숙련도 성장 → 최고 레벨에서 Perfect 확률 보유. **"직접 하면 더 잘하지만, 손이 두 개뿐"** 이라는 트레이드오프가 설계 핵심.
- 후반 지향점: 플레이어는 가장 어렵고 마진 높은 스테이션(그릴/사시미)에 집중하고 나머지는 자동화.

## 8.4 밸런스 스케치 (예시 수치, 프로토타입에서 조정)

- 1영업일 목표 매출: 초반 500G → 30일차 15,000G.
- 메뉴 해금 비용: 다음 등급 메뉴 = 직전 3~5 영업일 순이익 수준.
- Fail은 판매가 감액 또는 판매 실패로 처리하며 재료 재고 손실은 계산하지 않는다.
- 한 주문의 판매가와 팁을 합친 최종 수익은 기본 판매가 대비 최대 `×2.0`이다.

# 9. 사용자 시나리오

## 9.1 신규 유저 — D1 (튜토리얼)

1. 오프닝: 열쇠와 레시피 노트를 받는 짧은 컷. 스토리 장면은 모두 건너뛸 수 있다.
2. 첫 손님은 할아버지의 옛 단골인 혼술족으로 등장한다. 네기마 1개 주문 → 가이드 따라 **끼우기 → 굽기 → 뒤집기 → 서빙**을 드래그로 체험한다.
3. 퇴근 직장인 2인 그룹이 붙어 있는 좌석에 함께 입장하고 생맥주를 주문한다. 따르기 미니게임과 손님별 주문·대기 관리를 학습한다.
4. 첫 정산: 매출 + 별점 + "레시피 노트 한 장이 복원되었습니다!" (모모 해금) → 성장 루프 인지.
5. D1 종료 시점 목표: 메뉴 3종 보유, 다음 해금 목표가 화면에 보이는 상태로 이탈.

첫 영업일 전체는 튜토리얼과 기본 스토리를 포함해 최대 8분으로 제한한다.

## 9.2 중반 유저 — D7

- 메뉴 7종, 카운터 8석, 그릴 슬롯 4. 러시아워에 3~4팀 동시 대응.
- 오늘의 선택: 하이볼 해금(1,200G) vs 닭고기 등급업(1,000G) → 자기 플레이스타일에 따른 빌드 분기.
- 단골 '츠키오카 씨' 호감도 3 달성 → 에피소드 해금 + "늘 먹던 걸로" 주문 시작.

## 9.3 후반 유저 — D30

- 직원 2명(드링크·튀김) 배치, 본인은 그릴과 사시미에 집중.
- 금요일 단체 회식 예약 수행 → 최고 매출 갱신 → 인테리어 리뉴얼로 별 4.5 달성.
- 시즌 한정 메뉴 이벤트 참여, 가게 스크린샷 SNS 공유.

# 10. 보상 & 리텐션 설계

| 장치 | 내용 | 주기 |
| --- | --- | --- |
| 영업 정산 보상 | 매출 + 팁 + 별점 → 즉각 피드백 | 매 세션 |
| 일일 미션 | 예: "Perfect 굽기 5회", "하이볼 3잔 판매" → 골드/다이아 | 매일 |
| 주간 미션 | 누적 매출/단골 이벤트 → 다이아, 한정 장식 | 매주 |
| 업적/배지 | "꼬치 1,000개 굽기", "거품 비율 완벽 100회" 등 수집 요소 | 상시 |
| 요리사 랭크 | 계정 레벨. 랭크업 시 다이아 + 칭호 | 장기 |
| 단골 스토리 | 다음 에피소드가 궁금하게 만드는 서사형 리텐션 | 격일~주간 |
| 출석 보상 | 7일 사이클, 7일차에 프리미엄 재화 | 매일 |

**보상 원칙**: 즉각 보상(정산) → 단기 목표(일일 미션) → 중기 목표(해금/등급업) → 장기 목표(별 5성 가게, 스토리 완결)의 4중 루프가 항상 동시에 보이도록 UI 설계.

# 11. 조작(UX) 정의

| 행동 | 입력 |
| --- | --- |
| 재료 끼우기 / 서빙 / 잔 대기 | 드래그 & 드롭 |
| 꼬치 뒤집기 | 좌우 스와이프 |
| 타레 바르기 / 반죽 젓기 / 칼질 | 경로 드래그 |
| 맥주 따르기 | 홀드 + 각도 드래그 |
| 부채질 / 자리 치우기 / 고양이 쓰다듬기 | 탭(연타) / 탭 / 드래그 |
| 스테이션 전환 | 하단 탭 또는 좌우 스와이프 |
- 원버튼(원터치) 원칙: 메뉴 화면 포함 어떤 화면에서도 두 손가락 제스처·물리 버튼 불필요.
- 대기 게이지·주문 말풍선과 각 스테이션 진행 상태는 상단 고정 상태 바에 항상 노출한다.

## 11.1 화면과 지원 환경

- 모바일 브라우저는 가로 화면으로 고정한다.
- PC는 `16:9`, `1920×1080`을 중심으로 반응형 가로 화면을 구성하며 최소 `1280×720`까지 지원한다.
- 모바일 기준 환경은 최신 Android Chrome과 iOS Safari다.
- PC 기준 환경은 Chrome과 Edge다.

## 11.2 저장과 중단 복귀

- 브라우저 로컬 저장소를 사용하며 영업일 시작과 정산 완료 시 자동 저장한다.
- 탭이 백그라운드로 전환되면 게임과 모든 조리·손님 타이머를 일시 정지한다.
- 같은 탭으로 돌아오면 시간 경과를 적용하지 않고 중단 지점에서 즉시 재개한다.
- 영업 도중 새로고침하거나 브라우저를 종료하면 해당 영업일 시작 시점부터 재개한다.
