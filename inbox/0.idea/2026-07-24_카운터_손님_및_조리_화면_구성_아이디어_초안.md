## 1. 화면 기획의 우선순위와 기준 환경

- 현재 단계에서는 PC 데스크톱 화면을 최우선으로 기획하고, 모바일 화면으로의 전환과 모바일 최적화는 가장 후순위로 둔다.
- 기준 환경은 FHD 모니터와 Chrome 브라우저다.
- 입력된 화면 비율은 `16:8 FHD`이지만, 일반적인 FHD 해상도 `1920×1080`은 `16:9`이므로 후속 정제 시 목표 화면 비율과 기준 해상도를 최종 확인해야 한다.
- 화면 구성, 카메라 프레이밍, UI 정보 밀도와 에셋 제작은 확정된 데스크톱 기준 해상도를 우선하여 진행한다.

## 2. 가게 내부의 공간 설정

- 플레이어는 바 테이블 안쪽에 서서 일하는 주인공의 1인칭 관점으로 가게를 바라본다.
- 손님들은 바 테이블 건너편에 일렬로 앉는다.
- 모든 조리 기구는 손님 반대편인 주인공 쪽에 있으며, 바 테이블에 바로 붙어 있는 작업 공간에 배치한다.
- 손님을 보는 방향, 고개를 숙여 야키토리 불판을 보는 방향, 옆으로 고개를 돌려 주류 도구를 보는 방향이 하나의 실제 공간 안에서 자연스럽게 이어져야 한다.
- 화면마다 카메라가 독립적으로 구성되더라도 바 테이블의 높이와 깊이, 손님 좌석 간격, 조리 기구의 위치 관계는 동일한 공간 좌표를 기준으로 유지한다.

## 3. 손님 정보 화면

손님 정보 화면은 손님 응대와 현재 홀 상황 파악에 집중하는 독립 화면이다.

- 바 테이블 건너편에 앉은 손님들을 좌석 순서대로 명확하게 보여준다.
- 각 손님의 외형과 상태, 해당 손님이 주문한 음식 목록, 현재 손님 앞에 놓여 먹고 있는 음식을 한눈에 구분할 수 있어야 한다.
- 주문 대기, 식사 중, 추가 주문 가능, 식사 완료와 같은 손님 상태를 음식 및 주문 데이터와 함께 명확하게 표현한다.
- 화면의 중심 정보는 배경 장식보다 손님 데이터다. 여러 손님이 동시에 있어도 어떤 주문과 음식이 어느 손님에게 속하는지 혼동되지 않아야 한다.
- 손님이 먹고 있는 음식은 단순 UI 아이콘으로만 표시하지 않고, 손님 앞 바 테이블 위에도 실제 음식 에셋으로 놓여 있어야 한다.
- 바 테이블 위 음식, 테이블 표면, 손님의 몸과 좌석은 주인공이 바라보는 관점에서 크기와 겹침 순서가 자연스러워야 한다.
- 바 테이블 모서리와 음식 접시, 좌석 및 배경의 선이 동일한 소실점 체계를 따라야 하며, 음식이 테이블 위에 떠 있거나 기울어 보이지 않아야 한다.

## 4. 손님 화면과 조리 화면의 분리

- 손님 정보 화면과 조리 화면은 목적과 상호작용이 다른 별개의 화면 상태로 완전히 분리한다.
- 손님 정보 화면에서는 손님, 주문, 식사 상태와 서빙 결과를 확인한다.
- 조리 화면에서는 조리 도구와 직접 조작할 음식에 집중한다.
- 조리 화면에 표시하는 주문 정보는 손님 정보 화면 전체를 중복 표시하지 않고, 조리에 필요한 최소 정보만 담은 참조용 주문서로 제한한다.
- 화면을 전환해도 손님별 주문, 조리 진행 상태와 준비 완료 음식의 상태는 그대로 유지한다.

## 5. 조리 화면의 공통 정보 구조

각 조리 화면은 다음의 공통 구조를 가진다.

### 5.1 상단 주문서 영역

- 화면 상단에는 현재 손님들의 주문 정보를 영수증 모양의 카드로 표시한다.
- 주문서 카드는 바 테이블 건너편의 실제 좌석 배치와 같은 순서로 일렬 배치한다.
- 빈 좌석은 빈 간격 또는 명확한 비활성 슬롯으로 유지하여, 주문서 카드의 위치가 실제 손님 좌석과 어긋나지 않게 한다.
- 각 주문서에는 좌석 식별, 주문 메뉴, 수량, 진행 상태와 대기 상태처럼 조리에 필요한 정보를 표시한다.
- 어떤 조리 화면으로 전환하더라도 주문서의 좌석 순서와 위치는 유지하여 빠르게 손님과 주문을 대응할 수 있게 한다.

### 5.2 중앙 조리 영역

- 현재 선택한 조리 도구와 조작 대상 음식이 화면의 중심이 된다.
- 조립, 굽기, 주류 등 조리 도구별 화면은 서로 독립된 조리 스테이션으로 존재한다.
- 각 스테이션은 자체 카메라, 조작 대상과 진행 상태를 가지며, 다른 스테이션으로 이동해도 진행 중인 상태가 보존된다.

### 5.3 하단 준비 목록

- 각 조리 화면의 하단에는 조리가 끝났지만 아직 서빙하지 않은 음식과 음료를 준비 목록으로 표시한다.
- 어느 스테이션에서 만든 음식이든 준비가 완료되면 공통 준비 목록에서 확인할 수 있어야 한다.
- 준비 목록의 각 항목은 메뉴 종류, 수량, 품질 또는 상태, 제공할 손님이나 주문을 구분할 수 있어야 한다.

## 6. 조리 스테이션과 빠른 전환

- 최소 구성은 꼬치 조립 화면, 야키토리 굽기 화면, 주류 화면으로 나눈다.
- 이후 추가되는 조리 도구도 동일한 원칙에 따라 독립 화면으로 구성한다.
- 플레이어는 조리 중에도 각 스테이션으로 빠르게 전환할 수 있어야 한다.
- 전환 조작은 모든 스테이션에서 같은 위치와 방식으로 제공하고, 현재 스테이션과 다른 스테이션의 진행 또는 위험 상태를 즉시 알 수 있게 한다.
- 화면 전환은 메뉴 화면을 여는 느낌보다 주인공이 실제 작업 공간에서 시선을 옮기는 느낌을 우선한다.

전환 예시는 다음과 같다.

1. 정면을 보면 바 테이블 건너편에 손님들이 일렬로 앉아 있다.
2. 아래로 고개를 숙이면 바 테이블 주인공 쪽에 붙어 있는 야키토리 불판이 중심에 들어온다.
3. 옆으로 고개를 돌리면 주류 제조 도구와 잔이 배치된 주류 화면으로 이어진다.
4. 다른 조리 도구도 주인공을 중심으로 한 실제 위치와 방향에 맞춰 전환한다.

## 7. 카메라, 원근감과 에셋 제작 원칙

- 손님 정보 화면과 각 조리 화면은 모두 고정된 1인칭 카메라 프리셋을 사용한다.
- 각 화면은 독립적으로 제작하되, 주인공의 눈높이와 위치, 바 테이블의 기준 치수, 공통 소실점과 조리 도구의 실제 배치를 공유한다.
- 화면 전환 전후에 테이블 높이, 작업대 깊이, 사물의 크기와 좌우 방향이 갑자기 달라져서는 안 된다.
- 손님 화면에서 보이던 바 테이블과 조리 화면의 작업대가 동일한 공간의 같은 구조물로 인식되어야 한다.
- 음식, 접시, 불판, 주류 도구 등 테이블 위 에셋은 각 카메라 프리셋의 원근에 맞춰 배치하고, 배경 이미지에 그려진 기준선과 3D 조작 에셋의 투영이 어긋나지 않게 한다.
- 에셋 제작 전에 공통 공간 배치도와 카메라별 소실점 가이드를 먼저 만들고, 모든 배경 및 오브젝트 에셋이 이를 참조하게 한다.

## 8. 후속 정제 시 확인할 항목

- `16:8 FHD`가 실제 목표 비율인지, `16:9 1920×1080 FHD`를 의미하는지 확인한다.
- 손님 화면에서 손님별로 항상 노출할 데이터와 상황에 따라 숨길 데이터를 정한다.
- 조리 화면 상단 주문서에 표시할 필수 정보와 카드의 최대 개수를 정한다.
- 빈 좌석이 있을 때 주문서 카드의 좌석 대응 방식을 확정한다.
- 준비 목록에서 음식과 주문을 자동 연결할지, 플레이어가 제공 대상을 직접 선택할지 정한다.
- 스테이션 퀵 전환의 입력 방식과 전환 시간, 조리 중 타이머 처리 규칙을 정한다.
- 공통 공간 배치도, 카메라 높이, 화각, 화면별 카메라 회전값과 소실점을 수치로 확정한다.
