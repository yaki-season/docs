# 개선·버그·모순 기록

이 디렉토리는 사람이 개발 중 또는 개발 후 발견한 개선사항, 식별된 버그, 요구사항과 구현의 모순, 누락된 동작을 기록하는 공식 입력 창구다.

## 기록 대상

- 사용자 경험 또는 개발 방식의 개선 제안
- 재현되거나 관찰된 버그
- 서로 다른 요구사항 사이의 모순
- `spec/`과 `app` 구현 사이의 불일치
- `epic/` 작업에서 빠진 범위
- 구현 완료 후 발견된 후속 수정사항

## 작성 방법

파일명은 `YYYY-MM-DD-짧은-제목.md` 형식을 권장한다.

새 기록은 `template/inbox_변경요청_템플릿.md`를 복사해 작성하고 상태를 `접수`로 둔다. 긴 회의록이나 소스코드 전문을 붙이지 말고, 관찰한 현상과 원하는 결과를 분리해서 적는다.

## 처리 흐름

```text
사람이 변경사항 기록
  → AI가 중복·충돌·영향 분석
  → 관련 spec 상세 설계 갱신
  → 대기·진행 중 epic 태스크 즉시 반영
  → 필요하면 새 epic 태스크 생성
  → epic/작업_현황.md 갱신
  → app에서만 구현 및 운영 반영
```

세부 절차는 `template/AI_변경사항_반영_파이프라인.md`를 따른다.
