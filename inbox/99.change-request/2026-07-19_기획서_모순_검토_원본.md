## 남은 상세 설계 쟁점

- 탭·홀드·스와이프·드래그를 포함하는 한 손가락 조작 원칙과 기기별 제스처 임계값
- 2D 배경 레이어 수, 패럴랙스 범위와 비조작 대상의 2D·3D 표현 기준
- 여러 스테이션이 동시에 위험할 때 경고 우선순위와 난이도 상한
- 품질 판정 단계별 판매가 배율, 기본 팁 수치와 Fail 처리 기준
- 좌석 정리 조작과 소요 시간
- 레시피 복원, 명성 조건과 골드 해금 사이의 역할 구분
- 로컬 저장 데이터 스키마, 마이그레이션과 손상 복구 방식
- 최소 브라우저 버전, 기준 기기와 성능·발열 검증 조건
- 광고 기반 실패 복구의 범위와 주류 표현 관련 연령·지역 정책

상세 설계로 확정할 때 관련 `spec/` 문서에 요구사항과 근거를 기록한다.
