## 배경

2026-07-25에 제작한 손님 유형·6석 영업 화면과 핵심·후속 조리 스테이션 컨셉아트에서 다음 특징이 좋은 결과로 확인됐다.

- 생성형 이미지 특유의 매끈하고 균일한 표면보다 사람이 연필·잉크·과슈로 여러 차례 손본 듯한 흔적이 남는다.
- 따뜻한 일본 가족 애니메이션의 정서적 친근함은 가지되 특정 스튜디오·작품·작가의 고유 화풍을 복제하지 않는다.
- 오래된 야키토리 가게의 목재·종이·황동·도자기와 인물의 표정이 같은 재료감과 조명 안에 존재한다.
- 픽셀은 단순한 저해상도 필터가 아니라 손으로 정리한 덩어리와 계단형 윤곽으로 보인다.
- 밤의 짙은 남색과 실내의 호박색 조명이 분리되어 어둡지만 답답하지 않고 음식과 얼굴이 또렷하다.

이 스타일을 향후 배경, 캐릭터, 음식, 도구, 스테이션, UI 아이콘, VFX와 홍보용 일러스트까지 일관되게 적용하는 공통 품질 기준으로 삼고 싶다.

## 핵심 시각 언어

### 1. 선과 형태

- 연필 밑그림이 일부 비치고 그 위에 약간 불균일하지만 의도적인 잉크선을 얹는다.
- 윤곽선 굵기는 얼굴·손·음식·도구의 중요도와 빛 방향에 따라 달라진다.
- 완벽한 좌우 대칭, 반복 복제된 얼굴, 자로 그은 듯한 동일 두께 선을 피한다.
- 인물은 얼굴형·눈매·코·입·주름·손·자세를 함께 다르게 설계한다.
- 소품과 가구에는 사용 흔적, 모서리 닳음, 손때와 작은 비대칭을 남긴다.

### 2. 채색과 표면

- 불투명 과슈를 여러 번 덧칠한 듯한 면과 붓자국을 기본으로 한다.
- 종이 결, 안료 농도 차이, 마른 붓의 끊긴 가장자리와 작은 색 번짐을 제한적으로 사용한다.
- 금속·유리·음식도 사진처럼 반짝이게 만들지 않고 같은 회화 재료 안에서 표현한다.
- 그라디언트만으로 입체를 만들지 않고 2~4단계의 명확한 명암 덩어리와 선택적 하이라이트를 사용한다.
- 모든 영역을 같은 밀도로 채우지 않고 얼굴·음식·조작 대상에 가장 높은 정보 밀도를 둔다.

### 3. 픽셀 마감

- 최종 픽셀은 임의 노이즈나 단순 축소 결과가 아니라 형태를 설명하는 덩어리로 정리한다.
- 외곽은 계단형 리듬을 의도적으로 만들고, 내부 질감은 큰 덩어리를 깨지 않는 범위에서만 넣는다.
- 캐릭터 얼굴과 손, 음식 가장자리, 조작 도구는 실제 표시 크기에서 다시 수작업으로 정리한다.
- 최근접 축소에서도 눈매·안경·음식 종류·도구의 잡는 부분이 유지되어야 한다.

## 색감과 조명

### 기본 관계

- 주광: 제등·숯불·실내등의 호박색과 황갈색.
- 환경색: 깊은 남색·인디고의 밤과 창밖.
- 중간색: 오래된 목재의 짙은 갈색, 이끼색, 탁한 버건디, 종이의 크림색.
- 강조색: 좌석·주문·품질 상태에 사용하는 제한된 빨강·파랑·초록·보라·주황.

### 운용 원칙

- 화면 전체를 주황색 필터로 덮지 않고 따뜻한 빛과 차가운 밤을 동시에 유지한다.
- 밤 장면이더라도 얼굴, 음식과 조작 대상의 중간 명도는 확보한다.
- 가장 밝은 값은 램프 중심, 맥주 거품, 윤기와 선택 피드백에 제한한다.
- 검정은 완전한 단색보다 남색·짙은 갈색을 섞어 목재와 그림자를 구분한다.
- 음식의 구운 갈색이 목재에 묻히지 않도록 접시·림라이트·가니시 중 하나로 분리한다.
- 성장 뒤에도 과도하게 하얗거나 현대적인 매장 조명으로 바꾸지 않는다.

## 캐릭터 품질 원칙

- 같은 눈·코·턱을 헤어스타일만 바꿔 반복하지 않는다.
- 나이는 주름뿐 아니라 목·어깨·손·앉는 자세와 동작 폭으로 표현한다.
- 감정은 얼굴과 자세 중 최소 두 요소가 함께 변해야 한다.
- 손은 손가락 수와 관절 방향을 확인하고 컵·꼬치·메뉴와 실제로 접촉하게 한다.
- 직업·연령·음주 상태를 과장된 고정관념으로 표현하지 않는다.
- 피부와 얼굴은 매끈한 플라스틱 음영 대신 짧은 선, 제한된 색면과 작은 비대칭으로 마감한다.
- 인물별 대표색은 전체 팔레트 안에서 탁도를 공유하고 네온처럼 튀지 않게 한다.

## 배경·스테이션·소품 품질 원칙

- 배경은 생활 흔적과 공간 깊이를 주되 조작 대상보다 대비와 선 밀도를 한 단계 낮춘다.
- 스테이션은 사용 순서가 배치와 광원만으로 읽히고, 화살표·손 커서가 없어도 핵심 도구가 식별되어야 한다.
- 3D 조작물은 지나치게 매끈한 PBR 외형을 피하고, 손으로 칠한 base color·거친 roughness·제한된 하이라이트·그림형 접지로 2D 배경과 연결한다.
- UI 아이콘과 VFX도 같은 붓·종이·픽셀 언어를 축약해 사용하되 기능 가독성을 질감보다 우선한다.
- 생성 이미지 안에는 의미 텍스트, 틀린 문자, 워터마크, 서명과 가짜 로고를 넣지 않는다.

## 제작 흐름 아이디어

1. 제작을 시작하기 전에 `YS-HANDCRAFTED-NIGHT-v1`과 가장 가까운 기준 이미지 2~4장을 선택한다.
2. 새 컨셉은 같은 색·선·재료 언어를 명시한 공통 스타일 프롬프트와 에셋별 기능 프롬프트를 분리해 작성한다.
3. 캐릭터·배경·음식·도구를 같은 장면에 사용할 경우 가능한 한 같은 세션 또는 같은 기준 원본에서 제작한다.
4. 생성 또는 초벌 제작 뒤 다음 수작업 마감 패스를 수행한다.
   - 해부·손·접촉 관계 수정
   - 반복 얼굴·반복 소품 제거
   - 가짜 문자·워터마크 제거
   - 광원과 그림자 방향 통일
   - 과도한 매끈함·그라디언트 제거
   - 연필·잉크·과슈·종이 질감 보강
   - 실제 표시 크기의 픽셀 클러스터 재정리
5. 기준 이미지와 신규 결과를 같은 크기로 놓고 선, 채색, 색감, 재료, 밀도와 인물 개성을 비교한다.
6. 기능·화풍 검수를 통과한 결과만 `approved` 후보로 올리고 프롬프트·참조·후처리 내역을 provenance에 기록한다.

## 적용 범위 제안

- 이 기준은 앞으로 새로 만들거나 교체하는 모든 게임 아트와 리뷰 컨셉에 적용한다.
- 기존 승인 에셋은 즉시 일괄 폐기하지 않고, 교체·확장·회귀 검수 시 새 기준과의 차이를 기록한다.
- 회색 박스, 충돌 영역, 데이터 mask 같은 개발용 비표시 자산은 회화 마감 대상에서 제외한다.
- 접근성·입력 가독성과 성능 예산은 화풍보다 우선하며, 질감을 줄이더라도 실루엣·색 관계와 픽셀 리듬은 유지한다.

## 미해결 질문

1. 캐릭터 초상을 고해상도 과슈 원화로 만든 뒤 픽셀화할지, 처음부터 픽셀 크기로 그릴지.
2. 3D 모델의 외곽선과 손그림 흔들림을 texture로만 표현할지 셰이더도 사용할지.
3. 최종 팔레트를 고정 swatch로 제한할지 장면별로 명도·채도를 허용할지.
4. 수작업 마감 검수를 Artist 1인 승인으로 끝낼지 2인 교차 검수로 운영할지.
