# 2.art-concept

비주얼 방향성, 캐릭터, 배경, 소품, 색감, 분위기, 레퍼런스 이미지를 정리한다.

## 현재 이미지 분석

- 공통 시각 언어는 따뜻한 주황색 숯불과 조명, 짙은 남색 야간 배경, 목재와 종이 질감, 저해상도 픽셀 아트다.
- 가게 외관과 내부, 영업 화면, 꼬치 조립·그릴·드링크 스테이션, 품질 판정, 영업 루프와 성장 화면까지 큰 방향은 확보되어 있다.
- 2D 배경과 픽셀 셰이딩된 3D 조작 오브젝트를 혼합하는 2.5D 방향도 확인할 수 있다.
- 일부 탐색 이미지에는 이전 상호인 `鳥屋/Toriya`, 프로토타입 범위 밖의 취객·다수 손님·확장 메뉴가 포함되어 있다. 이 요소는 구현 기준이 아니라 초기 탐색 자료로만 취급한다.
- 확정 상호는 `炭火やきとり とり暦`, 게임 제목은 `YAKI SEASON(야키 시즌)`이다.
