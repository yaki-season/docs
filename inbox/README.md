# inbox

정식 요구사항으로 확정되기 전의 입력 자료를 모아두는 공간이다.

개발 전 입력뿐 아니라 `app` 구현 중이나 구현 후 발견된 개선사항, 수정사항과 결함도 이곳에 기록한다.

자세한 운영 기준은 `AGENTS.md`와 `운영_원칙.md`를 따른다. AI 파이프라인으로 처리할 변경사항은 `template/inbox_변경요청_템플릿.md` 사용을 권장한다.

## 하위 분류

- `0.idea/`: 초기 아이디어
- `1.design/`: 게임 디자인 초안
- `2.art-concept/`: 아트 콘셉트
- `3.reference/`: 참고자료
- `99.change-request/`: 사람이 기록하는 개선사항, 식별된 버그, 모순과 후속 수정 요청
