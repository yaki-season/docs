# inbox

사람이 직접 작성하거나 첨부한 정제되지 않은 원본 데이터(raw data)를 모아두는 공간이다.

아이디어 메모, 회의 원문, 대화 기록, 스케치, 참고 이미지처럼 불완전하거나 중복되고 서로 모순될 수 있는 자료도 원본 그대로 넣는다. 개발 전 입력뿐 아니라 `app` 구현 중이나 구현 후 발견된 개선사항, 수정사항과 결함도 포함한다.

AI는 이 디렉토리의 사람 입력 데이터를 수정·이동·삭제하지 않는다. 정리·정제된 결과는 `spec/`에 작성하며, 처리 이력은 `spec/meta/inbox_처리_이력.md`에서 관리한다.

자세한 운영 기준은 `AGENTS.md`와 `운영_원칙.md`를 따른다. 사람이 변경사항을 조금 더 자세히 남기고 싶을 때만 `template/inbox_변경요청_템플릿.md`를 선택적으로 사용한다.

## 하위 분류

- `0.idea/`: 초기 아이디어
- `1.design/`: 게임 디자인 초안
- `2.art-concept/`: 아트 콘셉트
- `3.reference/`: 참고자료
- `99.change-request/`: 사람이 기록하는 개선사항, 식별된 버그, 모순과 후속 수정 요청
