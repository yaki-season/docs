# inbox AI 작업 지침

## 목적

`inbox/`는 사람이 직접 넣는 정제되지 않은 원본 데이터(raw data)의 보관 영역이다. 개발 전 자료뿐 아니라 `app` 구현 중이나 구현 후 발견된 개선사항, 버그와 모순도 원본 상태로 수집한다.

## 사람 입력 원칙

- 형식, 파일명, 길이와 완성도를 강제하지 않는다.
- 한 줄 메모, 회의·대화 원문, 스크린샷, 불완전한 생각과 상충하는 의견도 넣을 수 있다.
- 내용이 중복되거나 틀릴 수 있으며, 입력 시점에 정리하거나 확정할 필요가 없다.
- 비밀번호, 접근 토큰, 개인정보처럼 저장하면 안 되는 민감정보는 넣지 않는다.
- 개발 중·개발 후 발견한 개선사항, 버그와 모순은 `99.change-request/`에 넣는다.

## AI 읽기 전용 원칙

- AI는 사람이 넣은 원본 파일을 수정·이동·이름 변경·삭제하지 않는다.
- AI는 원문에 상태, 판단, 링크 또는 처리 결과를 덧붙이지 않는다.
- AI는 `inbox/`만 보고 구현하지 않는다.
- 분석·정제한 결과는 관련 `spec/` 문서에 작성한다.
- 처리 여부와 판단 결과는 `spec/meta/inbox_처리_이력.md`에 기록한다.
- `README.md`와 `AGENTS.md`는 운영 지침이며 원본 데이터 처리 대상에서 제외한다.

## AI 생성 초안 예외

- 사용자가 AI에게 아이디어·기획·시나리오 초안을 `inbox/`에 작성하라고 명시적으로 요청한 경우에만 AI가 새 원본 파일을 생성할 수 있다.
- AI는 새 파일만 생성하며 기존 사람이 작성한 원본 파일을 수정·이동·이름 변경·삭제하지 않는다.
- AI가 만든 파일에는 생성일, 생성 주체, `미정제 원본` 또는 `초안` 상태와 아직 요구사항으로 확정되지 않았다는 안내를 적는다.
- 초안 작성 요청만으로 `spec/`, `spec/meta/`, `epic/`을 생성·수정하지 않는다.
- 사용자가 별도로 `spec` 또는 `epic` 반영을 명시하기 전까지 초안은 `inbox/`에만 보관한다.
