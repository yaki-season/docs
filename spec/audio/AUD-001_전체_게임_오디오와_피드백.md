## 목적

따뜻한 저녁 골목과 숯불 가게의 분위기를 유지하면서 조리 타이밍, 물건의 무게, 화면 밖 위험과 결과를 소리로도 정확히 전달한다. 오디오는 화면을 보조하되 무음 플레이를 막는 유일한 정보 채널이 되지 않는다.

## 범위

### 포함

- BGM, 골목·가게 환경음, 조리·도구·UI SFX
- 화면 밖 위험과 판정 알림의 우선순위
- 스테이션 전환, 일시정지, 중단 복귀와 믹싱
- 음소거·음량 설정과 무음 접근성

### 제외

- 캐릭터 전체 음성 더빙
- 최종 음원 파일·코덱·샘플레이트
- 주크박스·리듬 보너스와 외부 음악 서비스

## 상세 요구사항

상세 규칙은 음악, 환경음, 조리·UI SFX, 이벤트와 믹싱 영역을 함께 적용한다.

## 오디오 방향

1. 기본 분위기는 따뜻하고 절제된 로파이 BGM, 저녁 골목과 작은 목조 가게의 생활음이다.
2. 음악은 조리 타이밍보다 앞에 나오지 않고 숯불·레버·도자기·손님 반응 소리가 읽힐 공간을 남긴다.
3. 결과는 과장된 슬롯머신·승리 팡파르보다 음식·도구·손님의 작은 반응으로 전달한다.
4. 술 주문은 축배·폭음 경쟁보다 하루를 마치는 일상의 맥락으로 표현한다.

## BGM과 환경음

| 상태 | 요구사항 |
|---|---|
| S0 골목 | BGM을 억제하고 전철·젖은 타이어·먼 가게 소리·열쇠를 강조 |
| 준비 | 낮은 로파이 시작, 부채·숯 점화가 리듬을 이끔 |
| 한산 영업 | 기본 테마, 조리 SFX 공간 확보 |
| 러시 | 템포·레이어를 늘리되 별도 곡 전환으로 끊지 않음 |
| 마감 | 신규 주문이 멈추며 레이어를 줄이고 잔·식기·숯 소리를 강조 |
| 정산·노트 | 조용한 변주, 숫자 효과음보다 페이지·연필을 강조 |
| D30 종료 | 팡파르 대신 조용해진 카운터 뒤 다음 날 테마로 연결 |

5. 골목 환경음은 가게 내부에서 낮게 유지하고 문 열림·닫힘 때 짧게 밝아진다.
6. 손님 군중음은 실제 좌석 수와 러시 단계에 따라 증가하지만 개별 대사를 가리지 않는다.
7. BGM과 환경음은 애플리케이션 일시정지에서 멈추고 복귀 시 갑자기 최대 음량으로 시작하지 않는다.

## 조리·도구 SFX

### 조립

- 재료 선택: 생닭은 낮고 부드러운 `툭`, 대파는 가볍고 마른 `톡`.
- 관통: 눌림 뒤 짧은 `톡`, 재료별 음높이 차이, 꼬치 반동음.
- 잘못된 재료: 강한 실패음 대신 통으로 돌아가는 약한 소리와 주문표 피드백.
- 재료 제거: 짧은 저항 뒤 `뽁`.
- 조립 완료: 마지막 한 음 또는 다섯 재료의 짧은 연속음.

### 그릴

- 배치: 금속 `착` 뒤 기름 `치익`.
- 굽는 중: 화력·익힘에 따라 약한 지글거림→안정된 지글거림→거친 타닥거림.
- 적정 진입: UI 벨보다 음식에서 나는 짧고 높은 `치익`.
- 뒤집기: 집게·회전·재접촉과 기름 튐.
- 회수: 숯불 소리가 한 단계 줄고 도자기 접촉음이 난다.
- 탄 상태: 진한 연기와 거친 타닥거림을 사용하고 경보음을 계속 중첩하지 않는다.

### 생맥주

- 잔 배치: 맑은 유리음과 드립 트레이의 `딱`.
- 맥주 레버: 0.12초 저항 뒤 낮은 금속 `찰칵`, 액체음, 중앙 복귀 `턱`.
- 거품 레버: 더 가볍고 높은 `딸깍`, 부드러운 흐름음, 중앙 복귀 `턱`.
- 채움: 맥주가 차오를수록 액체·탄산음이 조금 높아지고 70% 근처에 작은 유리 공명음이 난다.
- 완성: 큰 판정음 대신 짧은 금속 종소리 한 번.
- 서빙: 빈 잔보다 낮고 무거운 유리·목재 접촉음.

### 서빙·정리

- 접시 선택은 내용물 무게에 따라 들림 속도와 마찰음이 달라진다.
- 카운터 이동은 짧은 목재 마찰 뒤 도자기·잔 접촉음으로 끝난다.
- 좌석 정리는 접시·잔 종류에 맞는 짧은 한 번의 소리를 사용하고 연속 탭에서 과도하게 중첩하지 않는다.
- 손님 만족은 대사, 작은 숨·끄덕임과 주변의 절제된 반응을 우선한다.

## UI·경고 SFX

8. 일반 선택, 비활성, 오류, 완료와 위험은 서로 다른 음색을 사용한다.
9. 화면 밖 경고는 스테이션 고유 음색과 방향감을 함께 제공할 수 있어야 한다.
10. 생맥주 흐름 중 그릴 경고는 액체음보다 높은 대역을 사용해 들리게 한다.
11. 경고의 잠정 우선순위는 `조리 실패 임박→손님 이탈 임박→일반 주문`이며 최종 순서는 플레이테스트 뒤 확정한다.
12. 같은 위험의 반복음은 남은 시간 단계를 전달하되 짧은 간격으로 무한 반복하지 않는다.
13. 마지막 1초 경고는 한 번의 명확한 임박 신호로 제한하고 전체 믹스를 왜곡하지 않는다.
14. Perfect, Good, OK, Fail은 텍스트를 읽지 않아도 다른 결과임을 알 수 있으나 손님 반응과 충돌할 정도로 과장하지 않는다.

## 이벤트·상태 계약

| 이벤트 | 재생 조건 | 중복 규칙 |
|---|---|---|
| 대상 선택 | 유효 입력 확정 | 대상별 50ms 내 재입력 병합 |
| 공정 시작 | 논리 상태가 진행 중으로 전환 | 애니메이션 재생으로 재발행 금지 |
| 적정 진입 | 판정 구간 최초 진입 | 면·잔 단계별 1회 |
| 위험 단계 | 3초·1초 임계 통과 | 임계별 1회 |
| 판정 | 공정 결과 확정 | 결과 ID별 1회 |
| 서빙 완료 | 접시·잔 도착 확정 | 주문 ID별 1회 |
| 손님 반응 | 맛보기 뒤 상태 전환 | 반응 상태별 1회 |

15. 판정 이벤트 수신 후 오디오 반응은 100ms 이내 시작을 목표로 한다.
16. 화면이 숨겨진 동안 예정된 SFX를 쌓아 두었다가 한꺼번에 재생하지 않는다.
17. 스테이션 전환은 활성 공정 소리를 짧게 낮추되 위험 신호는 유지한다.

## 믹싱과 설정

- 마스터, BGM, 환경음·SFX 음량을 독립 조절한다.
- 전체 음소거와 브라우저 자동 재생 제한 상태를 명확히 처리한다.
- 음성 더빙이 없으므로 대사 텍스트를 오디오에 의존하지 않는다.
- 여러 조리음이 겹치면 플레이어 입력 대상과 가장 임박한 위험을 우선한다.
- 동일 종류의 반복 SFX는 동시 재생 수를 제한하고 미세한 변형으로 피로를 줄인다.
- 최종 음량·라우드니스·동시 재생 상한은 오디오 제작과 실기기 검증 뒤 확정한다.

## 접근성

18. 모든 오디오 신호는 형태·텍스트·애니메이션 또는 진동 대체 신호를 가진다.
19. 무음 상태에서도 적정 굽기, 맥주 완성, 화면 밖 위험과 손님 이탈을 이해할 수 있어야 한다.
20. 진동은 별도 설정으로 완전히 끌 수 있고 오디오 설정과 독립적이다.
21. 경고음은 BGM보다 우선하지만 갑작스러운 과도한 음량 상승을 사용하지 않는다.

## 예외 및 경계 조건

- 오디오 파일 로딩 실패는 조리 진행을 막지 않고 무음 대체 신호로 계속한다.
- 브라우저 자동 재생 제한 시 첫 사용자 입력 뒤 오디오를 활성화하고 이미 지난 이벤트는 재생하지 않는다.
- 포인터 취소로 액체·공정이 중단되면 반복음을 즉시 멈춘다.
- 일시정지·복귀 시 반복음 재생 위치보다 논리 상태를 우선해 새 루프를 시작한다.

## 비기능 요구사항

- 오디오는 초기 5MB 로드 예산에서 분리해 지연 로드할 수 있어야 한다.
- 이벤트 ID와 오디오 키는 데이터·manifest에서 검증한다.
- 실제 모바일 스피커와 무음·낮은 음량 환경에서 경고 가청성과 비오디오 대체를 함께 검수한다.

## 완료 기준

- [ ] 각 핵심 조작이 화면을 보지 않아도 서로 다른 재질·무게로 구분된다.
- [ ] 적정·과다·위험·완료 신호가 BGM과 러시 소리 속에서도 식별된다.
- [ ] 복수 경고가 정의된 우선순위로 재생되고 중첩 폭주하지 않는다.
- [ ] 일시정지·백그라운드·포인터 취소가 반복음을 즉시 멈춘다.
- [ ] 무음 플레이에서도 모든 핵심 흐름을 완료한다.
- [ ] 오디오 실패가 게임 진행이나 상태 전이를 막지 않는다.
