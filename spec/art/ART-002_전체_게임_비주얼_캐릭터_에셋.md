## 목적

`YAKI SEASON`의 브랜드, 골목·가게, 캐릭터, 음식·도구와 VFX가 하나의 2.5D 픽셀 아트 세계로 읽히는 제작 기준을 정의한다. 조작 대상과 상태는 작은 화면·LOW 모드에서도 구분되어야 하고, 성장 뒤에도 오래된 가게의 생활감을 유지한다.

## 범위

### 포함

- 브랜드·간판·환경·조명·색채
- 2D 배경과 3D 조작 대상의 시각 결합
- 주요 캐릭터의 실루엣·복장·표정·동작
- 음식·스테이션·도구·VFX 상태 세트
- 캠페인 단계별 외관 변화와 기술 규격

### 제외

- 개별 에셋의 최종 제작 프롬프트와 파일 manifest
- UI 텍스트의 최종 폰트 라이선스
- 캐릭터 3D 리깅과 자유 카메라용 전 방향 모델
- 초기 탐색 이미지의 이전 상호와 생성 오류 문자

## 상세 요구사항

상세 규칙은 브랜드, 2.5D 표현, 환경, 캐릭터, 조작 에셋과 VFX 영역을 함께 적용한다.

## 브랜드와 시각 방향

1. 로고는 `YAKI SEASON`과 `炭火やきとり とり暦`를 함께 사용할 수 있어야 한다.
2. 간판은 `とり暦`가 첫 식별 요소이며 초기 `鳥屋/Toriya` 표기는 사용하지 않는다.
3. 공통 분위기는 따뜻한 주황 숯불·제등과 짙은 남색 저녁, 오래된 목재·종이·황동 질감이다.
4. 픽셀 아트는 흐릿한 필터가 아니라 굵은 픽셀 군집, 계단형 윤곽, 제한 팔레트와 무안티앨리어싱으로 표현한다.
5. 밝은 면은 황갈색 숯불광, 그림자는 남색·자주색을 사용하되 화면 전체를 단일 주황 또는 남색으로 덮지 않는다.
6. 생성 이미지의 설명·워터마크·틀린 문자와 콘셉트 시트 테두리를 런타임 에셋에 포함하지 않는다.

## 2.5D 표현 계약

| 대상 | 기본 표현 | 이유 |
|---|---|---|
| 골목·가게 배경 | 조명과 분위기가 베이크된 2D 픽셀 이미지 | 품질·성능·단계 교체 |
| 손님·직원 | 2D 스프라이트·초상 | 표정 가독성과 제작량 |
| 작업대 몸체 | 2D 평면 또는 저복잡도 3D | 카메라 고정 전제 |
| 꼬치·석쇠·잔·도구 | 픽셀 셰이딩 3D | 직접 조작과 상태 변화 |
| 불씨·연기·기름·판정 | 제한된 스프라이트·쿼드 | 반응성과 성능 |
| 의미 텍스트 | DOM 또는 UI 계층 | 오탈자·접근성·현지화 |

7. 2D와 3D는 동일한 고정 3/4 셰프 시점, 숯불 방향과 픽셀 크기 인상을 공유한다.
8. 3D 오브젝트의 가장자리와 재질은 배경보다 과도하게 매끈하거나 사실적으로 보이지 않아야 한다.
9. 접지감은 그림자 맵 대신 래스터 접지 그림 또는 blob shadow를 사용한다.
10. 배경, 손님, 스테이션, 조작 대상, VFX, 전경과 UI의 깊이 순서를 유지한다.

## 환경과 캠페인 변화

### 기본 외관·내부

- 외관은 좁은 저녁 골목, 낮은 목조 점포, 노렌, 제등, 화분과 비에 젖은 바닥을 사용한다.
- 내부는 6석 카운터, 어두운 목재, 병 선반, 종이·황동 조명과 깊은 남색 창을 중심으로 한다.
- 메뉴판과 간판 외 생성 이미지 속 문자는 장식 무늬로 대체하거나 UI에서 다시 그린다.

### 단계 변화

| 시점 | 시각 변화 |
|---|---|
| S0 | 꺼진 간판, 접힌 노렌, 적은 사람, 차가운 그릴 |
| S1 종료 | 간판·숯불·영업 중 표식 점등 |
| S3 종료 | 창을 보는 행인, 자전거·우산 등 생활 흔적 |
| S4 종료 | 정리된 화분, 새 메뉴판, 성냥갑 등 단골 흔적 |
| S5 종료 | 기다리는 손님, 직원 앞치마, 추가 제등 |
| S6 종료 | 확장 좌석의 내부 빛과 예약 표식 |
| S7 | 낡은 간판은 유지하고 관리된 활기만 증가 |

11. 단계 변화는 배경 이미지 교체와 작은 2D 루프로 구현할 수 있어야 한다.
12. 성장 결과를 현대식 고급 매장이나 과도하게 밝은 새 인테리어로 바꾸지 않는다.

## 캐릭터 공통 기준

- 성인은 약 6~6.5등신의 현실적 비율을 기본으로 한다.
- 작은 해상도에서 눈썹·눈매·입꼬리와 자세로 감정을 읽게 한다.
- 의상은 현대 일본 골목의 작업복·사무복·생활복을 바탕으로 하고 판타지·과장 전통복을 피한다.
- 동일 인물의 전신·초상·좌석 스프라이트에서 머리, 안경, 대표색과 앵커를 유지한다.
- 연령은 주름뿐 아니라 자세, 동작 속도와 손의 형태로 구분한다.
- 감정은 얼굴색 하나가 아니라 눈·입·고개·손과 자세 중 두 가지 이상으로 표현한다.

### 캐릭터 제작 단위

- 영업 말풍선 초상: 96x96 또는 128x128 후보, 기본·만족·불만·놀람.
- 영업 전후 대화: 256x256 이상 원본, 표정 8~12종 후보.
- 좌석 스프라이트: 착석, 주문, 대기, 임박, 먹기, 마시기, 만족, 취향 불일치, 추가 주문, 계산, 퇴장.
- 직원 스프라이트: 대기, 이동, 접시·잔, 정리, 주문 확인, 실수, 시범 관찰, 숙련 반응.
- 해상도는 잠정값이며 실제 화면 96px 이하 축소와 최근접 보간 검수를 통과해야 한다.

## 음식·스테이션·도구

13. 닭·대파·기타 재료는 색상 없이도 실루엣과 절단면으로 구분한다.
14. 꼬치는 손잡이 잡기 영역, 회전축과 재료별 서브메시를 가진다.
15. 그릴은 슬롯·사용 영역이 읽히고 숯불과 금속 몸체를 분리해 화력 상태를 표현한다.
16. 맥주잔은 손잡이 잡기 영역, 맥주·거품 경계와 70:30 기준선을 제공한다.
17. 붓·부채·집게는 잡기 영역과 기본 운동 방향이 실루엣으로 읽혀야 한다.
18. 인터랙티브 메시 하나는 2,000 triangles, 오브젝트 텍스처는 1024 정사각 상당을 넘지 않는다.

### 상태 에셋

| 대상 | 필수 상태 |
|---|---|
| 재료·꼬치 | 날것, 익는 중, 적정, 과다, 완전 탄 상태, 타레 광택 |
| 숯불 | 꺼짐, 약함, 적정, 과다, LOW 모드 |
| 맥주 | 빈 잔, 맥주층, 거품층, 이상 비율, 넘침, 완성 |
| 주문 | 대기, 위험, 제작 중, 완성, 실패·재조리 |
| 좌석 | 비어 있음, 예약, 착석, 식기 있음, 정리 필요 |

## VFX와 애니메이션

- 숯불 불씨는 상시 화력 비례, 최대 80개다.
- 연기는 굽는 동안 최대 6개 큰 쿼드와 UV 스크롤을 사용한다.
- 기름 튐은 뒤집기 순간 최대 30개, 수명 0.5초다.
- 판정은 링·짧은 불씨·윤기와 음식 반응을 사용하고 풀스크린 블룸을 금지한다.
- 관통은 눌림·정지·관통·반동, 뒤집기는 집게·회전·재접촉, 서빙은 카운터 마찰과 2~3px 멈춤을 표현한다.
- 애니메이션은 논리 상태를 지연시키거나 입력 영역을 갑자기 이동시키지 않는다.

## 파일·에셋 규격

19. 배경은 JPG 또는 WebP, 알파가 필요한 스프라이트는 PNG 또는 검증된 WebP를 사용한다.
20. 픽셀 에셋은 최근접 보간을 사용하고 압축으로 윤곽·알파가 번지지 않게 한다.
21. 배경의 논리 기준은 16:9이고 상단 HUD·중앙 손님·하단 작업 안전 영역을 비워 둔다.
22. 상태 변형은 같은 캔버스 크기·피벗·하단 중앙 앵커를 공유한다.
23. 에셋 manifest는 ID, 경로, 크기, 포맷, 알파, 앵커, 상태, 출처·생성 근거와 해시를 기록한다.
24. 런타임 텍스트, 손 모양, 커서와 콘셉트 번호는 에셋에 굽지 않는다.

## 예외 및 경계 조건

- 캐릭터 상태 에셋 누락 시 빈 좌석으로 바꾸지 않고 오류·재시도를 제공한다.
- LOW 모드에서도 안경, 머리띠, 앞치마, 주문과 익힘 단계가 식별되어야 한다.
- 좌우 반전 시 가르마·비대칭 소품의 정체성이 무의미하게 뒤바뀌면 별도 반전 에셋을 사용한다.
- D30 군중에서도 주요 인물의 머리와 대표색을 다른 손님이 완전히 가리지 않게 한다.

## 비기능 요구사항

- 모든 에셋은 게임 화면 크롭·겹침·알파·축소 검수를 통과해야 한다.
- 주류는 과음·경쟁의 상징, 손님 유형은 풍자·고정관념으로 과장하지 않는다.
- 에셋 라이선스와 생성 이력을 manifest에서 추적할 수 있어야 한다.
