# 아트 요구사항

비주얼 스타일, 에셋 규격, 애니메이션, VFX, 해상도, 파일 형식을 정의한다.

현재 화면·아트 방향과 납품 기준은 `ART-002`, `ART-003`, 정량 이미지 규격은 `ART-004`,
공통 스타일은 `YS-HANDCRAFTED-NIGHT-v1`이다. 프롤로그부터 설정까지 열 개 전체 화면 마스터와 화면별
분리 목록은 `art-workspace/concept-masters/2026-07-26/`을 사용하며, cutout·complete layer의
별도 승인은 `art-workspace/pipeline/` 계약을 따른다. 최종 runtime 승격은
`app/tools/assets/`의 자동 게이트로만 수행한다. 손님 화면은 손님측 바 바로 뒤, 화면
중앙의 단일 대문과 그 개구부 너머 밤 골목, 화면 끝까지 막힌 좌우 측면 벽을 물리적
불변 구조로 사용하고, 모든 신규 이미지 후보는 프롬프트 전에
`spatial-inference.json` 승인을 받아야 한다.

## 기본 완료 기준

- 에셋 종류와 목표 형식이 정의되어 있다.
- 스타일 일관성 기준이 문서화되어 있다.
- 개발용 무표시 graybox와 사용자 노출 승인 에셋의 경계가 정의되어 있다.
