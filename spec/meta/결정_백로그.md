# 기획 결정 백로그

- 상태: `운영 중`
- 담당 영역: `메타 / 기획 관리`
- 근거: 현재 사용자 대화 및 각 요구사항의 미해결 질문

## 목적

현재 제작을 막는 결정과 출시 후·구현 단계에서 처리해도 되는 결정을 분리한다. 같은 질문을 반복해서 사용자에게 묻지 않고, 결정 시점과 원본 요구사항을 추적한다.

## 현재 결정 묶음 상태

현재 기획 묶음 중 여섯 항목은 완료되었다. `NOW-03`은 D4·D5 범위만 완료했고 D6·D7은 사용자 지시에 따라 차후 기획으로 보류한다. 세부 인물 설정은 후속 캐릭터 디벨롭 단계에서만 다룬다.

| ID | 결정 주제 | 상태 | 연결 문서 |
|---|---|---|---|
| NOW-01 | 1차 PC 배포 콘텐츠 범위 | 완료: S0~D30 시나리오 전체의 무료 프로토타입 | `GPL-001`, `GPL-002`, `DAT-001`, `ART-003` |
| NOW-02 | S2 이후 캠페인 영업일 구성 | 완료: 필수 사건 사이에 일반 영업일 삽입 | `GPL-002` |
| NOW-03 | D4~D7 메뉴·영업일 구성 | 부분 완료: D4 양배추 사라다·하이볼, D5 토리카와 확정. D6·D7 차후 기획 | `GPL-006`, `DAT-001`, `UI-003` |
| NOW-04 | 주인공·핵심 인물의 고정 방식 | 완료: 선택형이 아닌 고정 인물, 세부 설정은 후속 캐릭터 디벨롭 | `SCN-002`, `ART-002`, `ART-003` |
| NOW-05 | 1차 PC 배포의 판매·수익화 정책 | 완료: 무료 프로토타입, 광고·IAP·다이아 제외 | `GPL-005` |
| NOW-06 | 현재 화면·아트 spec과 분리 제작 기준 | 완료: 프롤로그부터 설정까지 10개 전체 화면 마스터와 `sourceMasterId` 확정 | `UI-002 v5.24.0`, `ART-002 v3.5.0`, `ART-003 v3.8.0` |
| NOW-07 | 손님측 바와 가게 대문의 공간 관계 | 완료: 바·손님 좌석 바로 뒤에 큰 대문, 그 너머에 밤 골목이 이어지는 topology 확정 | `ART-002 v3.5.0`, `ART-003 v3.8.0` |

## 후속 처리 백로그

현재 묶음의 답변과 무관하게 진행 가능한 항목은 아래 시점까지 질문하지 않는다. 각 세부 문구는 연결 문서의 `미해결 질문` 절을 단일 원본으로 사용한다.

| 묶음 | 항목 수 | 처리 시점 | 연결 문서 |
|---|---:|---|---|
| 캠페인 후반·재도전·무한 영업·날씨 | 3 | D7 이후 콘텐츠 설계 착수 시 | `GPL-002` |
| D6·D7 메뉴·도구·주문·밸런스·이야기 결과 | 1 | 사용자가 D6 이후 기획 재개를 지시할 때 | `GPL-002`, `GPL-006`, `DAT-001` |
| 장기 경제·직원 숙련·운영 경향 | 3 | 성장 시스템 플레이테스트 뒤 | `GPL-005` |
| 데이터 형식·반올림·D31 이후 콘텐츠·조기 회수·원격 콘텐츠 | 5 | 구현·밸런스 도구 착수 시 | `DAT-001` |
| 시나리오 세부·레시피 추론·엔딩 경향 | 5 | D12·엔딩 시나리오 제작 시 | `SCN-002` |
| 아트 제작 세부·D31 이후 메뉴·D30 화면 | 13 | 해당 에셋 생산 스프린트 시작 시 | `ART-002`, `ART-003` |
| 오디오 설계 | 5 | 오디오 제작 착수 시 | `AUD-001` |
| 런타임·저장·렌더링·밸런스 도구 | 16 | 구현 아키텍처·최적화 단계 | `SYS-001`~`SYS-005` |
| QA·출시 검증 | 5 | 기능 완료 뒤 검증 단계 | `QA-001`, `QA-002` |
| 합계 | 56 | 후속 단계 | 각 연결 문서 |

현재 문서군의 세부 미해결 질문 56개는 모두 후속 단계로 보류한다. D4·D5 구현 착수를 막는 사용자 결정은 없으며 D6 이후 후보를 D4·D5 구현에 포함하지 않는다. 기존 화면·아트 제작은 `UI-002 v5.24.0`, `ART-002 v3.5.0`, `ART-003 v3.8.0`을 기준으로 사용하되 D4·D5 신규 작업면은 `GPL-006`과 `UI-003`을 우선한다.

## 운영 규칙

1. 현재 결정 필요 묶음이 끝날 때까지 새로운 미세 상호작용 예외를 독립 질문으로 올리지 않는다.
2. 기능 구현 중 발견한 경계 조건은 우선 합리적인 기본값으로 기록하고, 진행을 막는 경우에만 다음 결정 묶음에 넣는다.
3. 후속 처리 항목은 연결 문서의 미해결 질문을 보존하며, 실제 착수 시점에만 사용자에게 다시 제시한다.
