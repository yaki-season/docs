## 목적

스테이지, 성장과 운영 시스템 없이도 사용자가 주문을 보고 네기마를 조립하고, 양면을 굽고, 손님에게 서빙하는 핵심 조작이 재미와 이해 가능성을 갖는지 검증한다. 이 요구사항은 완성 게임이 아니라 한 주문을 처음부터 끝까지 반복 시험하는 최소 수직 슬라이스의 기능 기준이다.

## 범위

### 포함

- 고정 손님 1명과 고정 주문 1건
- 네기마 1종: `닭다리살-대파-닭다리살-대파-닭다리살`
- 재료 클릭 조립, 완성 꼬치 전달, 그릴 배치, 앞면 굽기, 뒤집기, 뒷면 굽기, 접시 회수, 손님 서빙
- 잘못된 재료 선택, 너무 이른 조리 입력과 탄 꼬치의 최소 피드백
- 성공 또는 실패 뒤 같은 흐름을 다시 시작하는 재시작 기능

### 제외

- 별도 스테이지 목표, 제한 시간, 별점, 점수, 재화, 팁과 정산
- 생맥주와 드링크 스테이션
- 모모를 포함한 추가 메뉴, 복수 주문, 복수 손님, 추가 주문과 손님 대기열
- 재료 재고, 품절, 청소, 좌석 회전, 직원과 자동화
- 타레 바르기, 소금 뿌리기와 도구 선택
- 저장, 불러오기, 계정, 서버와 네트워크 통신
- 스토리, 대사, 튜토리얼 챕터와 스테이지 진행

## 핵심 상태 흐름

```text
초기화
→ 주문 확인
→ 재료 5개 순차 조립
→ 완성 꼬치 전달
→ 그릴 배치
→ 앞면 굽기
→ 뒤집기
→ 뒷면 굽기
→ 접시 회수
→ 손님 서빙
→ 성공 확인
→ 다시 하기
```

## 상세 요구사항

1. 시작 시 손님 1명, 네기마 주문표, 닭다리살 재료통, 대파 재료통과 빈 꼬치 1개를 표시한다.
2. 주문표는 다섯 칸에 `닭-대파-닭-대파-닭` 순서를 아이콘과 텍스트로 표시한다.
3. 사용자가 현재 순서에 맞는 재료를 클릭하면 해당 재료가 꼬치의 다음 빈 칸에 자동으로 끼워지고 조립 진행 수가 1 증가한다.
4. 현재 순서와 다른 재료를 클릭하면 꼬치 상태를 바꾸지 않고 주문표의 올바른 다음 칸과 클릭한 재료를 각각 짧게 강조한다.
5. 다섯 번째 재료가 끼워지면 꼬치를 `조립 완료` 상태로 전환하고 더 이상 재료 입력을 받지 않는다.
6. 조립 완료 꼬치를 클릭하면 그릴 대기 위치로 이동하고 그릴 작업 화면을 활성화한다.
7. 대기 꼬치를 클릭하면 유일한 그릴 칸에 자동 배치하고 즉시 앞면 굽기 시간을 시작한다.
8. 각 면의 조리 시간은 그릴 배치 또는 뒤집기 완료 시점부터 독립적으로 계산한다.
9. 최소 프로토타입의 면별 판정은 다음 고정값을 사용한다.

| 경과 시간 | 상태 | 입력 결과 |
|---:|---|---|
| `0.0초 이상, 2.5초 미만` | 덜 익음 | 클릭 시 뒤집기·회수하지 않고 덜 익음 피드백 |
| `2.5초 이상, 5.5초 미만` | 적정 | 앞면은 뒤집기, 뒷면은 접시 회수 허용 |
| `5.5초 이상, 7.0초 미만` | 과다 | 조작은 허용하되 완성 품질을 낮은 상태로 기록 |
| `7.0초 이상` | 탄 상태 | 해당 꼬치 실패 처리, 조리 입력 중단, 다시 만들기 제공 |

10. 앞면이 적정 또는 과다 상태일 때 꼬치를 클릭하면 180도 뒤집고 앞면 결과를 고정한 뒤 뒷면 굽기 시간을 시작한다.
11. 뒷면이 적정 또는 과다 상태일 때 꼬치를 클릭하면 꼬치를 접시에 자동으로 옮기고 조리 시간을 중단한다.
12. 접시 위 꼬치를 클릭하면 접시를 선택 상태로 만들고, 이어 손님의 주문 매트를 클릭하면 접시가 손님 앞으로 이동한다.
13. 조립 순서가 정확하고 양면이 탄 상태가 아니면 서빙을 완료할 수 있다. 한 면이라도 과다 상태이면 낮은 품질 반응을, 양면이 적정이면 좋은 품질 반응을 표시한다.
14. 서빙 완료 뒤 손님의 반응과 `한 번 더 만들기` 명령을 표시한다.
15. `한 번 더 만들기`를 실행하면 모든 진행 상태와 타이머를 초기화하되 페이지를 새로고침하지 않는다.
16. 핵심 흐름에서 무작위 요소를 사용하지 않는다. 같은 입력과 같은 시간 조건은 같은 결과를 만들어야 한다.

## 예외 및 경계 조건

- 그릴에 올리지 않은 꼬치에는 굽기 시간이 흐르지 않는다.
- 뒤집기 애니메이션 중 추가 클릭은 무시하고 한 번만 처리한다.
- 조립 완료 후 재료 클릭, 접시 회수 전 손님 클릭과 빈 접시 클릭은 상태를 바꾸지 않는다.
- 실패 또는 성공 상태에서는 `한 번 더 만들기` 외 조리 입력을 받지 않는다.
- 브라우저 탭이 숨겨지거나 창이 포커스를 잃으면 조리 타이머를 일시 정지한다. 복귀 후 자동으로 누적 시간을 더하지 않는다.
- 렌더링 프레임이 지연되어도 조리 판정은 프레임 수가 아니라 경과 시간을 기준으로 계산한다.

## 비기능 요구사항

- 한 주문의 정상 경로는 페이지 새로고침 없이 완료되어야 한다.
- 상태 전이는 단일 상태 원본을 사용해 UI, 입력 가능 여부와 판정 결과가 서로 어긋나지 않아야 한다.
- 처음 로드한 뒤 정상 경로 완료까지 콘솔에 처리되지 않은 오류가 없어야 한다.
- 조리 수치는 구현 코드의 한 위치에서 조정 가능해야 하며 화면별로 중복 정의하지 않는다.

## 완료 기준

- [ ] 네기마 순서에 맞는 클릭 5회로 조립이 완료된다.
- [ ] 잘못된 재료 클릭은 진행 상태를 바꾸지 않고 원인을 알 수 있는 피드백을 준다.
- [ ] 앞면과 뒷면의 조리 시간이 독립적으로 진행되고 정의된 구간대로 판정된다.
- [ ] 너무 이른 클릭은 진행되지 않으며, 7초 이상 방치하면 실패 상태가 된다.
- [ ] 완성 꼬치를 접시로 회수하고 접시와 손님을 차례로 클릭해 서빙할 수 있다.
- [ ] 성공과 실패 양쪽에서 페이지 새로고침 없이 다시 시작할 수 있다.
- [ ] 한 번의 정상 흐름과 한 번의 탄 꼬치 흐름이 재현 가능하다.
