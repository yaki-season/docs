# 게임플레이 요구사항

핵심 루프, 플레이어 행동, 규칙, 승패 조건, 난이도, 보상 구조를 정의한다.

## 기본 완료 기준

- 핵심 루프를 독립적으로 테스트할 수 있다.
- 플레이어 행동과 결과 피드백이 명확하다.
- 난이도와 보상 규칙이 측정 가능한 형태로 작성되어 있다.
