## 목적

데스크톱 Chrome에서 플레이어가 바 안쪽의 주인공 시점으로 손님 화면과 독립 조리 화면을 오가며, 한 포인터로 준비, 조리, 서빙, 정산과 성장까지 전체 게임을 조작하는 화면·입력 계약을 정의한다. 손님 화면은 손님 데이터와 테이블 상황을, 조리 화면은 주문서·조리 도구·준비 목록을 명확히 분리해 보여준다.

## 범위

### 포함

- 전체 화면 흐름과 각 화면의 진입·이탈 조건
- 손님 정보 화면과 조리 스테이션 화면의 독립 구성
- 영업 HUD, 좌·우 단계 전환, 퀵 전환과 화면 밖 경고
- 손님 화면의 손님·주문·식사 상태 및 바 테이블 위 음식
- 조리 화면의 좌석 순서 주문서 카드와 공통 준비 목록
- 마우스·터치 공통 입력 문법과 선택형 제스처
- 데스크톱 Chrome의 `16:9`, `1920×1080 FHD` 기준 레이아웃
- 튜토리얼, 접근성, 일시정지·중단 복귀
- 로딩·오류·빈 상태·비활성 상태

### 제외

- 최종 카피라이팅과 번역 문자열
- 세로 모바일 플레이
- 키보드 전용 조작과 게임패드 지원
- 광고·결제 화면의 최종 구성
- 현재 단계의 모바일 전환·최적화와 모바일 완료 검수

## 상세 요구사항

상세 규칙은 전체 화면 흐름, 공통 입력 문법, 영업 HUD와 접근성 영역을 함께 적용한다.

## 전체 화면 흐름

```text

→ 프롤로그 또는 오늘의 영업 전 화면
→ 메뉴·직원·예약 확인
→ 영업 준비
→ 영업 HUD와 스테이션 화면
→ 마감
→ 정산
→ 레시피 노트·업그레이드
→ 다음 목표
→ 다음 날
```

## 공통 입력 문법

| 입력 | 의미 | 사용 |
|---|---|---|
| 클릭·탭 | 선택 또는 현재 상태의 대표 행동 | 재료, 꼬치, 잔, 완성품 |
| 같은 제작물 다중 선택 | 같은 주문·메뉴·조리 방식의 대기 꼬치를 빈 그릴 칸 수 이하로 선택 | D1 밖 조립 트레이 |
| 대상 선택→목적지 선택 | 복수 목적지 중 이동 | 위치별 그릴, `"아무거나"` 주문 |
| 누르고 유지 | 손을 떼면 즉시 멈추는 흐름 | 단일 레버의 맥주→거품 순차 입력, 좌석 정리 3초 홀드 |
| 드래그 | 빠른 직접 이동·서빙 | 재료·접시·잔, 손님 화면 하단 공용 완성품 카드→손님, 프롤로그 열쇠 |
| 수평 스와이프 | 방향이 있는 빠른 행동 | 꼬치 뒤집기 선택 입력 |
| 부채 탭·짧은 스와이프 | 그릴 위 모든 꼬치의 현재 면을 4초 앞당기는 강화 | D5 완료 뒤 그릴 화면 |
| 좌·우 화면 버튼 | 인접 화면 전환 | 손님 테이블·조립·그릴·드링크 등 |
| PC 좌·우 방향키 | 인접한 접근 가능 스테이션 전환 | 조립·그릴·드링크 등 |
| 퀵 전환 | 전체 화면 목록에서 즉시 이동 | 우측 상단 화면 선택기 |

1. 핵심 캠페인은 hover, 우클릭, 휠, 키보드 조합과 두 손가락 입력을 요구하지 않는다.
2. PC의 클릭·누르기·떼기와 모바일의 탭·홀드·릴리스는 같은 의미와 결과를 가진다.
3. 클릭·탭만으로 모든 핵심 조리와 서빙을 완료할 수 있다.
4. 드래그·스와이프는 속도와 회전 방향만 반영하고 품질 보너스를 주지 않는다.
5. 하나의 활성 포인터만 처리하며 동시 다중 터치를 요구하지 않는다.
6. 입력 우선순위는 `조작 물건→선택 목적지→스테이션 전환→배경 연출` 순서다.
7. 애니메이션 잠금 중 같은 대상의 빠른 반복 입력은 한 번만 처리한다.
8. 빈 영역을 누르면 일반 선택을 취소한다. 모바일에서는 선택된 완성품을 다시 눌러도 취소할 수 있다.
8-1. PC의 `ArrowLeft`·`ArrowRight`는 좌·우 화면 버튼과 같은 잠금 규칙으로 현재 스테이션의 인접 스테이션을 전환한다. 잠긴 스테이션은 방향키 전환에서도 건너뛰거나 열지 않는다.
8-2. 일반 영업에서 제공 전 제작물을 선택하면 현재 조리 화면에서만 명시적 `폐기` 조작을 제공한다. 폐기는 주문 카드나 손님을 취소하지 않고 제작물만 제거하며, 미제공 주문은 그대로 남는다. D1의 실패 안전 가이드에서는 이 조작을 노출하지 않는다.
8-3. 부채 강화는 D5 완료 뒤에만 그릴 도구로 표시한다. 부채 도구를 탭하거나 도구 위를 짧게 스와이프하면 현재 그릴 위 모든 꼬치의 현재 면 진행을 4초 앞당기고, 도구에는 9초 쿨타임 원형 게이지와 남은 시간을 표시한다. 쿨타임 중 입력은 무효다. 꼬치 자체의 수평 스와이프는 계속 뒤집기 입력이며, 부채 스와이프와 혼동하지 않는다.
8-4. D3부터 주문 카드·그릴 위 제작물·준비 목록에는 `타레` 조리 방식 표식을 텍스트와 아이콘으로 함께 표시한다. 타레 주문은 붓 선택 뒤 해당 꼬치를 선택하는 입력을 완료하기 전에는 준비 목록·서빙 대상으로 전환하지 않는다.
8-5. 생맥주 잔에는 맥주 3초·거품 1초의 목표와 각 `±0.7초`, 총 채움 4.7초 넘침 경계를 숫자 상시 노출 대신 잔의 기준선·층 변화·넘침 연출로 표시한다. 넘침 뒤에는 `낮은 품질로 제공`과 `폐기 후 새 잔 제조`를 같은 우선순위의 명시적 선택으로 보여 주며 자동 선택하지 않는다.
8-5-1. 생맥주 결과 표식은 두 단계가 모두 적정이면 `Perfect`, 한 단계 이탈이면 `Good`, 두 단계 이탈이면 `OK`, 넘침 뒤 낮은 품질 제공을 선택하면 `Fail`로 표시한다. 단계별 초 단위 수치 대신 기준선·층 변화와 결과 도장으로 품질 근거를 읽힌다.
8-6. D1 밖 조립 트레이에서는 같은 주문·메뉴·조리 방식의 대기 꼬치만 함께 선택할 수 있다. 선택 수가 빈 그릴 칸 수에 도달하면 추가 대상을 비활성화하고 `그릴에 올리기` 한 번으로 빈 칸 좌→우 순서에 배치한다. 배치 완료 즉시 선택 상태를 해제하며 뒤집기·타레·회수는 개별 입력만 제공한다.
8-6-1. D1 그릴 대기 rack 아래에는 `네기마` 하나만 선택하는 DOM 제어를 둔다. 현재 가이드 단계에서만 활성화되며, 활성화하면 다음 생 네기마 한 개를 선택해 기존 첫 빈 그릴 칸 자동 배치를 실행한다. 동일 메뉴의 꼬치별 pad, 선택 수, 다중 선택과 묶음 배치 버튼은 D1에 표시하지 않는다.
8-7. `맥주와 아무거나` 주문은 별도 선택 목록을 열지 않는다. 플레이어는 손님 화면 하단의 제공 가능한 공용 완성품 카드 하나를 해당 손님에게 드래그해 제공하며, 홀 담당 자동 서빙 시에는 제공 가능한 공용 완성품 중 하나를 무작위로 제공한다.
8-8. `Fail` 완성품은 `1/10` 판매율의 낮은 품질 표식을 붙여 제공할 수 있다. Fail 항목 수령 뒤에는 식사 연출 없이 손님이 화난 반응으로 즉시 퇴장하고 빈 식기·잔을 남긴다. 같은 주문의 미제공 항목은 취소하며, 팁·추가 주문·만족도·긍정 명성 보상은 생기지 않고 명성 `-1` 결과를 짧은 손님 반응과 정산 항목으로 읽힌다. 양면이 모두 탄 음식만 제공 선택지에 넣지 않는다.
8-9. 2인 동행의 한 명이 Fail 항목을 수령하면 두 사람이 같은 순간에 퇴장 동작을 시작하고, 양쪽 주문 카드의 미제공 항목을 취소 상태로 갱신한다. 빈 식기·잔과 좌석 정리 필요 상태는 각 좌석에 남긴다.
8-10. 성장 단계의 구매 메뉴는 `메뉴·스테이션·직원·인테리어` 카테고리를 한 목록에서 전환해 보여 주고, 각 카드에 비용·해금 조건·자동화 효과·구매 가능/보유 상태를 표시한다. 가라아게 이벤트는 튀김 장비 카드를 열고 강조할 뿐 구매 확인은 이 메뉴에서만 한다. 초기 직원 카드는 보유 명성 `70` 이상부터 표시하며, 홀 담당 `100G`(고용 시 1회, 자동 서빙·청소), 맥주 담당 `150G`(고용 시 1회, 주문 접수 즉시 자동 생맥주 제조·수동 제조 가능: Good 60%·Perfect 40%)를 명시하고 월 급여 정보를 표시하지 않는다. 음식 조리 직원 카드는 5단계 품질 업그레이드 비용 `40/55/75/100/140G`와 Perfect 확률 `20/40/60/80/100%`를 다음 단계별로 표시한다.
8-11. 맥주 담당을 고용한 뒤 드링크 스테이션에 진입하면, 플레이어 조작 영역과 분리된 별도 레이어에 직원이 생맥주를 제조하는 모습만 표시한다. 맥주 담당은 한 번에 한 잔만 제조하며, 현재 잔의 `5초` 원형 진행 게이지는 특정 주문 카드가 아닌 공용 드링크 진행 표시에 보인다. 플레이어 수동 완성 잔으로 남은 수량이 `0`이 되어도 이미 시작한 자동 제조의 작업 연출·게이지는 완료까지 유지하되, 새 자동 제조 연출·게이지는 만들지 않는다. 이 연출·게이지는 자동 공정의 상태 표식일 뿐 수동 레버를 잠그지 않는다.
8-12. 손님 화면 하단에는 모든 완성품을 주문 표식 없이 메뉴·조리 방식·품질별 공용 카드와 수량으로 보여 준다. 플레이어가 카드를 손님에게 드래그하면 접시 영역에 아이콘 기반 `1개만 제공`·`다 주기` 선택 상자가 나타난다. 수량을 고르기 전에는 상태가 변하지 않으며, 선택 상자 바깥 클릭·취소 입력 또는 선택 중 대상 손님 이탈 시 카드를 원위치로 돌리고 모든 상태를 보존한다. 선택 상자가 열린 손님은 홀 담당 자동 서빙 대상에서 일시 제외하고, 상자를 닫은 뒤 다시 후보로 평가한다. 대상 손님에게 일치하는 미제공 수량이 없으면 카드는 원위치로 돌아가고 주문·수량·대기 시간은 변하지 않는다. 같은 손님에게 일치하는 주문이 여러 개면 먼저 접수된 주문부터 자동 배정한다. `아무거나` 주문은 플레이어가 드래그한 카드를 제공할 수 있고, 홀 담당 자동 서빙 시에는 제공 가능한 공용 카드 하나를 무작위로 제공한다.

## 입력 크기와 피드백

- PC 최소 클릭 영역은 `44x44 CSS px`, 모바일 최소 터치 영역은 `56x56 CSS px` 상당이다.
- 생맥주 레버의 맥주·거품 영역은 각각 최소 `72x72 CSS px`를 확보한다.
- 탭은 누르고 뗀 위치 차이 `12px` 이하를 잠정 기준으로 하며 실제 기기 검증 뒤 조정한다.
- 드래그 시작은 이동 `8px` 이상, 무입력 길게 누르기 힌트는 `600ms`를 잠정 기준으로 한다.
- 입력 뒤 50ms 안에 들림, 외곽선, 그림자 또는 밝기 중 두 가지 이상으로 반응한다.
- 선택 상태는 대상 `1.05배` 들림, 굵은 외곽선과 목적지 맥동으로 표시한다.
- 손가락 아래 설명을 두지 않고 예상 도착점은 손가락보다 `12~20px` 위에 표시한다.

## 기준 화면과 후순위 모바일

22. 현재 화면 설계와 검수의 기준은 데스크톱 Chrome의 `16:9`, `1920×1080 FHD`다.
23. `1280×720`에서는 정보 우선순위와 조작 가능성을 유지하되 FHD 기준 구도를 변경하지 않는다.
24. 모바일 전환과 최적화는 1차 PC 배포 이후로 이관하며, 현재 P0 화면·에셋 완료를 차단하지 않는다.
25. 향후 모바일 전환 시에도 손님 정보 화면과 조리 화면의 분리, 주문서 접수 순서와 입력 의미는 유지한다.
26. 이미지 비율이 뷰포트와 다르면 중앙 크롭하되 손님·주문서·조리 대상·준비 목록 안전 영역을 자르지 않는다.

## 온보딩과 도움

27. 첫 행동은 손 모양 1회와 한 줄 동사 문구로 안내한다.
28. 같은 행동을 한 번 성공하면 손 모양, 두 번 성공하면 텍스트, 세 번 성공하면 강조를 제거한다.
29. 설정에서 전체 도움말을 다시 켤 수 있다.
29-1. 초보 보조는 설정의 독립 토글로 켜고 끈다. 켜진 상태에서만 적정 구간 확대·흐름 감속·임박 슬로 모션·시범 재생 보조를 제공하며, 플레이 실수·정체에 따라 자동으로 켜거나 강도를 바꾸지 않는다. D1 첫 주문의 필수 단계 가이드는 이 토글과 별개로 항상 표시한다.
30. 튜토리얼 1회 실패는 원인, 2회 실패는 목표와 판정 범위 확대, 3회 실패는 시범·자동 완료 선택을 제공한다.
31. 자동 완료를 사용해도 이야기·메뉴·다음 날짜 진행을 제한하지 않는다.
32. D1 첫 주문 `D1-ORDER-001`은 주문 접수, 생맥주 제조·부분 서빙, 네기마 2개 조립, 시작 2칸 그릴 두 칸의 동시 조리, 네기마 최종 서빙 순으로 한 단계씩만 안내한다.
33. 첫 주문의 각 안내는 한 줄 동사 문구, 손 모양, 다음 조작 대상 강조와 해당 주문 카드의 현재·남은 항목만 사용한다. 긴 설명 모달·이미지 안 문자·복수 동시 도움말은 사용하지 않는다.
34. 첫 주문 중에는 다음 유효 입력 외의 조작을 비파괴적으로 무효 처리하며, 잘못된 재료·이른 회수·과다 입력은 원인과 다음 대상을 바로 보여 준다. 3회 실패 시에는 현재 단계만 시범 또는 자동 완료하고 다음 단계를 계속 안내한다.
35. 정리 필요 좌석은 빈 식기와 별도로 큰 정리 아이콘을 표시하고, 좌석을 3초간 누르는 동안 치우는 모션과 0%에서 100%까지 차오르는 원형 게이지를 제공한다. 게이지와 정리 아이콘은 손님·주문·빈 식기를 가리지 않는다.
36. 정리 홀드를 놓거나 `pointercancel`·포커스 상실이 발생하면 모션·게이지를 즉시 중단하고 0%로 되돌린다. 게이지가 100%가 되는 단 한 번의 완료 이벤트에서만 빈 식기를 제거하고 좌석을 다음 입장 가능 상태로 갱신한다.

## 접근성

- 익힘은 색+질감+연기+소리+링 형태 중 최소 두 가지를 사용한다.
- 주문 연결은 색+도형+숫자를 사용한다.
- 맥주 비율은 액체층+잔 각인 선+완성 파동을 사용한다.
- 위험은 색+방향+아이콘+음향을 사용한다.
- 큰 터치 영역 옵션은 꼬치 손잡이와 도구의 유효 영역을 넓힌다.
- 초보 모드는 적정 구간 30~40% 확대, 흐름 감속과 제한된 슬로 모션을 제공할 수 있다.
- 소리 없이도 모든 상태를 이해할 수 있고 진동은 완전히 끌 수 있어야 한다.
- 브라우저 확대와 조리 영역 스크롤 방지의 충돌은 실기기 접근성 검증 대상으로 둔다.

## 예외 및 경계 조건

### 중단·오류·복귀

32. `pointercancel`, 포커스 상실과 화면 밖 이동 시 물건을 마지막 유효 위치로 복구하고 액체 흐름을 멈춘다.
33. 브라우저 백그라운드 진입 시 모든 게임 타이머와 렌더링을 멈춘다.
34. 복귀 시 현재 주문과 위험을 2초 동안 요약하고 요약이 끝날 때까지 타이머를 재개하지 않는다.
35. 필수 에셋 로딩 실패는 빈 화면 대신 실패 종류, 다시 시도와 지원 안내를 표시한다.
36. 구매·정산·저장 처리 중 중복 입력은 한 번의 결과만 만든다.

## 비기능 요구사항

- 의미 텍스트는 생성 이미지에 굽지 않고 접근 가능한 DOM 또는 동등한 UI 계층으로 제공한다.
- 중요 텍스트·아이콘은 배경과 충분한 대비를 확보한다.
- 레이아웃 변화로 조작 대상과 텍스트가 겹치거나 화면 밖으로 밀려나지 않아야 한다.
- 영업 중 긴 설명 모달과 전체 화면 점수 연출로 플레이 리듬을 끊지 않는다.
