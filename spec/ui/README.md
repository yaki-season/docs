# UI 요구사항

화면, HUD, 메뉴, 입력 흐름, 접근성, 피드백, 온보딩에 대한 요구사항을 정의한다.

## 기본 완료 기준

- 각 화면의 목적과 진입/이탈 조건이 명확하다.
- 입력 가능 상태와 불가능 상태가 구분되어 있다.
- 오류, 로딩, 비활성 상태의 표시 방식이 정의되어 있다.
