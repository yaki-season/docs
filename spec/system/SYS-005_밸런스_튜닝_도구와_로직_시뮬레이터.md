## 목적

기획자가 코드 수정 없이 게임 수치를 조절하고, 그 변화가 게임 결과에 주는 영향을 렌더링 없이 빠르게
확인할 수 있는 개발·기획용 내부 도구를 정의한다. 수치가 코드 상수로 흩어져 있어 기획자가 직접
조절할 수 없고 실제 플레이로만 검증되는 현재 한계를 해소한다.

## 범위

### 포함

- 밸런스 데이터를 읽어 수치를 조절·저장하는 편집 UI
- 조절한 수치로 영업일 루프를 렌더링 없이 빠르게 실행하는 로직 시뮬레이터
- 시뮬레이션 결과 지표 표시와 결과 재현성
- `candidate`/`approved` 상태 구분과 미확정 값의 격리

### 제외

- 최종 밸런스 수치의 결정 (도구는 조절 수단이며 값은 기획자가 정한다)
- 출시 빌드 포함과 라이브 운영용 원격 튜닝
- 에셋·아트·시나리오 편집과 3D 장면 렌더링
- 데이터 스키마 정의 (`DAT-001`이 소유)
- 게임 로직 정의 (`GPL-002`, `GPL-003`, `GPL-004`가 소유)

## 상세 요구사항

### 편집 UI

1. 도구는 `DAT-001` 계약의 밸런스 데이터를 읽어 수치를 항목별로 표시한다.
2. 각 수치는 슬라이더 또는 숫자 입력으로 조절하며 조절 즉시 화면 값에 반영된다.
3. 각 수치의 허용 범위와 단위(초·비율·정수)를 표시하고 범위를 벗어난 입력을 거부한다.
4. 원본 대비 바뀐 항목을 시각적으로 구분하고 항목별·전체 되돌리기를 제공한다.
5. 조절 결과를 데이터 형식으로 저장·내보낼 수 있다.
6. 각 수치의 `candidate`/`approved` 상태를 표시하고, `candidate` 값이 게임 기본값으로 혼동되지 않게 한다.

### 로직 시뮬레이터

7. 현재 편집 중인 수치로 한 영업일 루프를 처음부터 끝까지 실행한다. 실제 대기와 렌더링 없이
   모의 시간으로 진행한다.
8. 시뮬레이터는 게임과 **같은 로직**을 사용한다. 시뮬레이션 전용 상태 규칙을 따로 두지 않는다.
9. 조리·서빙 등 플레이어 입력은 자동 정책으로 대체한다. 실제 사람 입력을 요구하지 않는다.
10. 결과 지표를 표시한다. 최소한 총매출, 팁, 실패 주문 수, 손님 이탈 수, 평균 대기 시간, 품질 분포를 포함한다.
11. 같은 수치와 같은 시드는 같은 결과를 낸다. 무작위 요소는 시드로 고정할 수 있어야 한다.
12. 수치를 바꾸고 다시 실행해 직전 결과와 비교할 수 있다.

### 데이터·격리

13. 로직 코드는 조리 시간·인내심 같은 수치를 상수로 두지 않고 데이터에서 읽는다. 도구로 조절한 값이
    게임과 시뮬레이터에 동일하게 반영되어야 한다.
14. 도구는 개발·기획 전용이며 출시 빌드에 포함하지 않는다.
15. `approved` 상태의 값만 게임 기본값으로 로드하고, `candidate` 값은 도구에서만 시험한다.

## 예외 및 경계 조건

- 데이터 파일이 손상되었거나 스키마 버전이 맞지 않으면 편집을 시작하지 않고 오류를 표시한다.
- 범위를 벗어난 값이 저장되지 않도록 저장 전에 `DAT-001` 검증을 통과해야 한다.
- 시뮬레이터가 비정상 종료 조건(무한 루프, 음수 시간 등)에 빠지면 실행을 중단하고 원인을 보고한다.
- 저장하지 않은 변경이 있는 상태에서 초기화·재로드 시 사용자에게 확인한다.

## 비기능 요구사항

- 한 영업일 시뮬레이션은 실제 플레이 시간보다 현저히 빠르게 끝나야 한다.
- 도구는 게임과 같은 로직·데이터 모듈을 재사용하고 로직을 복제하지 않는다.
- 도구 실행에 비밀 키나 외부 서비스 가용성을 요구하지 않는다.
- 도구 사용 방법과 실행 명령을 `app` 문서에 기록한다.

## 완료 기준

- [ ] 데이터 파일을 읽어 수치를 슬라이더·입력으로 조절하고 저장·내보낼 수 있다.
- [ ] 범위를 벗어난 값이 저장 전에 거부된다.
- [ ] `candidate`/`approved` 상태가 구분되어 표시된다.
- [ ] 편집한 수치로 한 영업일 루프가 렌더링 없이 실행되고 결과 지표가 표시된다.
- [ ] 시뮬레이터가 게임과 같은 로직 모듈을 사용한다.
- [ ] 같은 수치·같은 시드가 같은 결과를 낸다.
- [ ] 도구가 출시 빌드에 포함되지 않는다.
