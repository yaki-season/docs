## 목적

이미 구현된 네기마 조립·굽기·서빙 기능을 실제 영업 장면 안에서 처음부터 끝까지 경험하게 하고, 접시가 손님에게 도착한 뒤 품질에 맞는 짧은 반응이 이어지는지 검증한다. 이번 장면은 인트로와 하루 운영 루프를 확장하지 않고 첫 손님 한 명의 한 주문에 집중한다.

## 범위

### 포함

- 영업 중인 가게 내부에서 시작하는 첫 프레임
- 첫 손님 `츠키오카` 1명과 네기마 1개 주문
- 주문 확인, 조립, 앞면 굽기, 뒤집기, 뒷면 굽기, 접시 회수와 전달
- 전달 직후 맛보기 동작과 좋은 품질·낮은 품질의 서로 다른 반응
- 탄 실패 뒤 손님을 비난자로 만들지 않는 재조리 상태
- 결과 확인 뒤 같은 주문을 다시 시작하는 반복 진입

### 제외

- 가게 외관, 열쇠, 레시피 노트, 숯 점화 등 모든 인트로
- 생맥주, 직장인 2인, 추가 주문, 좌석 정리, 정산과 모모 해금
- 대기 게이지, 팁, 만족도 수치, 재화와 명성
- 대사 선택, 컷신, 카메라 자유 이동과 퇴장 연출

## 장면 흐름

```text
영업 장면 로드
→ 츠키오카 착석·대기 + 네기마 주문 표시
→ 조립 스테이션
→ 그릴 스테이션 앞면·뒤집기·뒷면
→ 서빙 스테이션 접시 선택
→ 접시가 츠키오카 앞으로 이동
→ 맛보기 0.6~1.2초
→ 품질별 반응 + 짧은 문구
→ 한 번 더 만들기
```

## 상세 요구사항

1. 첫 프레임은 바 안쪽 주인공 시점의 영업 중인 가게 내부이며, 츠키오카가 고정 카운터 너머에서 플레이어를 향해 앉아 있고 네기마 주문이 제시된 상태여야 한다.
2. 손님은 공정 전환 중에도 같은 좌석과 같은 인물로 유지되어 한 주문의 대상이 바뀌지 않았음을 보여야 한다.
3. 고정 카운터는 츠키오카의 하체를 가리면서 손님측 주문 매트와 플레이어측 작업 공간을 나누며 모든 공정에서 유지되어야 한다.
4. 조립·그릴·서빙 동작과 판정은 `GPL-001 v1.0.0`을 그대로 사용하며 이번 요구사항이 조리 수치를 바꾸지 않는다.
5. 접시 선택 후 주문 매트를 클릭하면 접시가 작업 영역에서 손님 앞까지 0.35~0.65초 동안 이동한다.
6. 접시 이동이 끝나기 전에는 결과 반응을 시작하지 않는다.
7. 접시 도착 뒤 츠키오카는 `tasting` 상태를 0.6~1.2초 표시한 뒤 품질 반응으로 전환한다.
8. 양면이 적정이면 `satisfied`, 한 면 이상 과다이면 `neutral` 반응을 표시한다.
9. 탄 실패는 서빙 전에 발생하므로 맛보기 반응으로 연결하지 않고 `retry` 반응 또는 대기 자세와 재조리 안내를 표시한다.
10. 만족 반응은 과장된 환호 대신 눈매, 입꼬리와 작은 끄덕임으로 전달한다.
11. 낮은 품질 반응은 모욕·분노·환불 요구가 아니라 따뜻하지만 절제된 수용으로 표현한다.
12. 결과 문구는 두 줄 이하로 표시하고 2.0초 이상 유지하되 `한 번 더 만들기` 조작을 막지 않는다.
13. 다시 시작하면 츠키오카, 접시, 반응, 주문과 모든 공정 상태가 첫 프레임으로 복원된다.

## 반응 매핑

| 게임 결과 | 캐릭터 상태 | 문구 | 다음 동작 |
|---|---|---|---|
| 양면 적정 | `satisfied` | `불 향은 다르지만, 좋은데.` | 다시 시작 가능 |
| 한 면 이상 과다, 탄 상태 아님 | `neutral` | `첫날부터 예전 맛이 날 리는 없지. 그래도 따뜻하군.` | 다시 시작 가능 |
| 탄 실패 | `retry` | `서두르지 말게. 다시 구워 보게.` | 재조리 시작 가능 |

## 예외 및 경계 조건

- 빠른 이중 서빙 입력은 접시 이동과 반응을 한 번만 발생시킨다.
- 반응 전환 중 공정 탭을 눌러도 결과 상태와 캐릭터 상태가 초기화되지 않는다.
- 캐릭터 에셋 하나가 누락되면 빈 좌석으로 바꾸지 않고 로딩 오류와 다시 시도를 제공한다.
- 브라우저가 숨겨진 동안 반응 타이머를 진행하지 않으며 복귀 후 남은 시간부터 계속한다.

## 비기능 요구사항

- 접시 도착부터 첫 캐릭터 반응까지 100ms 이내에 상태 전환을 시작한다.
- 모든 반응은 얼굴색만 바꾸지 않고 눈·입·자세 중 두 가지 이상이 달라야 한다.
- 캐릭터 상태 교체 시 머리, 어깨와 카운터 접점이 눈에 띄게 튀지 않아야 한다.

## 완료 기준

- [ ] 인트로 없이 츠키오카의 네기마 주문 장면으로 바로 시작한다.
- [ ] 첫 프레임과 모든 공정이 바 안쪽 주인공 시점, 고정 카운터와 카운터 너머 츠키오카의 관계를 유지한다.
- [ ] 조립부터 접시 전달까지 기존 기능 흐름을 장면 안에서 완료할 수 있다.
- [ ] 접시 도착 뒤 맛보기 상태를 거쳐 좋은 품질과 낮은 품질 반응이 각각 표시된다.
- [ ] 탄 실패는 맛보기 없이 재조리 반응으로 연결된다.
- [ ] 다시 시작하면 같은 손님과 주문의 첫 장면으로 복원된다.
- [ ] 반응 중 중복 입력과 탭 숨김·복귀가 상태를 손상하지 않는다.
