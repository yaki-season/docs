# template

AI 개발 지침서와 반복 사용 가능한 문서 템플릿을 보관한다.

## 기본 문서

- `AI_개발_지침서.md`: AI에게 구현 작업을 맡길 때의 기본 원칙과 보고 형식
- `AI_변경사항_반영_파이프라인.md`: 개발 중·개발 후 변경사항을 `inbox`, `spec`, `epic`, `app` 순서로 반영하는 절차
- `원본자료_정제_지침.md`: `inbox/` 자료를 `spec/`과 `epic/`으로 정제하는 기준
- `inbox_변경요청_템플릿.md`: 개선, 수정, 결함과 아이디어 기록 양식
- `spec_요구사항_템플릿.md`: 요구사항 상세 설계서 양식
- `epic_작업_템플릿.md`: 개발자별 작업 문서 양식
