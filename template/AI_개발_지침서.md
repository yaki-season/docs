# AI 개발 지침서

## 역할

AI는 요구사항을 구현 가능한 작은 작업으로 분해하고, 변경 범위를 명확히 유지하며, 검증 가능한 결과물을 만드는 개발 보조자 역할을 수행한다.

구현과 운영은 `app` 저장소에서만 수행한다. 이 `docs` 저장소에서는 `inbox/`, `spec/`, `epic/`과 지침 문서만 관리한다.

## 기본 원칙

1. 작업 전 관련 `spec/`과 `epic/` 태스크 문서를 먼저 확인한다.
2. 불명확한 요구사항은 임의로 확정하지 않고 가정으로 명시한다.
3. 한 번의 작업은 하나의 명확한 결과에 집중한다.
4. 관련 없는 파일은 수정하지 않는다.
5. 구현 후 가능한 최소 검증을 수행한다.
6. 결과 보고에는 변경 파일, 검증 결과, 남은 리스크를 포함한다.
7. 구현 중 참조 요구사항이 바뀌면 변경 범위와 재작업 영향을 다시 확인한다.
8. 구현 중 발견한 개선·수정사항은 사람이 `inbox/`에 기록하고 `AI_변경사항_반영_파이프라인.md`에 따라 `spec/`과 `epic/`을 먼저 갱신한다.

## 작업 요청 예시

```md
목표: 전투 결과 화면의 기본 UI를 구현한다.
참조 spec: spec/ui/UI-001_결과_화면.md
참조 epic: epic/developer-2/NNN_결과_화면_UI.md
구현 저장소: app
범위: 결과 화면 표시, 다시 시작 버튼, 메인 메뉴 버튼
제외: 애니메이션, 최종 아트 에셋
검증: 로컬 실행 후 승리/패배 상태에서 화면 표시 확인
```

## 결과 보고 형식

```md
변경 내용:
- 결과 화면 UI 추가
- 승리/패배 상태별 문구 분기

검증:
- 로컬 실행 확인
- 수동으로 승리/패배 상태 진입 확인

구현 기준:
- 참조 spec·태스크: UI-001, epic/developer-2/NNN

주의:
- 최종 아트 에셋은 아직 플레이스홀더 사용
```
